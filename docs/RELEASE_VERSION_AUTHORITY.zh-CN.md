# iOS 发布版本依据

本文是 iOS／iPadOS 下一版版本选择的唯一维护入口；各渠道实际交付状态见[当前状态](CURRENT_STATUS.md)与[逐版交付记录](releases/README.md)。Android 版本独立管理。

**最近已交付版本为 1.8.8（330）；下一中间 hotfix 暂选 1.8.9（331），尚未冻结。** 330 的内部 TestFlight、GitHub stable/latest 与 awaited Feather 已分别核验，未提交公开 TestFlight。用户最新要求先修复传感器、计时器、化学文件删除和生物回收站清理，尽快交付新的中间内测，不等 GPU／新增 Linux 视频硬件解码；后续支持硬解的完整版本再推进公开 TestFlight。331目前只是候选，未预留、未上传或交付；冻结前仍需核实构建号未使用。不得从未交付的较高标签自动推算版号。

## 依据与判定

读取顺序为：最新用户指令 → 本文记录的版本决定 → 各渠道真实读回。用户后续明确指令优先；各渠道是否交付始终须由该渠道读回确认，文档不能替代实际状态。

标签、源提交、候选目录、版本说明、构建／归档成功和签名流程启动，都不能单独证明上传、审核通过或可安装。不得从最高标签自动推算下一版，也不得把未交付尝试称为上一已交付版本。
