# 353 之后的 iOS 预研接入

基线为 1.8.32（353）的冻结源 `5e2014b5b`。本页记录下一版从现有入口可以到达的功能、已跑过的检查和具体依赖。已交付构建和安装渠道见[版本依据](RELEASE_VERSION_AUTHORITY.zh-CN.md)。

| 功能 | 从哪里使用 | 交接范围 |
| --- | --- | --- |
| 游戏工程 | 空间 → 文件 → 新建游戏，也可从已有任务的 IDE 打开或运行工程 | 26 个游戏／RPG 包接到工程创建、导入、编辑、试玩、构建、导出和工程助手。RPG 瓦片在快捷编辑器操作，部署资源在工程概览导出。按引擎加载实际资源包，运行归属于打开工程的环境。 |
| 建筑与室内 | CAD 建筑工作区和从图纸打开的工作区 → 工程 | 保存源图后建立经过内容校验的独立 CAD 副本。工程保存和重开同时覆盖楼层绘图、资料与交付物。PDF 从交付页打开，可编辑的二维／三维成果复制到空间。工程助手复用工作室会话和资料服务。详见[组件入口](../FloeAgent/Modules/FloeInteriorKit/README.md)。 |
| 图片编辑 | 从附件或工作区编辑图片，或从空间重开图片工程 | 首次打开即进入画布。已有工程保留原始图片、图层身份和历史数据。工具栏用于选工具，画布上方显示当前工具和活动图层；窄屏在画布下方显示参数。选区羽化、活动图层蒙版、笔刷硬度各自生效。源文件写回继续核对来源与修订。 |
| 任务浏览器 | 任务使用浏览器时可随时接管或交还 | 同一运行从观察到操作持续持有页面。主动释放、运行结束和人工接管均保留标签，旧运行不能再读取页面或操作新持有人。见[控制权设计](FLOE_BROWSER_CONTROL_PLAN_20261115.zh-CN.md)。 |
| 聊天文件变更、归档与工具发现 | 回复下方的文件行、工作区归档预览、模型工具调用 | 按任务与运行归并真实编辑回执，可用时打开已保存并验证摘要的版本。网络复制会在写目标前确认读取完整。归档使用原生服务，工具发现保留进行中任务的下一步。 |
| Linux 图形、视频与计算 | 本地终端 → 图形与加速，设置 → 执行环境 | 终端在当前 Linux 环境枚举设备、检查编解码和计算工具，也可启动已安装的 Blender。执行环境显示实际硬件和软件输出计数，并保存视频软件编解码偏好。已收进原生视频后端、virtio-media 客户机驱动、Mesa、OpenCL 和 BLAS 构建来源。已发布的 v8 客户机镜像继续按实际存在的设备和工具报告能力。见[图形源说明](../FloeAgent/LinuxGuest/image/graphics/README.md)。 |
| 本机模型与电子库 | 设置 → 诊断，空间 → 电子工程 | Core AI 读取用户选择的模型所声明的函数。内置电子库复用 353 的 47 个管理器件、12 份按需模型包，补入可复现的源数据和许可证。 |

已对照 353 实际入口检查照片测量、手写画笔、帮助中心、电子元件和 Mac Bridge、会议／音乐、工具箱、科学数据与模拟、GIS、制谱、字体、LaTeX、画布、制造和打印。接入这些功能时沿用已有实现。完整梁壳与非线性求解、完整流体／射频及多场求解仍是长期设计项。USB DriverKit 分发需要匹配的驱动和客户端签名配置，真实 Core AI 函数读回需要兼容模型，游戏运行时与 Linux 后端还取决于相应的资源包、设备与环境。
