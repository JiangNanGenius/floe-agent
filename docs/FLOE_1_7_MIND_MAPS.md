# Floe 1.7：图文思维导图与文档小窗

本轮实施范围以 iPad 为先。此文件说明产品行为与实现边界；测试版发布状态另见 [继续实施状态](FLOE_1_7_CONTINUATION_STATUS.md)。

## 入口与文档关系

手记的加号可新建独立导图。普通手记、导入 PDF 和 Office 编辑器顶部的“文档导图”可新建并关联导图，也可关联已有导图。导图仍然出现在手记文件列表中；同一张导图可以被多份文档引用，编辑共享同一份内容。

关联可以属于整个文档或某一页。列表显示范围，可改到当前页、改为整个文档或解除关联。每份文档最多关联 100 张导图。新建与关联使用一个事务；失败不留下半成品。

删除页面把该页的关联保留到文档层级，撤销可恢复页码锚点。解除关联、删除父文档或删除聊天不会删除导图。导图移入回收站后，关联列表显示不可用并提供恢复入口。文档与导图的选择、编辑会话和撤销历史各自独立；不复用 Canvas 节点或撤销栈。

## 主题内容

主题支持标题、长说明、网页链接、样式、图标、标签、折叠、关联线与概要。选中主题后，顶部“主题内容与附件”可修改说明、网页地址、附件和来源跳转；“主题图片”负责封面图片。未选主题时，使用中心主题。

| 内容 | 保存与操作 |
|---|---|
| 主题封面 | 原图进入手记资源存储，编辑器加载有预算的缩略图；插入、替换、移除 |
| 附图 | 一个主题可有多张图，保留原文件；可预览并设为主题封面 |
| PDF、Office、文本 | 作为原文件附件保存，系统 Quick Look 支持的格式可预览，也可分享给其他应用 |
| 音频、视频 | 保存原媒体，按系统支持情况预览或播放，也可分享 |
| 其他文件 | 保存名称与字节内容，支持分享；不承诺任意格式都可预览或编辑 |
| 附件说明 | 每个附件有可编辑的说明；名称与说明进入手记搜索文本 |
| 来源 | 已有文档、页面或主题来源标识跟随内容保存，不以显示名称代替身份 |
| 网页链接 | 仅接受 HTTP/HTTPS；用户点击后打开浏览器，不在导图 WebView 内执行外部页面 |

每个主题最多 32 个附件，一张导图最多 2000 个附件、64 张不同封面图片。单个文件不超过 512 MB。导图预览共享 1600 万像素预算，不同时解码所有附件。替换保留附件标识和说明；移除当前封面对应的附件会同时清除封面引用。编辑面板先保存草稿，点击“保存”形成一次可撤销修改；与 Agent 并发修改时检查版本，不覆盖较新的内容。

## PDF／手记／Office 小窗

在“文档导图”列表点开关联项，导图出现在阅读区域的小窗中。可拖动顶部把手、拖动右下角调整大小、展开或还原，也可进入完整编辑器。小窗位置与尺寸按父文档保存在本机，尺寸受当前可用窗口约束。导图初次显示及窗口尺寸变化时自动适应可用区域，之后仍可手动缩放和平移。iPad 分屏缩窄或 iPhone 窄屏时，小窗占可用宽度；展开后占满阅读区域。

小窗支持节点编辑、导图独立撤销重做、主题附件和完整 Floe 助手入口。按钮保持至少 44 点触控区域，调整大小的把手不覆盖导图缩放控件。附件或主题的来源在主阅读器打开，小窗编辑会话保持导图身份；来源失效时保留当前内容。离开未保存的附件面板前，可保存修改、放弃修改或取消跳转。关闭小窗不解除关联。浮窗只在 Floe 内的编辑器中交互，不是写入标准 PDF 的可执行控件。

## Agent 编辑

`notes.read` 返回主题、附件元数据和关联标识。`notes.edit` 可整体编辑导图、保留图文资源、建立或解除文档关联。关联另一张导图必须先将该导图加入此对话的资料范围；关联本身不扩大访问权限。

`notes.attachFile` 将当前任务获准访问的工作区文件复制到选定主题，支持替换、附件说明及图片封面。路径校验同时覆盖原路径和解析后的实际路径；提交时再次检查文档授权与修订号。工具调用回执避免重试重复添加，编辑可撤销。

文件内容、课件文字与导图说明只是资料，不因此获得运行工具的权限。图片资源存在不代表模型已识别图片。

## 保存、导出与恢复

`.floenote` 第 2 版归档包含根文档、关联导图以及去重后的全部附件资源；导入时重新分配文档身份并重映射内部引用。资料列表在一次事务中创建整组内容，失败不出现半套文件。继续支持第 1 版单文档归档。资源路径、大小、摘要、重复条目及结构均校验；可编辑归档总量上限 2 GB。

聊天、访问授权和历史撤销记录不随归档导入。关联的导图若已移入回收站，导出明确失败，需先恢复或解除关联，不能悄悄漏掉文件。

标准 PDF 导出保留页面与批注；Markdown 是导图文字大纲。两者均不是完整可编辑工程备份，携带关联及原附件应使用 `.floenote`。

## 验证要求

主机测试覆盖持久化、独立撤销、页面删除、关联事务失败、Agent 授权、附件归档字节、来源身份重映射和旧文档读取。原生定向工程编译实际小窗、附件面板和 Agent 工具，并在 iPad/iPhone、SDK 27/26 上执行真实 WebKit 与 PDF 组合测试，截图标注为组件场景。

仍须用完整应用确认文件选择器、各种附件预览、旋转和分屏、关闭重开、Agent 并发操作以及真实设备的 Pencil 和内存表现。组件编译或截图不能替代这些验收。
