## 精确几何与编辑

复用 OCCT、现有特征历史及工具入口，增加两距离倒角、距离／角度倒角和真实变半径圆角。倒角保留所选支撑面的稳定身份，交换两侧会产生相应几何；变半径采用两端相同、中部独立的对称半径规律。当前变半径支持独立的开放单边轮廓，切线边链与闭合曲线明确拒绝，不以均匀圆角冒充。

实际原生检查覆盖 33 个不同用例，包括多边原子处理与逐边回执、重复选边、凹边体积、实际参数／公式重算、失败恢复原有撤销重做、保存重开、合并引用与格式兼容。没有静默网格降级。原运行 30 通过／1 失败，失败来自旧工具说明被替换；恢复旧说明并追加新能力后，原断言通过。新加入的闭合曲线拒绝和多边模式也已实际通过。
