# CAD 扫掠路径与螺旋持续编辑

2026-11-02。对应原始 M15 验收条件；保留原 CAD 内核、草图和参数服务。本记录不代替其他 CAD、界面、实体设备或整轮发布验收。

## 实际行为

- 原生路径选择保存有序草图及边身份。修改源端点后，同一精确扫掠实体随动；缺失边或断开的路径明确失败，不搜索相似边替代。
- 助手可以替换同一特征的路径，也可明确解除关联。解除时冻结当前实际路径，后续源修改不会改变已解除的扫掠。
- 历史面板的半径、螺距和圈数字段复用参数服务。修改生成对应精确螺旋及采样路径；失败保留原实体、引用和撤销历史。
- 半径修改保存截面相对源平面的三个附着坐标，包括法向偏移；只调整求值框架，原草图及其平面关联不变。非零起始角同样验证。
- 同一原路径在源修改后再次被选中，不因旧点缓存产生额外编辑或撤销。原有显式渲染路径在参数未变时保持原样。
- 保存、重开、撤销和重做保留特征及实体身份。新引用及截面附着按需使用本轮未发布的格式 7；旧数据可读，未来路径版本保持只读及原始内容。

测试通过精确实体的独立三角化量测半径，未以显示用采样路径或参数回显代替。零跳过；各次运行结束均关闭模拟器。原编译失败和运行失败保留。机器记录见 [app-check.json](app-check.json)。
