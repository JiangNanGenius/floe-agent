## 已完成的行为

- 导入前的报告分别列出保留与不保留内容，界面提供双语明细；原始文件保持不变。静态几何、对象位置与受支持材质不等于完整 Blender／USD 工程往返。
- Blender 复用现有读取器，正确组合父子变换、父级逆变换、六种欧拉顺序、四元数／轴角、增量变换及反射缩放。损坏、循环或无法确定的父级关系明确拒绝，不用单位矩阵代替。
- USD／USDZ 复用原生读取。二进制元数据无法确认单位时要求明确选择，不能假设厘米；单位选择属于输入校验，不显示为存储损坏。未知单位也不会在界面上标成“检测到”。文本单位检查有界，不再次展开整份归档或读取纹理来猜单位。
- Blender 当前保留基础颜色与颜色贴图，其他材质通道明确列为不保留。USD 保留读取器实际支持的静态材质。动画、骨骼、修改器及可编辑场景层级仍保存在原始文件中。
