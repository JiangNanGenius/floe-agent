# Floe Agent 1.4.33（Build 64）TestFlight 测试说明

这是首个公开 Beta 候选版本。请优先验证真实任务能否连续完成，不需要重复进行已经通过的全工具巡检。

## 测试重点

- **下载式本地模型：**分别完成一次普通回复和一次简单工具操作。回复或工具调用结束后，App 不应退出；下一轮仍应保留对话。Floe 会在每轮结束后释放模型的临时占用。
- **Apple Intelligence：**先自然聊天，再在同一任务中请求当前位置或另一项已开启的 Apple 能力。第二轮应开始回复或调用真实工具，不应一直停在准备状态，也不应只输出工具格式文本。
- **Python：**基础 Python 应可使用 `mmap`、`bz2`、`lzma` 和 `ctypes`。兼容的纯 Python 包可以在用途审核后安装；NumPy、pandas 等科学计算工作应走可见浏览器中的 WebAssembly Python 路径。
- **记忆：**“整理记忆”必须立即显示进度和结果。批量选择、全选与删除应即时更新。任务或工作区删除后，相关记忆仍保留原归属并逐步老化；跨任务提问可以召回相关记忆，被召回内容会暂时提高优先级。
- **工作区与恢复：**新任务的私有工作区应自动显示并挂载。中断后继续时应保留上下文和已完成工具记录，不得重新执行已经成功的相同操作。
- **界面文案：**设置、用量与错误提示应说明用户能理解的状态和下一步操作；诊断日志仍保留必要技术信息。

## 反馈信息

请注明 Build 64、设备型号、iOS/iPadOS 版本、所选模型、准确操作、结果和时间。若出现本地模型退出或 Apple 第二轮卡住，请只上传本次最新的脱敏 Floe 诊断，以及时间匹配的 Xcode Organizer/设备记录。不要发送密钥、Token、证书或描述文件。

本地模型和 Apple Intelligence 的最终稳定性必须在兼容的 iPad 真机上确认；Mac 构建通过不能替代真机结果。
