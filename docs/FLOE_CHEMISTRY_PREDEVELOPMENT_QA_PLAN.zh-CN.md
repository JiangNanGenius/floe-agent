# 化学工程预研发需求与实施基线

日期：2026-11-06。首轮产品 QA 已确认。本轮交付独立模块和可操作验证界面，尽可能完成更多实际功能；正式 App 接入由后续集成阶段收取。

化学工程以完整工具链为目标，覆盖小分子、晶体材料、蛋白质和 DNA。日常编辑、分析与适合设备规模的计算优先在 iPad 本地完成；重计算可交给用户配置的 Mac 或通用云环境。按阶段实现，不因 iPad 不适合超重计算而删除功能方向，也不以专有付费化学服务作为基础功能的前提。

## 功能范围

下表是预研发需求，不是已实现清单。每项在交接时记录实际代码、可执行后端、验证输入与结果；尚未完成的子项继续保留，不能用入口、工具描述或演示结果代替实现。

| 领域 | 需要形成的实际能力 |
| --- | --- |
| 输入与交换 | 新建、绘制、名称／结构标识输入、导入与导出；覆盖分子、反应、晶体、生物结构与谱图的对应格式。名称检索、文档／图片识别与结构解析分别记录数据和模型依赖。 |
| 分子编辑 | 二维结构式与三维结构、原子／化学键编辑、选择、测量、立体化学、氢处理、构型管理与结构校验。 |
| 基础计算与化学信息 | 分子式、分子量、计量和单位换算、反应配平、结构特征、相似性、结构检索及适用的性质估算。精确计算、经验估算与模型预测分别标注。 |
| 反应与合成 | 反应图编辑、原子对应、反应规则处理、产物预测、合成路线与相关结果管理；绘图、预测和反应过程计算分别实现与验证。 |
| 能量与电子结构 | 几何优化、构象搜索、能量、电荷、电子分布及相应可视化，保留方法、适用条件与求解状态。 |
| 分子模拟 | 设置模型和初始条件、运行动态计算、观察进度、取消、保存与回放轨迹，以及结果分析。动画演示与实际模拟轨迹分别说明。 |
| 晶体与材料 | 晶胞与周期结构编辑、重复结构、对称性、材料分析、衍射与相关计算输入／输出。 |
| 生物结构 | 蛋白质、DNA 等结构查看与编辑、链／局部选择、测量、相互作用与轨迹分析；结构预测、折叠与结合相关计算单列后端和验证。 |
| 光谱与实验数据 | 导入、显示、比较与分析谱图，连接结构和峰；已有谱图展示、计算生成谱图与模型预测分别收取。 |
| AI 工具链 | AI 能读取实际工程、编辑对象、启动与查询任务、处理错误、分析实际输出、制作图表并保存结果。大模型可完成适合它的基础计算，也可编排本地或远端工具。 |
| 工程与呈现 | 多对象工程、工作台／文档双视图、自动保存、历史版本、撤销恢复、结果重开、比较、导出以及后续手记引用。 |
| 资源与执行 | 可下载资源包、完整性与可用性检查、iPad／Mac／云能力发现、任务进度与取消、真实结果回传。缺少配置或组件时给出可操作的状态。 |

## 工具链与数据约束

沿用 Floe 现有模型、环境、作业、文件和权限服务，通过独立模块的宿主适配接口连接。执行记录携带明确的工程、对象修订和环境归属；不创建绕过现有机制的语言执行入口，也不默认使用宿主解释器。配置完成且实际可用的能力才进入 AI 工具发现。

工程数据是工作台和文档的共同来源。文档内容块引用稳定的工程对象与结果，不维护另一份分子或计算状态。手记保留独立编辑状态、撤销和 AI 对话，通过引用或明确导出连接化学工程。

每个计算记录输入对象和修订、方法、参数、引擎版本、资源版本、实际环境、状态与输出。计算结束后原对象已改变时，结果仍绑定原输入，不能静默覆盖新的结构。工具计算结果、资料来源和 LLM 推断保持可区分，模型说明不能冒充实际求解结果。

保存、资源安装与结果提交采用有界输入、取消、分阶段写入和可恢复提交。失败保留已有工程与原件；关闭视图不丢失服务持有的任务。并发修改与迟到回调不能写入其他工程或对象。

专业界面直接提供方法与参数，并允许 AI 解释。普通状态使用简洁中英文文案；内部标识、协议和完整诊断放入详情。iPad 优先，兼顾 iPhone 的紧凑操作；不更改 App 外层分栏。

## 首轮源码核对与首批实现路线

本轮核对固定在 Avogadro `a5947518efb84132a44110dbdecab94fc87ce3b8`、Indigo `f50fdb74c4e95337ab002c8f4b5006a100032ed7`、RDKit `4d1e2824988b95688de222fd96f71b75a3e7ac80` 与 Gemmi `97c808222f468f8188f2ed87266e0d7c5a854ce2`。这些是研究快照，正式引入依赖时另行固定经过验证的版本和哈希。

Avogadro 的 `Core`、`Calc`、`IO` 和 `QuantumIO` 在 `USE_QT=OFF`、`USE_OPENGL=OFF` 时仍进入构建；桌面界面与渲染组件另有开关。因此优先验证可独立使用的原生核心，不把整个桌面 App 移入 Floe。[构建选项](https://github.com/OpenChemistry/avogadrolibs/blob/a5947518efb84132a44110dbdecab94fc87ce3b8/CMakeLists.txt)、[子库构建关系](https://github.com/OpenChemistry/avogadrolibs/blob/a5947518efb84132a44110dbdecab94fc87ce3b8/avogadro/CMakeLists.txt)

| 首批链路 | 已确认的上游入口与实施安排 | 需要取得的实际证据 |
| --- | --- | --- |
| 分子数据与基础分析 | `Core::Molecule` 提供原子、键、坐标、分子式、质量、残基和晶胞数据；用稳定的工程对象标识连接原生核心。 | 水、乙醇、咖啡因与带电／立体结构的真实解析、编辑和计算；与已知值核对。 |
| 文件与轨迹 | `IO::FileFormatManager::readString/writeString`；上游已有 SMILES、MOL/SDF、XYZ、PDB、VASP、DCD、TRR 等实现。逐格式核实保留的信息和限制。 | 格式往返、坏文件／超限输入、坐标与键／电荷／立体信息检查。 |
| 本地几何与力场 | `Calc::UFF` 与 `EnergyOptimizer` 已在不依赖 Qt 的 `Calc` 中；优化接口支持分步状态，可作为进度和取消边界。 | 真实能量与梯度、几何优化、收敛／停滞／失败状态；不能把 Lennard-Jones 回退当成所选方法。 |
| 晶体与生物结构 | `UnitCell`、`CrystalTools`、残基／链数据和 PDB 读写构成共同基础；CIF/mmCIF、对称性和衍射继续对照 Gemmi、spglib 等补齐。 | 晶胞坐标往返、超胞结果、真实 PDB/mmCIF 样本和残基／链保留。 |
| 二维结构与反应 | 对照 Indigo 的 C API 和 Ketcher，验证布局、反应编辑、原子对应、结构检索等可补充能力；接入前核实是否与现有核心重复。 | 实际输入／输出与反应对象保存重开，离线资源完整时可操作。 |
| 计算结果与显示 | `QuantumIO` 含 Gaussian、ORCA、NWChem、Molden、QCSchema 等结果读取；电子结构求解、谱图预测和动态模拟分别接实际后端。 | 解析结果与原文件一致；任务提交、真实求解、回传和可视化逐层验证。 |
| AI 与工程闭环 | 首批即连接真实对象读写、计算与结果，形成“新建／导入 → 编辑 → 计算 → 查看 → 自动保存 → 重开”。后端暂缺时返回明确状态。 | AI 动作与手动操作使用同一数据和服务路径；旧修订、取消与权限拒绝不能产生误写。 |

以上为实施顺序，不替代完整功能范围。反应预测、合成路线、电子结构、动态模拟、谱图预测和生物结构预测继续保留在对应后端计划中。Mac／云后端使用用户的通用执行环境；LLM 可生成任务和分析结果，工程同时保留实际执行证据。

## 实施与验收安排

1. 固定需求和上游来源，核实真实可调用的核心与依赖，给每个功能方向记录后端、输入／输出、执行位置和当前状态。
2. 实现可独立验证的工程核心、保存与恢复、真实结构输入／输出和首批实际计算；同步形成可操作界面，不先堆积只声明能力的工具目录。
3. 依已验证的接口接通 AI 动作与执行环境适配，扩充分子、材料、生物结构、反应、模拟与谱图链路。每批交接能操作的功能、精确检查结果和剩余项。
4. 由主协调者进行界面判断与最终收件。独立模块验证通过后，另行交接正式 App 的空间、手记、作品和 AI 工具接线。

根据改动运行有意义的数值、格式往返、持久恢复、修订冲突、取消和权限边界检查。Swift 6 使用实际对象编译；iOS 与 Mac 组件、验证宿主、完整 App 和物理设备的证据分别记录。模拟器只使用仓库规定的复用 iPad 和串行锁，实施任务不独立占用设备。

每批保存源码标识、上游固定版本、工具链、命令、实际结果与原始失败。组件编译、计算成功、AI 工具调用、界面操作和实际 App 接入分别收取。本轮不更改 App 版本、标签、签名、TestFlight、正式审核或公开发布状态。

## 当前状态

- 已形成代码：`FloeChemistryNative`（Avogadro C++ 核心）、`FloeChemistryKit`（工程、计算、工具与原生工作台）、`FloeChemistrySketch`（离线化学转换组件与研发对照）。
- 已取得证据：三平台原生静态库、Swift 6 对象编译、分子／晶体／轨迹／反应／谱图及持久化测试；RDKit、Gemmi、OpenMM 和 xTB 在独立 Mac 验证环境中产生实际结果。后端脚本验证不代表已连接 App 的远端环境。

- 当前收件：15 项模块测试、9 项 Mac 后端测试通过；独立界面复核提出的四项修正均已评分为 resolved。具体能力与边界见[本轮实施记录](FLOE_CHEMISTRY_PREDEVELOPMENT_IMPLEMENTATION.zh-CN.md)。
- 正式 App 的空间／手记入口、现有模型服务、Mac／云环境作业适配和实际 LLM 调用仍交由集成阶段收取。原生三维生成、复杂组编辑、生物结构专用显示、预测模型及其他未完成子项继续保留。
