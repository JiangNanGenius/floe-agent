# 完整 PCB／原理图编辑器接入账

2026-11-08。用户明确原定目标是完整 PCB 编辑器，包含原理图与板级编辑；不能用 Gerber 查看器或几个放置／连线／布线操作结算。本表恢复这一完整目标并追踪实现，不将某个阶段的完成当作整个编辑器交付。

当前找到的历史源码只有工程文件的 Gerber／钻孔查看路径；`EngineeringPreviewPackage` 仍将 KiCad PCB／原理图标为未支持。历史完整编辑方案原件尚未找到，保留“原规划入口缺失”这条反馈；不据此断言完整编辑器从未被规划。本轮同时修复建筑二级功能，二者独立推进。

## 实现与验收顺序

1. 原生文档与编辑核心：明确对象／网络身份、修订、事务、撤销和保存格式，建立实际连通关系与局部规则检查。只结算这一阶段的实际能力。
2. 原生原理图、板与库编辑器：用同一服务编辑实际对象，接上空间与文件，形成保存返回链。
3. 补齐高级布线、规则、铜区、交换、制造、三维、仿真与全部二级功能，按上表保留逐项状态和缺口；专业引擎复用按实际许可与平台能力选型。
4. 接入既有模型工具、绑定的环境与作业、可信产物引用；主线串行编译、实际 App 核对并清理产物。

验证按改动选择真实算例与对象编译，优先实际编辑、结果、撤销及保存重开；不为一个小改动恢复全应用稳定性矩阵。原始失败、外部引擎未运行、实体输入或设备未验收分别记账。任何尚未实现的完整范围项都保持未完成，不改成“可查看”后标为完成。

本轮不改版本、签名或分发状态，不新增公开 TestFlight；USB 串口仍等待 Apple 审批，不随包加入。
