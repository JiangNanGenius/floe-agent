# 工具箱独立预研发收件清单

本表在用户追加 USB 后建立，用于防止新增专题覆盖原项目。所有原条目继续保留，不用完成 USB 代替整个工具箱完成。此前空间、手记、媒体、CAD、图解、画布、音乐、会议、打印等大升级专题仍按原收件记录推进，本工具箱专题不删除或重排它们。

| 原条目 | 产品范围 | 实施与复用边界 |
| --- | --- | --- |
| TB01 | 空间第四页工具箱 | 概览、手记、文件之后；保留原外层导航 |
| TB02 | 内置 Linux / SSH 终端与 AI | 内置环境、系统环境、工具箱机器、临时机器；助手绑定当前终端，复用模型、环境与权限 |
| TB03 | VNC | 复用现有远端桌面，不加 AI；SSH/VNC 配置和端口独立 |
| TB04 | 浏览器 | 名称改为“浏览器”；复用现有 WebKit、标签和会话服务，工具箱直接进入 |
| TB05–10 | Ping、路由、DNS、端口、局域网发现、Wi-Fi 信息 | 复用当前能力，分别反映真实平台与权限状态 |
| TB11–12 | TCP、UDP 客户端 | 合并到一个串口助手内部的连接方式；字节流与数据报语义分开，文本/HEX、本地绑定/目标端口和收发记录 |
| TB13 | Modbus | 串口助手内部的协议选择；TCP/UDP/蓝牙/USB，MBAP/RTU 按设备实际封装选择，读写与异常解码 |
| TB14–17 | HTTP/API、WebSocket、MQTT、BLE 串口 | HTTP、WS、MQTT 为主页同级独立客户端；BLE 是串口助手内部的连接方式。各自生命周期和数据层级明确，共用会话 AI 合同 |
| TB18–21 | 校验、JSON、编码、二维码 | 复用本机能力，正式文件/导出与主线文件服务对接 |
| TB22 | 记录与抓包分析 | 本工具数据＋PCAP/PCAPNG；滚动上限、自动保留、手动快照/导出、截断和缺包可见 |
| TB23 | 自动 AI 操作与审批 | 授权内自动诊断收发，写入沿用现有审批；目标/代次、拒绝、取消与迟到结果隔离 |
| TB24（新增） | USB 多芯片驱动代码预研 | CDC-ACM、FTDI、CP210x、CH34x 等可支持族，PL2303 等按修订评估；公开 USBDriverKit、许可和分发权限分别核对。用户硬件测试，不保证兼容性，不作为本阶段等待门槛 |
| TB25（追加） | 漫游追踪 | 网络诊断中的独立入口；Wi-Fi 接入点变化、延迟/丢包、观察间断及导出。只使用有来源的测量，未知信息不作零值或切换推断 |
| TB26（追加） | 终端文件管理与同步 | SFTP默认、SCP、FTP/FTPS、WebDAV、SMB纳入；内置Linux直用环境文件；rsync归同步。终端文件面板、展开双栏、队列、冲突、半成品与保存回传；复用原SSH/挂载/凭据/jobs。详见[远程文件预研](FLOE_TOOLBOX_REMOTE_FILES_PREDEVELOPMENT.zh-CN.md) |

## 当前交接层次（R4）

- **TB01–04**：18入口和空间顺序、原生机器来源/终端文件面板、VNC独立控件、浏览器路由合同齐备；复用现有终端/VNC/WebKit。终端AI绑定会话，临时机器不保存策略已有Main定向补丁。
- **TB05–10、TB25**：原生ICMP、DNS-SD记录、显式端口、Bonjour、Wi-Fi观察及独立AP/Ping采样服务；有取消、权限/来源与滚动记录边界。平台不给出的BSSID/RSSI留空。
- **TB11–17**：实际TCP/绑定本地端口UDP、WS消息、HTTP、MQTT3.1.1/5 QoS0/1/2、Modbus读写/MBAP/RTU，以及现有蓝牙接口的有界分块桥接；不是只保留传输协议合同。
- **TB18–23**：实际流式摘要、JSON/编码/二维码；PCAP/PCAPNG、自动CAS记录/快照/导出；终端和通信AI调用现有模型/审批回调。模块不需要开发者拥有第三方账号才开放用户配置入口。
- **TB24**：芯片候选、描述符/IPC验证、真实DriverKit service/user client、USB批量后端及异步IOKit客户端；已做对象编译/错误路径与随机输入检查。dext签名/团队USB权限/系统启用由正式接入处理，硬件由用户测试。
- **TB26**：有界SFTP、真实SCP/FTP/FTPS/WebDAV、已有挂载/File Provider桥接；持久传输队列、恢复复核、源/目标冲突、半成品、编辑保存回传。rsync使用已解析环境的exec.shell/jobs，模块不在宿主执行shell。现有SMBClient的接收帧/目录聚合缺口已定位并交接，不能原样宣称通过畸形服务器验证。
- **主线收取边界**：App路由、原有Keychain/数据库/jobs、模型工具注册、文件选择/分享、驱动启用与实际App UI验收由集成任务收取。本轮独立模块没有更改App版本、签名、审核或发布状态。
- **证据**：R4累计87项组件测试、7项接入检查通过，覆盖独立loopback MQTT/Modbus/FTP/FTPS/WebDAV及OpenSSH SCP；真实iOS26对象编译及DriverKit对象另有最终资格记录。iOS/DriverKit对象、浏览器预览、App、真实硬件与分发分别结算，不相互替代。

产品与源文件对照见[模块README](../FloeAgent/Modules/FloeToolbox/README.md)，接线顺序见[Integration](../FloeAgent/Modules/FloeToolbox/Integration/README.md)。

TB05–10、TB18–21 是功能组编号范围。原 20 项工具加 USB 的能力身份保留；后续按用户修订合并五个连接/协议入口并追加漫游，主页为18个入口。编号不随界面合并重排，也不以主页按钮数结算功能数。
