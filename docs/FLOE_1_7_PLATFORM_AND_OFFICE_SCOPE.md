# Floe 1.7 平台与 Office 范围补充

状态：开发中；本文件是实施要求，不是验证或发布结论。

## 平台优先级

全项目以 iPad 为首要设计对象，iPhone 保持完整核心流程。
iOS / iPadOS 27 是本轮主要更新平台：系统已有公开原生能力时优先采用，
尤其是 PencilKit 选区、手写、系统文档和交互能力。不要为了 26 的实现方式
削弱 27 的体验，也不为系统已经解决的问题另造通用底层。

最低兼容版本继续保持 26。新增 27 API 必须通过可用性判断隔离；26 保证
内容可打开、可编辑、可保存，提供必要的兼容交互。不能无条件引用 27 API，
不能在兼容设备上展示无法执行的操作。私有 API 不作为兼容途径。

优先验收 iPadOS 27 的完整体验，然后验证 iOS 27；26 双端验证核心可用性、
保存恢复和降级入口。开发 SDK 构建结果不能代替发布 SDK 与真机证据。

## 手记中的 Office

复用 Floe 现有 Office 引擎与安全工作副本机制，文件归手记长期管理，
不随聊天删除。优先完善 Word 和 PowerPoint；Excel 暂缓新增增强功能，
保留原有能力。

- Word：实际编辑、格式调整、图片与附件、画笔批注、保存重开。
  笔迹必须可持久化，并明确其在原格式与 PDF 导出中的保留方式。
- PowerPoint：基本幻灯片编辑、增删排序、图文修改和真实全屏放映；
  iPad 上优先完善触控、键盘翻页和退出放映。
- 导出：优先 PDF，同时接通引擎真实支持的 Word、演示及其他兼容格式。
  按当前文档类型列出有效格式，不能仅修改扩展名；导出前说明确实存在的
  格式能力差异，失败保留可恢复的编辑副本。
- 验收：重新打开原格式和导出文件，检查中文、版式、图片、笔迹、页数；
  PPT 需验证真正放映以及返回编辑，不以静态预览代替。

## 当前改动与待完成项

手记独立存储、入口、PencilKit、选区图片与助手接入已写入；27 与 26.6 SDK 的 iPad/iPhone 原生组件测试已通过一轮。可编辑归档有主机往返与篡改拒绝证据。

Office 的多格式导出、矢量笔工具和放映接口已经接线，宿主云端构建通过并更新了固定资产摘要。仍需在完整应用和真机中验证 Word 笔迹保存重开、不同格式输出、PPT 真正放映与返回编辑，不能把桥接调用完成当成这些交互已验收。

后续 AI 回答保存、分页、来源跳转、Office 恢复入口与完整导图编辑的状态，统一见 [继续实施记录](FLOE_1_7_CONTINUATION_STATUS.md)。

完成本轮功能后再集中验证、构建和推送 TestFlight；不自动正式发布。
