# 本轮预研接入

本轮目标是把预研直接融入空间、手记和创作，补齐界面、执行、可见结果、持久保存和 AI 工具。纯方案也纳入实现。以完整接入为优先，仅交付内部 TestFlight。315 的正式审核与自动发布选择保持。

加工原生链路和建筑／Mesh 本机化由各预研进程独立收尾，主线按文件范围接 UI 与服务接口。若其他模块先完成、加工尚未完成，可先交付不含加工的内部测试中间版本；这不撤销后续全量集成目标。

## 当前验证边界

本地使用 Xcode 27.2（27B52）与 27.2 SDK，iOS/iPadOS 26 为兼容目标。完整 App 的 arm64 Simulator 构建已通过；Siri 针对性运行包含 20 项 XCTest 和 9 项 Swift Testing 测试，均通过；后者还包含参数化链接用例。实际界面验证仅使用指定复用 iPad Simulator，未测试用户真机或实际 Siri 听音。

后续小型 App 测试宿主已实际构建通过。已通过的针对检查包括原生双格式切片、三个音乐／加工／打印运行检查、会议原件重开，以及两组 8 项作品权限与链接检查（含参数化用例）。这些是实际 App 宿主／指定 Simulator 的证据，不是整个 App 的稳定性或所有界面验收。

加工 R10 的 Rust 组件测试原为 130 通过、5 失败，原失败与断言保留。后续 R11 修复圆柱边界场及口径，137 项 Rust 检查和三个实际 C ABI 复核通过；主 App 已用新能力标记确认实际运行的是 R11，再验证计算与存档。组件资格不代替全部工业场景验收。

最新定向 App 检查包含实际本地 IFC 几何生成与重读、64×64／16 样本离线 PNG，以及 R11／作品权限持久链。原生音乐界面检查已验证 MIDI 音符字段、助手输入框和普通历史隔离；打印界面首次自动检查停在侧栏导航，原现场保留，修正定位后继续复核。未以该次导航失败推断切片引擎失败。

许可证按原预研来源及组件声明收取，继续采用主 App 原生计算；不预设存在许可冲突而更换架构。保留 TurningNative 的 GPL-2.0 声明、其他组件声明、Rust 依赖许可证文本及固定版本。
