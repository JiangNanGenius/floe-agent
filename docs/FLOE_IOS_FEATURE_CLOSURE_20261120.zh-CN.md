# iPad 与 iPhone 功能盘点 · 1.8.55

这次从用户指南、工作台指南以及 App 的可见入口向下追踪。下表记录每类功能从哪里进入、结果在哪里找回，以及本轮证据能说明什么。表中的“源码”表示已检查界面与服务的调用关系。模拟器上运行过的流程另列。

| 功能 | 用户操作与结果 | 本轮核对 |
| --- | --- | --- |
| 导航、聊天与任务中心 | iPad 从侧栏选择任务，iPhone 从抽屉进入。回复、工具记录、计划与任务状态可从同一会话找回。 | iPad 测试覆盖按轮停止、单独停止子任务、其他子任务继续及编辑器审批继承。 |
| 本轮文件修改 | 在回复下点文件名查看该次保存的差异，再点一次收起；工作区源码管理用于查看当前状态。 | iPad 测试覆盖较长差异一次展开，以及跨分页时旧回复的文件归属。 |
| 空间与手记 | 从空间的文件、手记或新建进入。作品写入个人文库，可关闭再打开；文件任务可找回作品助手。 | 源码。手记、画布和任务工作区各有存储归属。 |
| 游戏 | 空间创建游戏或导入工程；聊天产生的游戏从工程文件进入 IDE；游戏主页和 IDE 均提供运行。源码管理使用同一工作区。 | 已检查工程与会话身份，iPad 验证空工程、右侧助手，以及从 Phaser 工程主页和 IDE 各自运行、停止并回到发起页面。不同引擎及第三方插件的兼容性仍需按样本记录。 |
| 文件、IDE 与 Git | 从文件树打开预览或 IDE，在源码管理查看改动，网页服务由 IDE 启动并可返回。 | iPad 首次发现过期 Studio 目录会遮住普通文件，修复后在同一工作区通过文件 → IDE → 运行选项 → 返回。 |
| 创意、图片、视频与音乐 | 从创意模式打开画布，从空间或文件打开图片与 Studio 工程。图层、时间线和导出文件分别保存在对应工程或工作区。 | 源码。静态预览、可编辑工程和导出文件用途不同。Pencil 操作与硬件视频处理需真机验收。 |
| Office、PDF 与 LaTeX | 文件预览或空间作品进入专用编辑器；Office 保存并重新打开，LaTeX 工程排版后查看 PDF。 | 源码。本轮未重新测量排版保真度或所有格式的往返保存。 |
| 建筑、CAD、三维、电子与 GIS | 从空间打开对应作品；编辑、保存或另存为，再从个人文库或导出位置找回。 | 源码。设备连接、制造输出及具体格式仍须按实际设备或文件核对。 |
| 会议、化学、生物与字体 | 在各自作品或字体管理中打开。会议保留录音与转写，专业编辑器将结果写回当前作品。 | 源码。语音质量、外部计算服务及专业格式未逐项真机验证。 |
| 浏览器与工具箱 | 浏览器工具和实时预览共享会话及接管状态。测量、串口、网络工具从工具箱进入，按工具查看记录或导出。 | 源码。定位、蓝牙、USB 串口、传感器和 AR 需要相应设备。 |
| Linux、远程主机与 Bridge | 执行设置配置环境；任务先用已绑定环境，新任务可采用工作区或全局远程主机偏好。终端、端口、服务都有对应管理入口。 | 源码。Mac 本机配对入口有平台限制。包安装、视频编码和跨机传输的速度本轮没有重新测量。 |
| 模型、搜索与语音 | 设置中配置供应商、凭据与模型，聊天或作品助手采用有效配置，调用错误回到当前任务。 | 源码。云账户、实时语音、端上模型推理需实际配置验证。 |
| Skill Hub、连接器与自动化 | 从 Skill Hub 安装、管理或导入；连接器与远程主机有各自配置；定时任务在任务中心查看。 | 源码。外部账号投递与推送到达未实测。 |
| 设置、引导与数据 | iPad 使用分栏，iPhone 使用逐级导航。设置含引导、权限、同步、诊断与存储恢复。 | 源码。历史导航别名已从可见列表过滤；跨设备钥匙串同步及存储恢复要用真实数据验收。 |

## 入口与优先级

1. 修复会挡住用户下一步的故障。Studio 目录失效时应标出该目录，其他文件仍可用。聊天打开游戏时校验任务和工作区归属。
2. 合并同一页面通向同一操作的控件。游戏主页只保留一个 IDE 入口和一个助手入口；首页运行与 IDE 运行分别服务于正在使用这两个页面的人。文件差异直接在原回复展开。
3. 补足运行证据。第三方游戏、真机语音、Pencil、GPU 编码、跨设备同步及系统推送分别记录样本、设备和结果。一次 iPad 模拟器通过只覆盖对应路径。

相关实现可从 `GameProjectSpaceScreen.swift`、`WorkspaceIDEView.swift`、`FileTreeViewModel.swift`、`ThreadDetailView.swift`、`SettingsRootView.swift` 和 `TaskExecutionEnvironmentCenter.swift` 追踪。完整操作说明见[用户指南](USER_GUIDE.zh-CN.md)与[空间及专用工作台](WORKSPACES_GUIDE.zh-CN.md)。
