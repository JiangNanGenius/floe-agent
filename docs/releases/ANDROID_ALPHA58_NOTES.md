# Android 0.1.0-alpha.58 / code84

This intermediate preview continues N01–N08; whole-App acceptance remains in progress.

- Phone observations retain empty editable fields and unlabeled actionable controls. Labels from read-only children identify their actual clickable parent; flags distinguish click, text input, scrolling and read-only content. Protected values stay masked. Existing ownership, page freshness and action checks remain authoritative.
- Returning to the newest chat message now requests an actual scroll, including when the last response is longer than the screen. An accepted send returns to the live end; a rejected send keeps the reading position. Programmatic scrolling does not count as a user scrolling away.
- External-edit guidance arranges screen handover before opening an editor and requires a new observation after a return to Floe. Linux status reports graphics only for the exact task environment; project software is available through explicit execution-location selection, with no silent retargeting.

Related Full/Play compilation and 43 focused JVM checks passed. Actual ARM64 production, packaging and Samsung evidence are recorded separately for this exact candidate. Compilation does not establish automatic editing or scheduled UI recovery.

Known limits: automatic external editing has not passed the preceding Samsung cases. Approval denial, an inaccessible editor control or a changed page requires a clear stop or handover, not an invented tool receipt or replayed node. Unattended unlock, scheduled multi-App editing and remaining professional-preview paths continue through device iteration. Existing files, recovery copies and task software are retained.
