# Floe Agent 1.8.0 for Mac

## 简体中文

- 连续发送消息时保留已显示的前文。较长的对话可以分批加载旧消息，也可以直接导出完整的 Markdown 对话。
- 可从已保存的消息在 Finder 中显示原始附件。
- 任务中心显示已归档任务和较早任务的最近运行状态，退出后遗留的运行标为已中断。
- 修复启动时工作台恢复上次任务偶尔卡在加载界面的问题。
- 原 Floe Bridge 可继续通过「检查更新」升级，再选择「切换到 Floe Agent」。

## English

- Keep the visible conversation when sending another message. Load older messages in batches or export the full conversation as Markdown.
- Reveal original attachments from saved messages in Finder.
- Task Center shows the latest run for archived and older tasks, and marks runs left behind after a quit as interrupted.
- Fix an occasional loading stall when reopening the last task at startup.
- Update existing Floe Bridge installations with Check for Updates, then choose Switch to Floe Agent.
