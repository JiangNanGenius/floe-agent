# Floe Agent 1.11.22 for Mac

适用于 Apple 芯片和 macOS 15 或更新版本。现有 Floe Bridge 和 Floe Agent 可通过「检查更新」升级。

- 在「设置 → 设备同步」中，可以按设备和会话单独共享工作区文件。接收会话与文件时复用同一条连接，两端都编辑过的文件会保留冲突副本。
- 「权限」移到设置前列，便于调整默认审批模式、操作开关和已保存的授权。
- 主模型只支持文本时，运行中的带图引导可由已配置的辅助视觉模型读取。引导仍以原用户消息保存。
- Agent 可从工作区图片提取文字、读取条码，并查看扫描 PDF 的指定页面。
- 已安装兼容版本的 Kimi CU 时，Agent 可向指定窗口发送后台快捷键和拖拽。

## English

For Apple silicon Macs running macOS 15 or later. Use Check for Updates in an existing Floe Bridge or Floe Agent installation.

- In Settings → Device Sync, opt in to workspace files separately for each paired device and conversation. Conversation and file transfers reuse one connection, and concurrent edits are kept as conflict copies.
- Permissions is near the top of Settings for quick access to default approval modes, the actions switch, and saved approvals.
- A configured vision helper can read images in steering messages when the primary model is text-only. The original user message remains in the conversation.
- The agent can extract text and read barcodes from workspace images and inspect a selected page of a scanned PDF.
- With a compatible Kimi CU installation, the agent can send background keyboard shortcuts and drags to a specific window.
