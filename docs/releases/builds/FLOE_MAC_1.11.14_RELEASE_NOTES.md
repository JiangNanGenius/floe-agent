## Floe Agent 1.11.14 for Mac

- 会话沿用 iPad 的消息、运行事件和 JSONL 导出格式。更新会自动补齐旧版会话库的兼容字段。
- 在供应商设置里搜索、刷新和多选模型，确认后随供应商一起保存。模型列表复用 iPad 的选择逻辑。
- 任务和子代理共用权限范围。执行面板显示本机命令输出，权限设置可查看和撤销已保存的授权。
- 任务可在上游运行成功后启动。任务里可查看关联的定时安排。
- 终端可连接已保存的 SSH 和 VNC 主机。空间提供基础图片调整和视频裁剪。
- 设置增加技能目录、免认证的 MCP 连接器及本地诊断。

Floe Bridge 用户可以通过原有的更新入口升级。适用于 Apple 芯片和 macOS 15 或更高版本。

### English

- Sessions use the iPad message, run event and JSONL export formats. Updating adds the compatibility fields to existing session databases.
- Search, refresh and select multiple models in provider settings, then save them with the provider. The model list shares the iPad selection logic.
- Tasks and subagents share permission limits. The progress inspector shows live local command output, and settings can revoke saved grants.
- A scheduled task can start after its upstream run succeeds. View linked schedules from the task.
- Open saved SSH and VNC connections from the terminal. Space includes basic image adjustments and video trimming.
- Settings include the skill catalog, a credential-free MCP connector and local diagnostics.

Floe Bridge can upgrade through its existing update command. Requires Apple silicon and macOS 15 or later.
