# Floe Agent 1.11.20 for Mac

适用于 Apple 芯片 Mac。现有 Floe Bridge 和 Floe Agent 可通过「检查更新」升级。

- Agent 可查看当前工作区中的 PNG、JPEG、WebP 和 GIF。生成图片和 Computer Use 的窗口截图也可直接作为模型的视觉输入。
- 视觉主模型接收图片。使用纯文本主模型时，已配置的辅助视觉模型先查看图片，再把描述交给主模型。
- 包含上一版本的排队、插入、目标模式和会话响应修复。

## English

For Apple silicon Macs. Use Check for Updates in an existing Floe Bridge or Floe Agent installation.

- The agent can inspect PNG, JPEG, WebP, and GIF files in the current workspace. Generated images and Computer Use window captures can also reach the model as visual input.
- A vision-capable primary model receives images directly. For a text-only primary model, the configured vision helper inspects the images and returns a description.
- Includes the previous release’s changes to queueing, steering, Goals, and chat responsiveness.
