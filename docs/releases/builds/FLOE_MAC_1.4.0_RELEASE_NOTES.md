# Floe Agent 1.4.0 for Mac

## 简体中文

Mac 工作台开始共用 Floe 原版界面的源码，包括侧栏、设置入口、新建任务欢迎页、输入栏、消息气泡、Markdown 表格和代码块。Mac 用户仍可从 Bridge 窗口切换到 Agent，并沿用「检查更新」。

任务支持重命名、置顶和导出当前显示的消息。文件浏览器可把所选 UTF-8 文本插入新任务草稿，确认后再发送。

可以添加、编辑和切换多个模型服务商。工具箱接入原版 HTTP、WebSocket、MQTT 和串口助手。串口助手支持 TCP、UDP 和网络串口网关。

工具箱已有 22 个 Mac 入口。Agent 工具执行、图片和通用附件、定时与子代理、MCP、Skills 和跨设备任务同步仍在接入。

## English

The Mac workbench shares Floe’s original sidebar, settings entry, new-task welcome, composer, message bubbles, Markdown tables, and code blocks. Switch to Agent from the Bridge window and continue using Check for Updates.

Rename or pin tasks and export the displayed messages. Insert selected UTF-8 file contents into a new task draft so you can review them before sending.

Add, edit, and switch between model providers. The Toolbox uses the original HTTP, WebSocket, MQTT, and serial workbenches. The serial assistant supports TCP, UDP, and network serial gateways.

The Toolbox now has 22 Mac entries. Agent tool execution, image and general attachments, schedules, subagents, MCP, Skills, and cross-device task sync are still being integrated.
