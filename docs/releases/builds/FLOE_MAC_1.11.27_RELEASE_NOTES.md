# Floe Agent 1.11.27 for Mac

适用于 Apple 芯片和 macOS 15 或更新版本。可从 Floe Agent 或 Floe Bridge 检查更新。

- 普通聊天可在输入栏的思考强度菜单选择「自动」。每个会话记住自己的选择，新会话默认使用「快速」。
- 自动档按当前请求选择适合模型的强度。辅助模型失败、超时或当前模型没有可调档位时，使用模型默认设置。
- 同一轮任务中断后续跑，沿用原来的思考强度。新一轮使用当前设置。

## English

For Apple silicon Macs running macOS 15 or later. Use Check for Updates in Floe Agent or Floe Bridge.

- Choose Automatic from the reasoning menu in the Chat composer. Each conversation remembers its choice, and new chats start in Fast.
- Automatic chooses a supported effort for the current request. Floe uses the model default if the helper fails or times out, or the model has no adjustable effort.
- Resuming an interrupted task keeps the reasoning effort chosen for that turn. A new turn uses the current setting.
