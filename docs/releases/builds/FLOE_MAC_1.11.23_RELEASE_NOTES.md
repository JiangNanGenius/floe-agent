# Floe Agent 1.11.23 for Mac

适用于 Apple 芯片和 macOS 15 或更新版本。可从现有 Floe Agent 或 Floe Bridge 检查更新。

- 在「设置 → 权限 → Computer Use」可选择 Kimi CU 或 Floe 本机。选择会保存，并从下一次任务运行生效。升级后默认使用 Kimi CU。
- Floe 本机可读取和截取指定窗口，点击可访问控件、修改字段，并向支持的后台窗口发送按键和拖动。需要为 Floe Agent 授予辅助功能权限，截图和拖动还需要屏幕录制权限。

## English

For Apple silicon Macs running macOS 15 or later. Use Check for Updates in an existing Floe Agent or Floe Bridge installation.

- Choose Kimi CU or Floe Native in Settings → Permissions → Computer Use. The selection is saved and applies from the next run. Kimi CU remains the default after upgrading.
- Floe Native can inspect and capture a selected window, press accessible controls, edit fields, and send keys and drags to compatible background windows. Allow Accessibility for Floe Agent and Screen Recording for captures and drags.
