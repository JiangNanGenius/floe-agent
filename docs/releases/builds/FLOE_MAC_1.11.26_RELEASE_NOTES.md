# Floe Agent 1.11.26 for Mac

适用于 Apple 芯片和 macOS 15 或更新版本。可从 Floe Agent 或 Floe Bridge 检查更新。

- 新建任务、模式菜单和模型配置提示沿用 iPad 的控件和操作位置。窄窗下优先保留输入区。
- 从侧栏顶部或按 Command-Shift-F 打开任务搜索弹窗。搜索任务名称和消息正文，从结果直接跳到对应消息。
- 在模型供应商设置里刷新官方目录，查看来源和供应商数量。生图与视频模型在各自分组配置。
- 空间的工具箱增加快捷工具和功能说明。搜索支持工具用途，点击后打开对应的 Mac 工具。

## English

For Apple silicon Macs running macOS 15 or later. Use Check for Updates in Floe Agent or Floe Bridge.

- New tasks, the mode menu, and model setup use the same controls and placement as iPad. Narrow windows give priority to the composer.
- Open task search from the top of the sidebar or with Command-Shift-F. Search task titles and message text, then jump to a matching message.
- Refresh the official catalog in Model Providers and see its source and provider count. Configure image and video models in their own sections.
- The toolbox in Space has a quick tool shelf and descriptions. Search by what a tool does and open it from the results.
