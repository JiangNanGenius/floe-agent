# Floe Agent 1.10.9 for Mac

## 简体中文

- 在设置里选择新任务的默认审批方式，在输入栏单独调整当前任务。逐次询问、自动审批和完全访问都随任务保存。开启完全访问需要通过 Mac 身份验证。
- 可以单独选择审批模型。在项目文件的审批卡上可允许一次，或记住本任务、本项目对该文件的同一种操作。已记住的授权可在权限设置中撤销。

- 模型需要你补充信息时，直接在任务里回答。可以选择选项、填写文字或取消这组提问。回到任务后仍可查看提问和回答。
- 项目 Agent 和目标任务可以把资料查阅交给后台子任务。可在原任务里查看进度、取消单个子任务并查看结果。子任务只能查阅当前项目。
- 运行中可以编辑、调整顺序或移除排队消息，也可以将消息改为本轮引导。尚未被采用的引导可以放回队列。
- 输入栏可以选择思考强度。聊天按会话记住选择。支持返回思考内容的模型会在对话中显示可展开的思考记录。
- 重开项目任务后，可以从工具记录在 Finder 中定位生成或修改的文件。长对话可以一键回到最新消息。
- 模型目录刷新后保留已设置的能力和思考选项。手动添加的聊天模型默认启用工具调用，可以在模型设置中关闭。

## English

- Choose a default approval mode in Settings and change it for an individual task in the composer. Each task remembers Ask, Automatic or Full Access. Enabling Full Access requires Mac owner authentication.
- Choose a separate model for approval reviews. A project file approval can apply once or cover the same operation on that file in the current task or project. Revoke saved file permissions in Settings.

- Answer model questions in the task by selecting options or entering text, or cancel the request. Reopen the task to review questions and answers.
- Project Agent and Goal tasks can delegate research to background subtasks. View progress, cancel a single subtask and read its findings in the parent task. Subtasks have read-only access to the current project.
- Edit, reorder or remove queued messages during a run. Send a queued message as guidance for the current run, or return guidance to the queue before the run consumes it.
- Choose reasoning effort in the composer. Chat remembers the choice per conversation. Expand reasoning text in the thread when the model provides it.
- Reopen a project task and reveal a generated or edited file in Finder from its tool activity. Jump to the latest message in a long conversation.
- Refreshing the model catalog preserves saved capability overrides and reasoning preferences. Manually added chat models start with tool calling enabled and you can turn it off in model settings.
