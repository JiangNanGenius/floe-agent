# Floe Agent 1.11.1 for Mac

## 简体中文

- 首次打开即进入 Agent。新建会话就能开始工作，文件保存在各自的目录里。也可以选择已有项目，在它的原目录继续工作。手动切换到纯 Bridge 后，下次打开会记住选择。
- Agent 可以在 Mac 本机运行命令，返回输出和退出状态。普通任务默认在会话或项目范围内执行；访问范围外的文件时会请求审批。审批卡显示命令、执行范围和风险等级。完全访问使用当前 macOS 账户已获准的权限。
- 安装并授权 Kimi CU 后，可以让 Agent 在后台查看指定窗口、点击控件和填写文本。可在「设置 → 权限」中打开 Kimi CU。
- 空间可以浏览会话文件夹或已有项目。任务中心支持置顶、重命名、按标题或目标搜索，以及恢复归档任务。
- 现有 Floe Bridge 和 Floe Agent 用户可通过「检查更新」升级。

## English

- Floe opens in Agent mode on first launch. Start a conversation and its files stay in a dedicated folder, or choose an existing project to work in its directory. Floe remembers an explicit switch to Bridge mode.
- The Agent can run native Mac commands and return their output and exit status. Standard tasks run in the conversation or project folder. Access outside it requires approval. The approval card shows the command, scope and risk. Full Access uses the permissions already granted to your macOS account.
- Install and authorize Kimi CU to inspect a specific window, click controls and fill in text in the background. Open the companion from Settings → Permissions.
- Browse conversation folders and projects in Space. In Task Center, pin or rename a task, search titles and goals, and restore archived tasks.
- Existing Floe Bridge and Floe Agent users can upgrade with Check for Updates.
