# Floe Agent 1.3.0 for Mac

## 简体中文

从 Bridge 窗口切换到 Floe Agent 后，会打开新的 Mac 工作台。侧栏可在任务中心、会话和工具箱间切换。任务中心显示已保存的任务和执行状态，对话支持基础 Markdown 显示。可以选择本机文件夹，浏览、筛选并用快速查看或默认应用打开文件。工具箱目录可直接打开 Mac 已支持的工具。

本次发布工作台的第一版。Agent 执行工具、任务附件、定时与子代理、Skills、MCP 和跨设备任务同步仍在接入。Bridge 用户可以沿用「检查更新」。

## English

Switch from Bridge to Floe Agent to open the new Mac workbench. Use the sidebar to move between the task center, conversations, and the toolbox. The task center shows saved conversations and recorded run status. Chats display basic Markdown. Choose a local folder to browse or filter its contents, preview files with Quick Look, or open them in their default apps. Supported tools open directly from the toolbox catalog.

This is the first workbench release. Agent tools, task attachments, schedules, subagents, Skills, MCP, and cross-device task sync are still being integrated. Bridge users can continue to use Check for Updates.
