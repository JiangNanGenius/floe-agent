# Floe Agent 1.11.4 for Mac

## 简体中文

- 工作台沿用 iPad 的分栏、侧栏操作和输入栏控件。窄窗会把输入选项换行。设置在宽窗内并排显示分类和内容，窄窗可逐层返回。常用按钮保留紧凑字号，并扩大点击范围。
- 在会话中打开网页，浏览后可以回到原来的任务和草稿。
- 在任务文件栏或「空间 → 文件」打开 HTML，可直接预览生成的网页，使用同一目录中的样式、图片和脚本。需要联网的网页服务请在网页浏览器中打开。
- 聊天、计划和 Agent 可以在后台读取公开 HTTPS 网页的标题和正文，长页面可以继续读取。读取公开页面使用独立的匿名连接。
- 长消息可以展开编辑，支持换行、撤销、查找和继续编辑原草稿。点「完成」返回输入框，点「发送」提交。点击会话消息里的附件即可预览，也可以在访达中定位原件。
- 在 Agent 或目标任务中，可以让子代理独立执行分工。子代理使用父任务当前的工具权限，命令和文件操作沿用父任务的审批策略。展开「子代理」可查看各项进度、取消运行中的子任务、打开完整结果或失败原因。同一任务中的子代理可以相互发现和传递消息。重开父任务仍可查阅。
- 普通任务失败或中断后，可从已保存的进度继续，并保留原来的执行记录。
- 可以在当前会话中要求 Floe 新建独立任务。新任务默认有自己的文件夹，也可归到指定项目；可从会话中查找和读取其他任务的记录。
- 可在任务中调用已配置的生图和视频供应商。生成的文件归属当前工作区，可在执行记录中定位。视频支持查询进度和取消。辅助模型设置可选择是否允许 Agent 自主挑选生图模型。
- 从新任务右上角进入临时聊天，离开时清空；点「保留为会话」可以继续原来的对话。任务导出支持纯文本、Markdown 和包含工具记录的 JSONL。
- 「空间 → 文件」和任务文件栏支持新建文件夹、重命名、在工作区内移动文件或文件夹、制作普通文件的副本，以及移入系统废纸篓。可从「最近删除」放回文件。若 macOS 限制访问废纸篓，可以在访达中把文件拖回原文件夹。
- 在「设置 → 网页搜索」管理搜索供应商；配置后可在会话中调用。新增「用量统计」，可以查看各模型、供应商和会话的用量。
- 已安装 Floe Bridge 或 Floe Agent 的用户可通过「检查更新」升级。

## English

- The workbench follows the iPad layout with larger hit targets, compact Mac type and composer controls that wrap in narrow windows. Settings show categories beside their content in wide windows and use back navigation in narrow ones.
- Open a webpage from a conversation and return to the original task and draft.
- Open an HTML file in the task inspector or Space → Files to preview a generated website with stylesheets, images and scripts from its folder. Use the web browser for sites that need an internet connection.
- Chat, Plan and Agent can read public HTTPS pages in the background, retrieve their title and text, and continue reading long pages. Page retrieval uses an anonymous connection.
- Expand the message composer for multiline editing, undo and find. Done returns to the draft, and Send submits it. Click a message attachment to preview it or reveal the original in Finder.
- In Agent and Goal tasks, delegate work to independently executing subagents. Their commands and file operations use the parent task’s effective tools and approval policy. Expand Subagents to track progress, cancel a running child and open its full result or error. Sibling subagents can discover and message each other. The details remain available when you reopen the parent task.
- Continue an eligible failed or interrupted task from its saved history and keep the original execution record.
- Ask Floe to start a separate task in its own folder or in a specific project. Find and read other tasks from the current conversation.
- Generate images and videos from a task with your configured providers. Find generated files in the task workspace and execution history, check video progress or cancel a job. Auxiliary model settings let you choose whether the agent may select an image model.
- Start a temporary chat from New Task. Leaving clears it. Choose Keep as Saved Chat to continue it later. Export a saved task as plain text, Markdown or JSONL with its recorded tool activity.
- Create folders, move items within the workspace, rename items, duplicate files, and move items to the system Trash from Space or the task inspector. Restore files from Recently Deleted. If macOS restricts access to the Trash, open it in Finder and drag the file back to its original folder.
- Configure search providers in Settings → Web Search to use them in conversations. Usage shows totals by model, provider and conversation.
- Existing Floe Bridge and Floe Agent installations can upgrade with Check for Updates.
