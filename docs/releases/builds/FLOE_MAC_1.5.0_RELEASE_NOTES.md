# Floe Agent 1.5.0 for Mac

## 简体中文

工作台采用 Floe 原版的任务导航、会话输入区和工具箱目录。在对话旁打开工作区文件，在输入区直接切换已配置的模型。任务历史可以从侧栏搜索，工具箱可以按原版分类或名称查找。

新任务可选已授权的项目目录。给模型开启「支持图片输入」后，可以发送附加图片。普通文件以引用保存在任务中。文件栏支持多选、内联预览和文本另存副本。

工具箱接入扫描与文字识别，以及基于 Bonjour 的局域网服务发现。串口助手支持 macOS 已识别的 USB 串口设备。

Bridge 和 Agent 继续使用同一个安装包。应用记住主动选择的模式。已有 Bridge 可在菜单中检查更新，再切换到 Floe Agent。

本版开放对话模式。Agent 工具执行、跨设备任务同步和执行交接仍在接入。

## English

The workbench uses Floe's task navigation, composer layout, and Toolbox directory. Open workspace files beside a conversation and switch configured models from the composer. Search task history from the sidebar and find tools by name or category.

Choose an authorized project folder for a new task. Turn on Supports Image Input for a compatible model to send attached images. Other files are kept as references in the task. The file pane supports multiple selection, inline previews, and saving text edits as a copy.

The Toolbox adds scanning and text recognition, plus Bonjour service discovery on your local network. The serial assistant supports USB serial devices recognized by macOS.

Bridge and Agent use the same installer. Floe remembers the mode you select. Existing Bridge installations can check for updates from the menu and switch to Floe Agent.

Chat mode is available in this release. Agent tool execution, cross-device task sync, and handoff are still in development.
