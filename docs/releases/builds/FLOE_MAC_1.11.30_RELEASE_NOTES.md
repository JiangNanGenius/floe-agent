# Floe Agent 1.11.30 for Mac

适用于 Apple 芯片和 macOS 15 或更新版本。可从 Floe Agent 或 Floe Bridge 检查更新。

- 定时任务的「立即运行」会打开本次启动的会话。启动失败时保留定时任务面板，方便检查设置并重试。
- 模型供应商的账号行更容易点按。打开账号后可以查看和管理已选模型。
- Agent 的选择题直接显示在会话里，可在卡片上作答。需要审批的操作继续按任务权限处理。
- 修复自动审批把内部标识误判为凭据的问题。检测到疑似凭据时仍转为本机确认。

## English

For Apple silicon Macs running macOS 15 or later. Use Check for Updates in Floe Agent or Floe Bridge.

- Run Now opens the conversation for the run you just started. The schedule panel stays open if the run cannot start, so you can check its settings and retry.
- Provider rows have a larger click target. Open an account to view and manage its selected models.
- Answer Agent questions directly in the conversation. Actions that require approval continue to follow the task's permissions.
- Fixed automatic approval being blocked by internal request identifiers. Detected credentials still trigger local confirmation.
