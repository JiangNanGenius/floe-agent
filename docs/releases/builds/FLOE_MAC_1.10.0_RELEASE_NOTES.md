# Floe Agent 1.10.0 for Mac

## 简体中文

- Agent 可修改已选工作区内的现有 UTF-8 文本文件。审批前可以查看原文和替换文字。
- 修改前会核对原文件版本。文件已变动或原文匹配有歧义时会拒绝修改。成功后在同目录保留原版本。
- 原 Floe Bridge 可继续通过「检查更新」升级，再选择「切换到 Floe Agent」。

## English

- Agent can edit an existing UTF-8 text file in the selected workspace. Review the original and replacement text before approving.
- Floe checks the file revision before writing. Stale or ambiguous edits are rejected. Successful edits keep the previous version beside the updated file.
- Update existing Floe Bridge installations with Check for Updates, then choose Switch to Floe Agent.
