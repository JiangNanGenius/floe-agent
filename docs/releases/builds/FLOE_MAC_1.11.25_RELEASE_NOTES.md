# Floe Agent 1.11.25 for Mac

适用于 Apple 芯片和 macOS 15 或更新版本。可从 Floe Agent 或 Floe Bridge 检查更新。

- Agent 可以把指定的 Mac 窗口、任务浏览器视口和 shell 生成的截图送给视觉模型。纯文本主模型可通过已配置的辅助视觉模型获取解读。
- 浏览器截图提供快速文字识别预览，保留识别文字在截图中的位置。
- shell 只附带本次成功命令生成或更新的指定图片。重新打开任务时，可以查阅当时保留的截图。
- 空间支持批量移到废纸篓、撤销和恢复。定时计划可跳过下一次运行，手动运行后会打开对应任务。

## English

For Apple silicon Macs running macOS 15 or later. Use Check for Updates in Floe Agent or Floe Bridge.

- Agents can deliver selected Mac window captures, task-browser captures, and screenshots produced by shell commands to vision models. Text-only primary models can use a configured auxiliary vision model.
- Browser captures include a quick on-device text preview with the locations of recognized text.
- Shell commands attach only the declared image created or updated by a successful call. The retained screenshot can be viewed after reopening a task.
- Space supports batch Trash, undo, and restoration. Scheduled tasks can skip their next occurrence, and Run Now opens the launched task.
