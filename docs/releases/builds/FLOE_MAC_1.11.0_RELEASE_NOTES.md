# Floe Agent 1.11.0 for Mac

## 简体中文

- 在 Agent 侧边栏打开「创意模式」，可以在画布、生图和生视频之间切换。在「设置 → 模型」中分别配置图片和视频模型，也可以从已配置的供应商导入。
- 新建画布，添加文字，或从生成历史、访达中添加图片和视频。可以拖动素材、修改文字、按名称查找作品，并在下次启动后继续编辑。
- 画布与 iPad 共用文件格式。导出为 `.floeCanvas` 时会打包画布引用的素材；Mac 可以重新导入基础文字、图片和视频画布。
- 生图可按模型选择候选张数、参数和参考图。画布中的图片可直接用作生图参考或视频首帧。
- 提交视频生成任务后可查看状态或取消。重开应用会继续查询已提交的任务，完成后可播放、导出并添加到画布。原有生图历史和从任务添加图片的入口继续可用。

## English

- Open Creative in the Agent sidebar to switch between canvases, image generation and video generation. Configure image and video models in Settings → Models, or import a connection from a saved provider.
- Create a canvas and add text, generated media or files from Finder. Drag items, edit text, find a canvas by name and reopen it after relaunch.
- Canvas files use the iPad format. Exporting a `.floeCanvas` package includes its media. Mac can import basic canvases containing text, images and videos.
- Choose the number of image candidates, parameters and reference images supported by the selected model. Use an image on the canvas as a reference or the first frame of a video.
- Track or cancel video jobs. After relaunch, the app resumes checking submitted jobs. Play or export the result, or add it to a canvas. Existing image history and the image attachment workflow in tasks remain available.
