# Floe Agent 1.11.7 for Mac

## 简体中文

- 输入区共用 iPad 的模型菜单、排队和引导操作。发送时按草稿版本确认，等待期间重新输入的内容会保留。
- 任务中心与 iPad 共用任务行和批量选择控件，继续支持按消息定位、归档和恢复。
- 空间中的文件编辑和引用沿用 iPad 的文本识别规则，保存时保留 UTF-8 文件的原有字节顺序标记。
- 跟随最新消息时，输入区高度变化后仍能看到会话底部的审批操作。
- Floe Bridge 和 Floe Agent 都可通过「检查更新」升级。

## English

- The composer shares iPad's model menu, queued sends, and steering controls. Send completion preserves a draft retyped while the previous send was pending.
- Task Center shares iPad's history rows and selection controls, with message search, archiving, and restoration.
- Workspace editing and quoting use iPad's text rules, and saving preserves an existing UTF-8 byte order mark.
- When following the latest messages, approvals stay reachable as the composer changes height.
- Update from Floe Bridge or Floe Agent through Check for Updates.
