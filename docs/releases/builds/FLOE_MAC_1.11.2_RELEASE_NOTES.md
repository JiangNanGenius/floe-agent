# Floe Agent 1.11.2 for Mac

## 简体中文

- 在设置中可以直接找到模型账户、辅助模型和生图、生视频配置。通用设置增加运行中输入的偏好，可选择排队或引导当前任务。
- 从侧栏或任务中心搜索会话正文，可从匹配片段跳到原消息。会话文件夹在任务开始后仍然可以从输入栏打开。
- 可在任务运行期间调整后续操作的审批模式。权限设置集中显示 Agent 操作开关、Kimi CU 和系统授权入口，包括完全磁盘访问。
- 回复下方可以直接复制。右键自己的消息可以用作新草稿，也可以追加到已有草稿。
- 已安装 Floe Bridge 或 Floe Agent 的用户可以通过「检查更新」升级。

## English

- Open provider, auxiliary model, image and video settings directly. Choose whether input sent during a run joins the queue or steers the current task.
- Search conversation text from the sidebar or Task Center and jump from an excerpt to the original message. The conversation folder remains available in the composer after a task starts.
- Change the approval mode for subsequent actions during a run. The Permissions pane brings together Agent actions, Kimi CU and system permission controls, including a link to Full Disk Access.
- Copy a reply from its footer. Right-click your own message to reuse it as a draft or append it to an existing one.
- Existing Floe Bridge and Floe Agent users can upgrade with Check for Updates.
