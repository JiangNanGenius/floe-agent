# Floe Agent 1.11.6 for Mac

## 简体中文

- 会话共用 iPad 的消息时间线。回复、思考、工具结果和审批按执行顺序显示，重开任务时也沿用同一顺序。
- 打开任务先显示最新消息，可以继续加载更早的消息和工具记录。浏览历史或跳到搜索结果时，新回复到达会保留当前阅读位置。
- 在会话内使用 iPad 同一套查找栏，按上一个和下一个定位消息。退出查找时保留当前位置及输入框草稿。
- 供应商选择直接使用 iPad 的搜索、筛选和目录列表组件。
- Floe Bridge 和 Floe Agent 都可通过「检查更新」升级。

## English

- Conversations use the iPad transcript. Replies, reasoning, tool results, and approvals appear in execution order, including when a task is reopened.
- Tasks open at the latest messages. Load earlier messages and tool activity on demand. New replies preserve your reading position while you inspect history or a search result.
- Use the same conversation find bar as iPad to move between matches. Closing find keeps your place and composer draft.
- Choose model providers using the iPad catalog’s search, filters, and list.
- Update from Floe Bridge or Floe Agent through Check for Updates.
