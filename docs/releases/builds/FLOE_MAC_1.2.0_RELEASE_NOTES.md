# Floe for Mac 1.2.0

## 简体中文

Floe Bridge 用户可以从菜单栏选择「检查更新」，直接升级到 Floe for Mac。新版在同一个应用里提供 Bridge、原生 Floe 对话和工具箱。现有任务运行时，更新会等任务结束再安装。

原生对话使用 Floe 自研核心，支持自定义模型提供商和本地会话历史。工具箱包含浏览器、网络诊断、二维码、校验、文本和计时工具。部分工具仍在移植。支持运行 macOS 15 或更新系统的 Apple 芯片 Mac。

## English

Floe Bridge users can choose Check for Updates from the menu bar to upgrade directly to Floe for Mac. Bridge, native Floe conversations, and the Toolbox are available in one app. Updates wait for active work to finish before installing.

Native conversations use Floe’s own core with configurable model providers and local conversation history. The Toolbox includes a browser, network diagnostics, QR codes, checksums, text utilities, and timers. Some tools are still being ported. Requires a Mac with Apple silicon and macOS 15 or later.
