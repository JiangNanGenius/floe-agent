# Floe Agent 1.10.3 for Mac

## 简体中文

- Mac 和 iPad 共用本地对话上下文及草稿格式。重开任务后可续用已保存的上下文摘要和工具结果，完整对话仍可查看。
- 未发送的消息和附件按任务保存。旧 Mac 草稿会自动读入新版格式，应用确认接收任务后才清除已发送的草稿。
- 可在对话中读取带文字层的 PDF 和 Word `.docx` 附件。文件变动、没有可读文字或超出读取范围时会提示用户。
- Floe Bridge 和 Floe Agent 可以通过「检查更新」升级。

## English

- Mac and iPad share the local conversation context and draft formats. Reopened tasks can reuse saved summaries and tool results while keeping the complete conversation available.
- Unsent messages and attachments are saved per task. Older Mac drafts are read into the shared format, and a submitted draft is cleared after the app accepts the task.
- Chat can read text-layer PDFs and Word `.docx` attachments. The app reports changed files or text it cannot extract within the reading limit.
- Existing Floe Bridge and Floe Agent installations can use Check for Updates.
