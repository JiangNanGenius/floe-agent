# Floe Agent 1.10.2 for Mac

## 简体中文

- 纯 Bridge 模式只运行 Bridge。切换到 Floe Agent 后才启动工作台，工具箱在打开时加载。
- 返回纯 Bridge 模式会关闭 Agent 工作台和工具箱。进行中的 Agent 操作、未保存的文件修改和待发送附件会阻止切换，已配对的设备可以继续连接。
- 在 Floe Agent 的「设置」中，Floe Bridge 有独立的标签页，用于管理配对、存储和权限。已安装的 Floe Bridge 和 Floe Agent 可以使用「检查更新」。

## English

- Bridge-only mode runs Bridge services. The Agent workspace starts when you switch to Floe Agent, and Toolbox loads when opened.
- Returning to Bridge-only mode closes the Agent workspace and Toolbox. Active Agent operations, unsaved file edits, and staged attachments keep the workspace open. Paired devices can stay connected.
- Floe Agent Settings includes a dedicated Floe Bridge tab for pairing, storage, and permissions. Existing installations can use Check for Updates.
