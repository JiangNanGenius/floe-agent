# Floe Agent 1.10.7 for Mac

## 简体中文

- 工作台侧栏固定常用入口，项目名称显示在任务标题下方。新任务会用首条消息生成简短标题，重开 App 会恢复窗口的位置和大小。
- 在「空间」切换已添加的项目文件夹。宽窗口可以拖动右侧文件栏，窄窗口打开文件后可点「返回任务」。文件列表支持双击打开、拖入文件和快捷筛选。
- ⌘F 查找当前页面，⇧⌘F 查找任务标题，⌥⌘0 显示或隐藏任务的文件栏。空间内的工具箱按类别排列，可直接搜索。
- 切到空间时继续加载原任务。正在执行的任务会暂停附件编辑，切换服务商后只显示当前配置的连接测试结果。

## English

- Keep common actions at the top of the sidebar and see the project name beneath the task title. New tasks get a short title based on the first message. Reopening the app restores the workbench window size and position.
- Switch between added project folders in Space. Drag to resize the file pane in a wide window. Use Back to Task after opening Files in a narrow window. Double-click to open files, drag in files to import them, and filter the current folder.
- Press ⌘F to search the current view, ⇧⌘F to find task titles, or ⌥⌘0 to toggle the task’s file pane. The Toolbox in Space lists tools by category and supports search.
- Task history continues loading when you open Space. Attachment editing pauses while a task is running. Connection test results stay with the provider configuration being edited.
