# Floe Agent 1.11.18 for Mac

适用于 Apple 芯片 Mac。现有 Floe Bridge 和 Floe Agent 可通过「检查更新」升级。

- 修复多会话运行时，新建和切换会话可能卡顿的问题。文件面板按需加载文件夹。
- 改善长文本粘贴和编辑的响应。输入框内部滚动，草稿保留完整文本。
- 多阶段任务流式输出时，正文按各阶段显示，已经出现的段落不会在末尾重复。

## English

For Apple silicon Macs. Use Check for Updates in an existing Floe Bridge or Floe Agent installation.

- Improve responsiveness when creating or switching tasks while other conversations are running. The Files panel loads folders on demand.
- Improve responsiveness when pasting and editing long text. The composer scrolls internally and retains the full draft.
- Keep streamed text next to the matching tool steps during multistage tasks, with each paragraph shown once.
