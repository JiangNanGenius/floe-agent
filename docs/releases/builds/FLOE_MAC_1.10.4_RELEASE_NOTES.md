# Floe Agent 1.10.4 for Mac

## 简体中文

- 设置沿用 iPad 的分类布局。选择服务商可进入编辑，按 `⌘,` 打开设置，按 `⌘N` 新建任务，按 `⌘F` 查找任务。
- 在对话里展开工具执行记录并处理审批。计划和目标显示在对话上方，模型、项目和模式在输入框下方。
- 模型可以在已授权的工作区内查找文件和文字、读取文档。模型设置支持上下文和输出上限，重新打开任务时会优先恢复上次使用的模型。
- 模型修改工作区文件时逐项审批，可查看原文和替换内容。权限设置可将模型的工作区访问限制为只读。
- 生图工作台支持配置服务商和模型，生成的图片保存在本机，可查阅历史并另存。
- 可把失败任务中的提示词放回输入框编辑重发。现有 Floe Bridge 和 Floe Agent 都可通过「检查更新」升级。

## English

- Settings follow the iPad category layout. Select a provider to edit it. Use `⌘,` for Settings, `⌘N` for a new task, and `⌘F` to find tasks.
- Expand tool activity and handle approvals in the conversation. Plans and goals appear above it, and the model, project, and mode controls sit below the prompt field.
- Models can find files and text and read documents in an authorized workspace. Model settings support context and output limits, and a reopened task restores its last model when available.
- Each workspace edit proposed by the model requires approval. Review the original and replacement text before deciding, or limit model access to read-only in Permissions.
- Set up an image provider and model in the image workbench. Generated images are saved locally and can be reopened or exported.
- Bring a failed run's prompt back to the composer to edit and send again. Use Check for Updates in existing Floe Bridge or Floe Agent installations to upgrade.
