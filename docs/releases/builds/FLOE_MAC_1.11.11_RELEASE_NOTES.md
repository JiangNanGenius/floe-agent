# Floe Agent 1.11.11 for Mac

## 简体中文

- 重开意外中断的任务时，可以从原模型请求继续，或重新审核尚未执行的审批。执行结果无法确认时，任务显示「待核对」。
- 目标模式保留每轮验收证据，并按已确认的进度、剩余预算和停止条件决定是否继续。
- Agent 可以在任务文件夹内创建目录、写入文件、追加文本和应用单文件补丁。审批与已保存的文件记录跟随任务。
- 从任务菜单或消息里的链接打开任务浏览器。Agent 和用户可在同一任务的标签页上交接，浏览器里的下载可以保存到任务文件夹。
- 创意工作台可以把 iPad 画布备份导入为独立副本。在 Mac 编辑文字、素材和连线后，可以导出到 iPad 继续使用。导入的画笔笔迹和锁定内容会保留。
- 生图和视频结果可以加入当前画布，也可以从任务进入创意工作台后保存到该任务的文件夹。
- Floe Bridge 和 Floe Agent 都可通过「检查更新」升级。

## English

- Reopen an interrupted task to continue the original model request or review an approval that had yet to execute. The task marks uncertain results for review.
- Goal mode keeps acceptance evidence for each round and uses confirmed progress, the remaining budget, and stop conditions to decide whether to continue.
- The Agent can create directories, write files, append text, and apply single-file patches in the task folder. Approval and saved-file records stay with the task.
- Open the task browser from the Task menu or from a link in a conversation. The Agent and user can hand off control of the same task tabs, and browser downloads can be saved in the task folder.
- Import an iPad canvas backup as an independent copy. Edit text, media, and connectors on Mac, then export the canvas to reopen it on iPad. Imported Pencil strokes and locked content are preserved.
- Add generated images and video to the current canvas, or open the creative workbench from a task to save them to that task’s folder.
- Update from Floe Bridge or Floe Agent through Check for Updates.
