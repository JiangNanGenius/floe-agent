# Floe Agent 1.10.8 for Mac

## 简体中文

- 调小桌面工作台的字号、工具按钮和侧栏行高。消息与输入区左右对齐，输入栏随窗口宽度换行。
- 点击输入栏当前模式，按 iPad 相同的顺序选择 Agent、聊天、计划或目标。模型菜单按服务商分组。首次使用可以在新任务页配置模型。计划和 Agent 需要项目时，可以在输入栏选择文件夹。
- 项目聊天支持列目录、搜索和读取文本。计划收起后可在原任务重新打开，确认后执行。目标支持逐行填写验收标准，可从模式菜单编辑已有目标，也可在目标卡片上暂停、继续和确认验收。
- 任务运行中可选择「队列」或「引导」，然后按 ⌘Return 发送。引导补充当前运行，队列里的消息在当前运行成功结束后开始下一轮。
- 与 iOS 1.8.57（378）共用任务执行逻辑。工具重复返回同一结果时，Agent 会停止这条尝试。如果模型提出另一种可用方法，Agent 会在原任务中继续执行。云模型连续两次无响应时会结束本次尝试并显示错误。
- 在任务中心按 ⌘F 可直接搜索当前或已归档的任务。

## English

- The desktop workbench uses smaller type, controls and sidebar rows. Messages and the composer share a reading column, and the composer adapts to the available width.
- Open the current mode in the composer to choose Agent, Chat, Plan or Goal in the same menu as on iPad. Models are grouped by provider. Set up a model from a new task, or choose a project folder when Plan or Agent needs one.
- Project chats can list folders, search files and read text. Reopen a collapsed plan and confirm it in the same task. Enter one success criterion per line. Edit an existing goal from the mode menu, or pause, continue and confirm completion from its card.
- While a task is running, choose Queue or Steer and press ⌘Return. Steering adds guidance to that run. Queued messages start a new turn after it finishes successfully.
- Mac now shares the task runtime from iOS 1.8.57 (378). Repeated calls with unchanged results stop. If the model proposes a different available approach, the agent continues within the same task. Two consecutive silent cloud attempts end with an error.
- Press ⌘F in Task Center to search the current or archived task list.
