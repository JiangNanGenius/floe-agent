# Floe Agent 1.11.21 for Mac

适用于 Apple 芯片 Mac。现有 Floe Bridge 和 Floe Agent 可通过「检查更新」升级。

- 运行中插入的引导，以及从排队转为引导的消息，生效后会以你发送的消息显示在对话里。
- 同一步收到多条引导时，按接收顺序显示在前后两段回复之间，并保留原发送时间。重新打开任务也能看到这些消息。

## English

For Apple silicon Macs. Use Check for Updates in an existing Floe Bridge or Floe Agent installation.

- Steering messages, including messages moved from the queue, appear as your messages once the agent receives them.
- Multiple steering messages at the same step appear between replies in the order the agent received them. Their original send times remain visible when you reopen the task.
