# Floe Agent 1.11.9 for Mac

## 简体中文

- App 意外退出时，如果任务停在等待回答的位置，重开任务并答复后可点「继续任务」。原模型会从原来的运行接着做，已经完成的工具操作会保留在记录里。
- Agent 可以把工作区里的文件保存为当前任务的产出。展开前的执行记录也会显示产出文件，点开即可快速查看或分享。之后编辑工作区原件，已保存的版本仍可查看。
- 执行记录会保留每次尝试的文件回执。后续重试失败时，仍能在原任务里找到先前成功交付的文件。
- Floe Bridge 和 Floe Agent 都可通过「检查更新」升级。

## English

- If Floe quits while a task is waiting for an answer, reopen the task, submit the answer, and choose Continue Task. The original model picks up the same run with its completed tool steps intact.
- The agent can publish a workspace file to the current task. Published files stay visible when execution details are collapsed and can be previewed or shared. They retain the saved version even if the workspace original changes.
- Execution history retains file receipts across attempts, so a successful earlier delivery stays visible if a later retry fails.
- Update from Floe Bridge or Floe Agent through Check for Updates.
