# Floe Agent 1.11.29 for Mac

适用于 Apple 芯片和 macOS 15 或更新版本。可从 Floe Agent 或 Floe Bridge 检查更新。

- 配对设备可以同步会话里的原始附件和工具结果摘要。在 Mac 上可为每台设备、每个会话单独开启附件共享。
- 两台设备都开启「同步重命名和删除」后，可同步已确认版本的文件改名和删除。同步删除的文件可从工作区的 `Floe Sync Conflicts/Removed` 找回。
- 修复带亚毫秒时间戳的消息重复接收时误报冲突的问题。

## English

For Apple silicon Macs running macOS 15 or later. Use Check for Updates in Floe Agent or Floe Bridge.

- Paired devices can sync original conversation attachments and tool result summaries. On Mac, attachment sharing is enabled separately for each conversation and device.
- Enable Sync Renames and Deletions on both devices to sync changes to files that still match the last confirmed version. Recover synced deletions from `Floe Sync Conflicts/Removed` in the workspace.
- Fixed false conflicts when receiving messages with sub-millisecond timestamps again.
