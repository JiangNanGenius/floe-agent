# Floe Agent 1.11.16 for Mac

适用于 Apple 芯片 Mac。现有 Floe Bridge 和 Floe Agent 可通过「检查更新」升级。

- 网站数据默认随任务浏览会话结束而清除。可以记住单个站点的登录状态，并从设置查看和清除它保存的数据。
- 连接器可管理多个 MCP 服务，支持 Bearer 和自定义请求头。已记住的任务、项目和会话工具授权集中在权限设置，可逐条撤销。
- 记忆和个性化沿用 iPad 的存储与审核。任务可检索长期记忆，经确认后可写入。
- iCloud 配置页可手动上传和下载供应商、模型、默认模型选择及兼容偏好。供应商密钥通过独立授权的 iCloud 钥匙串传输。设备配对继续用于会话互传。
- 数据管理显示 Floe 占用和可清理的临时目录。清理前会列出可处理的范围。
- 本地模型沿用 iPad 的 MLX 引擎和目录。从设置下载模型后可在普通任务中选用。需要 macOS 15.4 或更新版本。
- 聊天输入框提供听写和连续语音对话。语音对话保存在当前会话，朗读完成后自动恢复收音。
- 创意工作台支持多轨时间线、SRT 和 WebVTT 字幕、调色和视频导出。画布提供更多节点编辑，沿用现有画布包格式。

## English

For Apple silicon Macs. Use Check for Updates in an existing Floe Bridge or Floe Agent installation.

- Task browsing clears website data when the session ends by default. Remember a site's login and manage its retained data in Settings.
- Connect multiple MCP servers using Bearer tokens or custom headers. Review and revoke remembered task, project, and session approvals in Permissions.
- Memory and personalization share iPad storage and review behavior. Tasks can look up saved memories and request approval to save new ones.
- Upload and download providers, models, default selections, and supported preferences from iCloud Configuration. Provider keys use separately authorized iCloud Keychain access. Paired devices can exchange conversation history.
- Storage settings show Floe's disk usage and the eligible temporary directories before cleanup.
- Download an on-device model and select it for ordinary tasks. Mac uses the shared iPad MLX engine and model catalog. This feature requires macOS 15.4 or later.
- Dictate into the composer or start a voice conversation. Turns save to the current conversation, and listening resumes after each reply is read aloud.
- Edit a multitrack timeline, import and export SRT or WebVTT subtitles, adjust color, and export video. The canvas editor supports more node edits in the existing canvas package format.
