# Floe Agent 1.11.8 for Mac

## 简体中文

- 在侧边栏和「空间」管理项目。可重命名、在访达显示原文件夹，或打开项目专属的任务列表并搜索消息。
- App 意外退出后，重新打开任务可看到原来的待回答卡和已保存的草稿。提交后，回答会保存在原任务的记录里。
- 会话浏览器重新打开时恢复上次浏览的网页地址。浏览器沿用 iPad 的文件下载服务，支持从当前页面保存 PDF 和图片，可查看进度和取消。
- Floe Bridge 和 Floe Agent 都可通过「检查更新」升级。

## English

- Manage projects from the sidebar or Space. Rename a project, reveal its folder in Finder, or open and search its task list.
- Reopening a task after an unexpected quit restores its pending question and saved draft. Submitted answers are saved in the original task.
- Reopening a task browser restores its last page address. The browser uses iPad’s download service to save PDFs and images from the current page, with progress and cancellation.
- Update from Floe Bridge or Floe Agent through Check for Updates.
