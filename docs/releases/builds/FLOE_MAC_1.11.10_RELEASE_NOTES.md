# Floe Agent 1.11.10 for Mac

## 简体中文

- 目标任务在等待回答时意外退出，可以重开任务、提交答案，再点「继续目标」。原模型从同一轮接着处理，已保存的进度和文件回执一并带回。
- 目标卡显示已完成的步骤、验收条件和证据。目标空闲时可继续，也可以从菜单暂停。
- 待审批操作显示在输入框上方，查看长执行记录时也能直接批准或拒绝。
- 已确认的计划启动执行时，确认记录会及时关联到对应的执行轮。
- Floe Bridge 和 Floe Agent 都可通过「检查更新」升级。

## English

- If Floe quits while a Goal task is waiting for an answer, reopen the task, submit the answer, and choose Continue Goal. The original model resumes the same round with its saved progress and file receipts.
- The Goal card shows completed steps, acceptance criteria, and evidence. An idle Goal can continue from the card or pause from its menu.
- The active approval card stays above the composer while you read the execution history.
- A confirmed plan’s message is updated as soon as its execution starts.
- Update from Floe Bridge or Floe Agent through Check for Updates.
