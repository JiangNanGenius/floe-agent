# Floe Agent 1.9.0 for Mac

## 简体中文

- 在模型设置点 iCloud 图标，可下载同一 iCloud 账户的供应商和模型配置，也可上传已保存的配置。API 密钥保存在各设备自己的钥匙串。
- 随消息附加的小型纯文本和 Markdown 文件可以在校验通过后供模型读取。
- 在文件页或工具箱也能看到当前任务的状态。点状态可回到任务查看回复或处理审批。
- 原 Floe Bridge 可继续通过「检查更新」升级，再选择「切换到 Floe Agent」。

## English

- Use the iCloud button in Model Settings to download provider and model configurations from the same iCloud account or upload a saved configuration. API keys stay in each device’s Keychain.
- The model can read small plain-text and Markdown files attached to the current message after verifying them.
- See the current task’s status while using Files or Toolbox. Click the status to return to the task and review replies or approvals.
- Update existing Floe Bridge installations with Check for Updates, then choose Switch to Floe Agent.
