# Floe Agent 1.10.6 for Mac

## 简体中文

- 侧栏按项目归纳任务。点项目名称或旁边的「＋」，即可在该项目里新建任务。已有任务可以在后台继续运行。
- 输入区共用 iPad 的附件样式和窄栏布局，窄窗口会把控件移到输入框下方。计划和审批也使用两端共用的界面，确认计划后直接启动执行。
- 「空间」默认打开文件管理，可在页头或 Mac 菜单栏切换到工具箱。对话右侧的文件栏可以打开预览，再返回文件列表。
- 工具箱只显示 Mac 可用的工具。
- 现有 Floe Bridge 和 Floe Agent 可通过「检查更新」升级。

## English

- The sidebar groups tasks by project. Click the project name or its plus button to start a task there. Existing tasks can keep running in the background.
- The composer shares the iPad attachment controls and moves its controls below the text field in narrow panes. Mac and iPad share the plan and approval views. Confirming a plan starts execution.
- Space opens the file manager. Switch to Toolbox from the page header or the macOS Space menu. Open a file preview in the conversation’s file pane and return to the list from there.
- The Toolbox lists tools available on Mac.
- Use Check for Updates in an existing Floe Bridge or Floe Agent installation to upgrade.
