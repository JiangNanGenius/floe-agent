# Floe Agent 1.11.12 for Mac

## 简体中文

- 在新任务或已有会话的输入栏点击审批模式，会像 iPad 一样打开任务权限弹窗。选择完成后回到当前会话，草稿留在原处。
- Floe Agent 和 Floe Bridge 默认在后台检查更新。发现新版后由你确认安装。可在「设置 → 通用」关闭自动检查，也可以随时手动检查更新。

## English

- Click the approval mode in the composer to open the task permissions sheet, just like on iPad. Close it to return to the current conversation with your draft intact.
- Floe Agent and Floe Bridge check for updates in the background by default. You choose when to install an available update. Turn automatic checks off in Settings → General, or check for updates manually at any time.
