# Floe Agent 1.6.0 for Mac

## 简体中文

- 输入区可切换聊天、Agent、计划和目标模式。已有模型可在设置中启用「支持工具调用」。
- 在已授权的项目文件夹中，Agent 可以列出目录、读取文本和创建文本文件。创建前可查看文件路径与内容，并选择允许一次或拒绝。
- 可以查看、接受并执行保存的计划。目标保存验收条件、运行状态和工具执行记录，从任务历史重新打开后仍可查看。
- 工具箱新增本机交互终端和 VNC 远程桌面。终端从选择的目录启动。VNC 支持手动连接并使用键盘和鼠标操作。
- 原 Floe Bridge 通过「检查更新」升级。在 Bridge 窗口选择「切换到 Floe Agent」，即可打开新版工作台。

## English

- Switch between Chat, Agent, Plan, and Goal in the composer. Enable Supports Tool Calling in Settings for a compatible model.
- In an authorized project folder, Agent can list directories, read text, and create text files. Review the destination and contents before allowing the operation once or declining it.
- Review, accept, and run saved plans. Goals retain acceptance criteria, run status, and tool evidence when reopened from task history.
- The Toolbox adds an interactive local terminal and VNC remote desktop. Choose a starting folder for the terminal. Connect manually to a VNC server and use your keyboard and mouse to control the desktop.
- Existing Floe Bridge installations can use Check for Updates. Choose Switch to Floe Agent in the Bridge window to open the updated workbench.
