## Linux 环境升级与虚拟屏幕

启动旧版共享 Linux 时，App 会在启动前询问是否升级。用户可以选择「升级 Linux 环境」或「本次继续使用当前版本」。也可以在「设置 → 执行环境」主动升级，终端的虚拟屏幕在需要新组件时也提供入口。升级保留工作区，以及可用于恢复的旧系统盘。新 Linux 系统中需要重新安装原先自行安装的软件。切换成功后会清理已无其他环境引用的旧安装镜像。[本版更新说明](../notes/RELEASE_NOTES_1.8.31_BUILD_352.md)

在保留旧数据的 iPad 模拟器中，实测了启动旧版和升级两种选择。原先升级一块逻辑大小为 16 GiB 的稀疏磁盘时，App 要求超过 32 GiB 可用空间。修复后，升级按实际复制方式估算额外空间。模拟器从 v1 成功切换到 v8，旧可写盘的文件标识及已分配字节数保持一致，App 清理了一份已替换的安装镜像。原终端自动重新连接，虚拟屏幕实际显示了新客机中的 xterm 提示符。

在执行环境设置中可以预设图形内存，启动后可查看图形设备实际获得的额度。已验证设置保存与读回、模拟器界面和虚拟屏幕。本次未在 M4 实机测量 GPU 性能或视频硬件解码。

## 云端双向语音

对语音输入使用的 WebSocket 通路连续制造两次断线后，客户端重新连接并补发尚未确认的语音。测试端核对了 64,000 字节音频，最终转写仅提交一次。会议录音链路另测了重连和离线时结束录音的行为。测试使用受控服务端，真实云账号和实体麦克风的表现仍待实测。
