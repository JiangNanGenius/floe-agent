# Floe Agent 1.11.19 for Mac

适用于 Apple 芯片 Mac。现有 Floe Bridge 和 Floe Agent 可通过「检查更新」升级。

- 排队和待插入的消息显示在输入框正上方。可在消息菜单中编辑、重排、删除，也可以把尚未插入的消息转回队列。
- 运行中可为当前会话选择排队或插入。停止和发送按钮沿用 iPad 的顺序。
- 从输入框的模式菜单选择「目标」，在原输入框里描述要完成的事。模型根据执行结果判断进度和阻塞。删除目标会停止后续推进，保留本轮执行、会话和文件。
- 包含 1.11.18 的卡顿、长文本粘贴和多阶段正文顺序修复。

## English

For Apple silicon Macs. Use Check for Updates in an existing Floe Bridge or Floe Agent installation.

- Queued messages and messages waiting to be inserted appear immediately above the composer. Open a message menu to edit, move, or remove it, or return a pending insertion to the queue.
- Choose queueing or insertion for the current conversation while a task runs. Stop and Send follow the iPad order.
- Choose Goal from the composer’s mode menu and describe the outcome in the same input field. The model checks results for progress and blockers. Deleting a goal stops future advancement and keeps the current round, conversation, and files.
- Includes the responsiveness, long-text paste, and multistage streaming fixes from 1.11.18.
