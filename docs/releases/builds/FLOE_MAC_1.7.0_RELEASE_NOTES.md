# Floe Agent 1.7.0 for Mac

## 简体中文

- 在模型设置选择供应商预设或配置自定义接口。支持模型列表的服务可自动拉取或手动刷新，也可以手填模型 ID。
- 在任务中心归档、恢复和删除任务。删除任务需要确认。
- 未发送的文本按任务保存在本机。重新打开工作台可回到上次打开的任务。
- 原 Floe Bridge 可通过「检查更新」升级，再选择「切换到 Floe Agent」。

## English

- Choose a provider preset or configure a custom endpoint in Model Settings. When the service provides a model catalog, Floe can fetch it automatically or refresh it on demand. You can also enter a model ID manually.
- Archive, restore, and delete tasks in Task Center. Deleting a task requires confirmation.
- Unsent text is saved locally for each task. Reopening the workbench can restore the last opened task.
- Update existing Floe Bridge installations with Check for Updates, then choose Switch to Floe Agent.
