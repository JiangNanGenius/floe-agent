# Floe Agent 1.11.5 for Mac

## 简体中文

- 模型请求失败时，会话会显示可处理的原因。火山方舟 Agent Plan 套餐失效、模型或接口找不到、额度受限时，可以直接打开模型设置。原消息保留，重新打开任务仍可查看原因。
- 修正 OpenAI 和 Anthropic 的工具名兼容问题。新增供应商和为某个任务切换模型时，保留用户设置的默认模型。
- 「模型供应商」可以按名称、别名、域名或模型搜索，并刷新与 iPad 共用的签名目录。支持列出模型的账号可以拉取自己的模型。网页搜索的供应商也可以搜索和检查目录更新。
- 多个任务运行时，可以继续新建会话。流式回复和草稿分别归属各自的会话，后台回复减少了对当前窗口的刷新。任务中心支持选择多项后归档或恢复。
- 任务运行中可随引导或排队消息发送附件。可以从已添加的图片中提取文字并插入草稿。
- 浏览器和工作区文件集中在任务右上角的检查器菜单。会话中的链接可打开内置浏览器，返回时保留原任务和草稿。主侧栏按 iPad 工作台排列。
- Floe Bridge 和 Floe Agent 都可通过「检查更新」升级。

## English

- When a model request fails, the task shows the cause and links to model settings. This includes an inactive Volcengine Agent Plan, an unavailable model or endpoint, and quota limits. The original message and error remain available after reopening the task.
- Corrected function names sent to OpenAI and Anthropic. Adding a provider or choosing a model for one task preserves the user's default model.
- Search model providers by name, alias, domain, or model and refresh the same signed catalog used on iPad. Accounts with a model-listing endpoint can fetch their own models. Web search providers also have a searchable catalog with refresh.
- Start a new conversation while other tasks are running. Drafts and streaming replies stay with their own conversations, and background replies update the visible window less often. Select multiple tasks to archive or restore them in Task Center.
- Send attachments with guidance or queued messages while a task is running. Extract text from an attached image and insert it into the draft.
- Find the browser and workspace files in the task inspector menu. Open conversation links in the built-in browser and return to the original task and draft. The main sidebar follows the iPad workbench.
- Update from Floe Bridge or Floe Agent through Check for Updates.
