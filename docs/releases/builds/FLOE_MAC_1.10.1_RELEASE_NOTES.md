# Floe Agent 1.10.1 for Mac

## 简体中文

- 切换到 Floe Agent 后，退出再启动会直接打开 Agent 工作台。
- 在 Floe Agent 的「设置」中可管理模型，或进入「Floe Bridge」管理设备配对、存储和权限。工作台「服务」中的 Floe Bridge 入口会直接打开该设置页。
- 已安装 Floe Bridge 或 Floe Agent 的用户可以使用「检查更新」。

## English

- After you switch to Floe Agent, launching the app again opens the Agent workspace.
- Floe Agent Settings includes model configuration and a Floe Bridge tab for pairing, storage, and permissions. The workspace Services shortcut opens that tab directly.
- Existing Floe Bridge and Floe Agent installations can use Check for Updates.
