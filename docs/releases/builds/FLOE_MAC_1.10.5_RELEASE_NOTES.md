# Floe Agent 1.10.5 for Mac

## 简体中文

- 运行中的任务可以留在后台。切换任务后，审批、进度和停止操作仍对应各自的任务。
- 目标可以暂停、保留已有的验收证据并继续下一轮，满足验收标准后可以确认结果。
- 按 `⌘F` 查找当前对话，包括尚未载入的早期消息。在其他页面按 `⌘F` 可查找任务。按 `⌘.` 停止当前任务。
- 可把任务移到项目或移回个人任务。项目任务可以直接打开对应的工作区文件。
- 可把 Finder 文件拖进输入框。在文件编辑器中按 `⌘S` 保存，按 `⇧⌘S` 另存副本。文件被其他应用改动时会保留编辑内容并提示冲突。
- 从「工具」或输入框的附件菜单打开生图。可把生成的图片附加到当前任务，也可另存。生图配置集中在模型设置。
- 模型设置可以测试服务商连接，也可配置本机和局域网的模型服务。返回任务时恢复各自的对话、执行、计划或目标模式。
- 现有 Floe Bridge 和 Floe Agent 可通过「检查更新」升级。

## English

- Leave tasks running in the background. Approvals, progress, and Stop stay with the right task as you switch.
- Pause a goal, keep its verification evidence when you start another round, and confirm the results when they meet the acceptance criteria.
- Use `⌘F` to search the current conversation, including older messages. Elsewhere, `⌘F` finds tasks. Use `⌘.` to stop the current task.
- Move tasks into projects or back to personal tasks. Open the project folder directly from its conversation.
- Drag Finder files into the composer. In the file editor, use `⌘S` to save and `⇧⌘S` to save a copy. If another app has changed the file, Floe keeps your edits and reports the conflict.
- Open image generation from Tools or the composer’s attachment menu. Attach the result to your task or save it. Image generation is configured in Models.
- Test provider connections and configure local or private-network model servers from Models. Each task remembers its Chat, Agent, Plan, or Goal mode.
- Use Check for Updates in an existing Floe Bridge or Floe Agent installation to upgrade.
