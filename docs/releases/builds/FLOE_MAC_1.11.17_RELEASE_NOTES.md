# Floe Agent 1.11.17 for Mac

适用于 Apple 芯片 Mac。现有 Floe Bridge 和 Floe Agent 可通过「检查更新」升级。

- 支持增量同步的配对设备可分批接收文本会话。中断后再次接收会从已保存的位置继续，适合长会话。
- 在两台设备分别追加同一会话后，可以交换新增消息。重复接收会自动去重。
- 设备同步默认关闭。可按设备选择会话，也可撤回单独的会话共享。已接收的历史仍可查看。

## English

For Apple silicon Macs. Use Check for Updates in an existing Floe Bridge or Floe Agent installation.

- Paired devices that support incremental sync can receive text conversations in batches. If a transfer is interrupted, the next receive resumes from the saved position.
- Add messages to the same conversation on either device and exchange those additions. Receiving the same messages again keeps one copy.
- Device sync is off by default. Choose which conversations to share with each device and revoke sharing individually. Previously received history stays available.
