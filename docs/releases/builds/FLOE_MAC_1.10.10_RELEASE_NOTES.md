# Floe Agent 1.10.10 for Mac

## 简体中文

- 在“设置 → 模型”中为同一供应商添加多个模型。可以先保存账号，随后从供应商目录选择模型或手动输入模型 ID。移除最后一个模型也会保留账号。任务输入栏按供应商列出可选模型。
- 在辅助模型设置中选择通用辅助模型、图片理解模型和审批模型。通用辅助模型可以给新任务命名，并为支持自动思考强度的模型选择强度。手动命名的任务会保留自己的标题。
- 文本模型收到图片附件时，可以由指定的图片理解模型读取，再把描述交给任务模型。支持图片的任务模型直接读取附件。
- 每个模型可以单独启停。高级设置支持修改显示名称、从主模型选择器中隐藏模型、控制思考参数，以及配置供应商的非敏感请求头和工具名称兼容选项。

## English

- Add multiple models to one account in Settings → Models. Save an account first, then pick from its catalog or enter model IDs. Removing the last model keeps the account. The task composer groups models by provider.
- Choose separate helpers for task naming, image understanding and approval reviews. The general helper also chooses reasoning effort for supported models set to automatic. Manually assigned task titles are preserved.
- A text-only task model can use a description from your selected vision helper. A vision-capable task model reads attached images directly.
- Enable or disable models individually. Advanced settings include display names, visibility in the main picker, reasoning parameters, non-secret request headers and tool-name compatibility.
