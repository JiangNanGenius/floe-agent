# Floe Agent 1.11.3 for Mac

## 简体中文

- 打开「设置 → 模型供应商」，可按对话、生图、视频三种用途添加账户。可搜索与 iPad 相同的供应商目录，拉取或手动添加模型，也可编辑、停用或移除单个模型。火山方舟 Agent Plan 等不提供模型列表的服务使用随包候选。
- 在同一页选择默认生图模型和视频模型。首次添加可用模型时会自动选中，已有独立配置的用户可以继续使用原配置。调整媒体模型不会改变聊天模型。
- 在创意工作台可以跟随默认模型，也可为这次生图或视频单独选模型。请求使用所选账户当前的密钥。停用账号或移除模型后，可以重新选择；已提交的视频任务会记住所用账号。
- 对话输入框支持粘贴 Finder 文件和截图，也可以从系统照片选择器添加图片。移除附件时保留原文件。
- Floe Bridge 和 Floe Agent 都可以通过「检查更新」升级。

## English

- Open Settings → Model Providers to add accounts for chat, image generation or video generation. Search the same provider catalog as on iPad. Discover or manually add models, edit their settings, and disable or remove individual models. Plans without a model-list endpoint, including Volcengine Agent Plan, offer bundled model choices.
- Choose default image and video models on the same page. The first available model becomes the default for its role. Existing standalone configurations remain available, and choosing a media model preserves the chat selection.
- Creative lets you follow the default or pick another model for the current image or video. Requests use the selected account’s current credentials. Choose another model if an account is disabled or a model is removed. Submitted video jobs retain their original account.
- Paste Finder files and screenshots into the message composer, or add images from the system Photos picker. Removing an attachment preserves the original file.
- Existing Floe Bridge and Floe Agent installations can upgrade with Check for Updates.
