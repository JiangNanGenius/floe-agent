# Floe Agent 1.2.1 for Mac

## 简体中文

Mac 应用现名为 **Floe Agent**。在 Bridge 窗口右上角点击「切换到 Floe Agent」，即可打开原生 Agent 工作区。需要返回 Bridge 时，从菜单栏打开「设置」。已有用户可沿用「检查更新」升级。

## English

The Mac app is now named **Floe Agent**. Click **Switch to Floe Agent** at the top right of the Bridge window to open the native Agent workspace. To return to Bridge, open **Settings** from the menu bar. Existing users can upgrade with **Check for Updates**.
