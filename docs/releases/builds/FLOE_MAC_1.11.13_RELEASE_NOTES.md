# Floe Agent 1.11.13 for Mac

## 简体中文

- 在任务中心创建单次或重复定时任务，暂停计划、查看下次运行并打开历史结果。Agent 运行时执行计划。恢复运行后可查看错过的任务并补跑。
- 已有任务的权限弹窗支持跟随全局默认、选择恢复策略和设置通知。审批和运行结果通知可回到原任务。
- 从任务检查器查看运行进度和文件变更，打开有可靠记录的补丁差异。终端从当前任务目录启动，也可以连接指定的 SSH 主机。
- 在模型供应商设置中测试所选模型的实际响应，查看访问、额度、网络和接口错误，并分享脱敏诊断。

## English

- Use Task Center to create one-time or recurring schedules, pause them, see the next run, and reopen results. Schedules run while Agent is active. When Agent returns, review missed runs and run them on demand.
- Saved tasks can follow the app’s default approval mode, select a recovery policy, and choose notifications. Open the original task from approval and run notifications.
- The task inspector shows progress and file changes, including verified patch diffs. Open a terminal in the current task’s folder or connect to an SSH host you specify.
- Test the selected model in provider settings, see actionable access, quota, network and endpoint errors, and share a redacted diagnostic.
