# Floe Agent 1.11.28 for Mac

适用于 Apple 芯片和 macOS 15 或更新版本。可从 Floe Agent 或 Floe Bridge 检查更新。

- 任务浏览器可在画布和 SVG 上按截图文字或像素位置操作。从任务打开工作区 HTML 预览后，可把网页准备的完整 PNG 保存为新文件。
- 模型供应商新增能力变更审阅，可以查看并确认已保存模型的读图能力和上下文变化。在支持 Apple Intelligence 的 Mac 上，可在「本地模型」中启用系统模型。
- 文件与项目可交给已安装的 VS Code。文件支持选择其他应用打开。创意工作台的图片和视频可以另存副本，再交给所选应用继续编辑。

## English

For Apple silicon Macs running macOS 15 or later. Use Check for Updates in Floe Agent or Floe Bridge.

- The task browser can use screenshot text or pixel positions on canvas and SVG controls. Open workspace HTML in the task browser and save the full PNG staged by the page as a new workspace file.
- Review image-input and context changes for saved models in Model Providers. On supported Macs, enable the system model in Local Models.
- Open files and projects in an installed copy of VS Code, or choose another app for a file. Save a copy of a generated image or video to edit it in the app you choose.
