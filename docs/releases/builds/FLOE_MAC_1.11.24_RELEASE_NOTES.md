# Floe Agent 1.11.24 for Mac

适用于 Apple 芯片和 macOS 15 或更新版本。可从 Floe Agent 或 Floe Bridge 检查更新。

- 加快 Floe 本机 Computer Use 的连续窗口截图。每次仍会采集窗口的当前画面。
- 改值、定位到文本框及全选文字在确认生效后更快返回。

## English

For Apple silicon Macs running macOS 15 or later. Use Check for Updates in Floe Agent or Floe Bridge.

- Repeated window captures in Floe Native Computer Use are faster. Each capture reads the current window.
- Editing a field, focusing a text field, and selecting text return sooner when the change is confirmed.
