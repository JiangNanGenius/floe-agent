# Floe Agent 1.4.50（Build 81）TestFlight 测试说明

本轮重点修复凭据消息被替换、画布节点交互与旧画布迁移问题，并回归 Harness 批次结算和云模型恢复。Build 81 只有在 App Store Connect 显示处理完成并挂载到测试组后才算可用。

## 重点验证

- **凭据交接**：在当前会话中要求 Agent 设置 SSH/VNC 密码时，用户消息不得被改写为 `credential:UUID`；保存连接后应显示已配置，但不得在工具卡片、日志或诊断中回显密码。
- **画布节点**：选中未锁定节点后可用八个控制点调整大小，并可旋转；操作结束后位置和尺寸应可靠保存，重新进入画布不得丢失。
- **媒体预览**：素材库或媒体任务插入的本地图片和视频应在节点内显示真实内容；路径异常时显示安全占位，不访问应用目录之外的文件。
- **侧栏层级**：画布左上角只保留应用导航与一个带明确语义的画布列表控制，不再出现两个相同的收起/展开按钮。
- **旧画布迁移**：原有文本、节点、连接、笔迹和媒体引用应继续可用；新版可保存 PencilKit 原始数据与空白、网格或点阵背景。
- **任务连续性**：云模型断线后应从稳定请求检查点重连；同一批工具必须按调用顺序一次性结算，已完成工具不能在恢复后重复执行。

## 回归边界

- 本地大模型仍只在 iPad 真机验证；Mac 定向测试不会加载本地大模型。
- 创意模式已有多画布、素材库、媒体后台任务、同步开关、画布助手和视觉辅助路由不得回退。
- 普通聊天可以保留用户主动输入的密码语义；只有保存连接配置时才写入 Keychain。审计、工具结果、崩溃反馈和诊断仍必须脱敏。

反馈请注明 Build 81、设备型号、iOS/iPadOS 版本、模型与供应商、画布或任务 ID、准确操作、结果和时间。只上传脱敏诊断、Xcode Organizer、TestFlight crash 或设备日志；不要发送 API Key、Token、密码、SSH 私钥、证书或描述文件。
