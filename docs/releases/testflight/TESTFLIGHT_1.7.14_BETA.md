# Floe Agent 1.7.14 / Build 255 — TestFlight delivery

Immutable tag `v1.7.14` fixes App source `850701db34411ab87ac9788eeaaf7ea3baeea2b4`; all shipping targets use version 1.7.14 and build 255. The [bilingual release notes](../notes/RELEASE_NOTES_1.7.14_BUILD_255.md) cover Linux guest allocation (four cores total, at most three per guest), guest-tool discovery, voice startup and waveform stability, and Notes fixes. Physical iPad guest and voice behavior remains for user acceptance.

The [first release run](https://github.com/JiangNanGenius/floe-agent/actions/runs/37214725242) passed NativeNotes and both iPad/iPhone Notes UI legs on the accepted SDK and SDK 27. It stopped before signing because its Python regression scripts generated `__pycache__` inside a SwiftPM resource; the native-runtime audit correctly rejected the copied bytecode. The retained accepted-SDK input is artifact `11309426046` (`sha256:4208765636693e0ac835f8fff2566c14929c7d85e39544ef5c575c04d9cb0edd`). Packaging controller commit `38eee8f476e3974e33504af7088449ff51438421` disabled bytecode generation and added a resource check. The product tag was not moved.

The [normal release retry](https://github.com/JiangNanGenius/floe-agent/actions/runs/37221265462) succeeded: NativeNotes, full-App regressions, SDK 27 and accepted-SDK iPad/iPhone Notes UI, unsigned device builds, packaging audit, secret scan, SBOM, licenses, signing and upload. Its SDK 27 unsigned IPA artifact is `11310787496` (`sha256:70944f8a96858278e14c6d2ac8b2f8699f99fbe9b69efa278af6a9baab87ac46`). The public [GitHub prerelease](https://github.com/JiangNanGenius/floe-agent/releases/tag/v1.7.14) has `Floe-Agent-1.7.14-build255-unsigned.ipa` (738,962,981 bytes; SHA-256 `748b40ff148073815894723a6aecb68c878e7cb33fc734ce9b4c4bb660b64255`); it requires the tester's own signing and is separate from the signed TestFlight build. The [Feather source run](https://github.com/JiangNanGenius/floe-agent/actions/runs/37227342812) verified that asset, its attestation and the pinned dispatch/source chain, then published Build 255 as the newest `feather.json` entry. The [iPhone import screenshot](../../evidence/floe-1.7/notes/build255-iphone-imported-pdf.png) is a local full-App Simulator capture with a synthetic PDF; it is not device acceptance.

Apple accepted the signed upload and processed build ID `6c5cb03d-6a23-47c9-bf02-d7978d0498b8` as `VALID`, unexpired and `APP_STORE_ELIGIBLE`. [Preparation](https://github.com/JiangNanGenius/floe-agent/actions/runs/37227610461) attached the existing private `Floe QA` group and read back English and Simplified Chinese beta notes. [Independent verification](https://github.com/JiangNanGenius/floe-agent/actions/runs/37227667889) at 2026-10-04 19:17 UTC found exactly that one internal group and `IN_BETA_TESTING`; Build 255 is internally installable.
