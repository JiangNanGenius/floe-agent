# Floe Agent 1.4.47（Build 78）TestFlight 测试说明

本轮集中验证模型供应商设置、创意模式入口与跨设备配置同步。Build 78 只有在 App Store Connect 显示处理完成并挂载到测试组后才算可用。

## 重点验证

- **模型供应商**：分别添加对话、图片和视频服务；同一供应商包含多种模型时，应在对应分区显示。图片和视频模型不应混入首页对话模型选择器。
- **辅助模型**：这里只选择视觉、软件包审查、图片和视频默认模型，不再提供重复的“添加图片模型”入口。视频模型是可选 Extra。
- **创意模式**：配置至少一个可用生图模型后即可进入，不强制创建或绑定 Workspace；视频模型和 Workspace 都是可选增强。
- **跨设备同步**：在两台设备上交叉新增、修改和删除供应商及图片/视频模型，确认删除会同步，偏好先于模型到达时不会丢失，重新启动后会自动补齐。
- **凭据状态**：启用同步但当前设备缺少同步凭据时，应显示等待凭据，而不是误报同步完成。凭据内容不得进入诊断或 CloudKit 配置记录。

## 回归边界

- 对话模型、图片模型和视频模型的保存互不删除；编辑媒体供应商不应改变默认对话模型。
- 本地模型仅保留设备本地路由，云端同步不得覆盖设备专属选择。
- 长任务、恢复、工具执行、工作区和现有聊天流程不应因本轮模型设置变化而回归。

反馈请注明 Build 78、设备型号、iOS/iPadOS 版本、涉及的供应商与模型、同步操作顺序及准确时间。只上传脱敏诊断、Xcode Organizer、TestFlight crash 或设备日志；不要发送 API Key、Token、密码、SSH 私钥、证书或描述文件。
