# Floe Agent 1.4.41（Build 72）TestFlight 测试说明

本版集中修复任务权限切换和自动审批连续性。请在真实任务中验证，不需要重新运行已经通过的全工具巡检。

## 测试重点

- **完全访问：**在聊天输入框下方把当前任务切换为“完全访问”，完成 Face ID/Touch ID 后直接关闭权限页。App 不应退出；再次打开时仍应显示“完全访问”，不需要额外点击保存。
- **运行中切换：**让一个工具停在待审批状态，再从输入框权限按钮切换为“自动审批”或“完全访问”。当前任务应继续原来的工具，不应丢失上下文、重建任务或重复执行已完成步骤。
- **唯一入口：**当前任务权限只出现在聊天输入框下方。右上角菜单、任务列表菜单和右侧检查器不应再出现重复的任务权限入口。
- **自动审批：**明确要求安装/部署、换源、修复依赖、准备 SSH 环境或更新 Floe 守护程序后，完成同一目标所需的常规系统包与守护程序维护不应逐条询问。删除数据、读取凭据、上传/付款、目标不明的大范围远程改动和灾难性命令仍应拦截或要求复核。
- **连续指令：**在已经明确授权的环境任务中回复“继续”，应继承该任务中的用户授权；模型或工具输出不能自行扩大权限。

## 反馈信息

请注明 Build 72、设备型号、iOS/iPadOS 版本、所选权限模式、准确操作、结果和时间。若身份验证后仍退出，请上传本次最新的脱敏 Floe 诊断，以及时间匹配的 Xcode Organizer/设备记录。不要发送密钥、Token、证书或描述文件。

真机 Face ID/Touch ID、后台恢复和远程守护程序最终行为必须在兼容设备与真实主机上确认；Mac 编译和自动化测试不能代替这些结果。
