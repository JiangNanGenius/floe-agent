# Floe Agent 1.4.49（Build 80）TestFlight 测试说明

本轮集中验证原生画布交互、Apple Pencil、画布模型路由、凭据安全传递以及长任务与云模型断线恢复。Build 80 只有在 App Store Connect 显示处理完成并挂载到测试组后才算可用。

## 重点验证

- **Apple Pencil 与画布**：画笔面板应可调整工具、颜色和粗细；笔迹可整理为卡片或结构化内容，原笔迹是否保留遵循画布设置。左上角不应再出现重复侧栏按钮。
- **画布模型**：在“设置 → 画布”分别选择默认 Agent 和视觉辅助模型。非多模态 Agent 处理笔迹、截图或画面时，应调用视觉辅助链路并返回有效内容，而不是静默失败。
- **快捷创作**：画布中可快速新建文本、想法、任务和问题卡片；画布助手以画布内浮窗工作，不应强制跳回普通聊天或绑定工作区。
- **凭据交接**：用户在当前会话明确要求 Agent 设置 SSH/VNC 等密码时，操作应成功写入 Keychain；聊天时间线、恢复检查点、工具卡片和诊断中不得出现明文。
- **任务连续性**：云模型首包超时、流中断或长时间无事件时，应显示真实重试状态并自动恢复；已经完成的工具不得重复执行，最终回复顺序不能倒置。
- **记忆归属**：新增长期记忆必须记录所属任务；跨任务召回应保留来源并遵守当前任务、工作区和权限边界。

## 回归边界

- 本地大模型仍只在 iPad 真机验证；本轮不应降低云模型上下文、压缩或工具能力。
- 普通聊天、工作区、媒体后台任务、同步、PiP、浏览器和远程连接继续按原有能力工作。
- 自动审批仍以任务完成为目标，但重要文件、提权、破坏性动作和外部副作用不能因凭据交接而绕过授权边界。

反馈请注明 Build 80、设备型号、iOS/iPadOS 版本、模型与供应商、画布或任务 ID、准确操作、结果和时间。只上传脱敏诊断、Xcode Organizer、TestFlight crash 或设备日志；不要发送 API Key、Token、密码、SSH 私钥、证书或描述文件。
