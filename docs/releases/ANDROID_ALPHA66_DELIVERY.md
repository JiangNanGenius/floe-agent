# Android Alpha66 / code92

本版是持续迭代的GitHub预发布。技能的GitHub来源可保存、重开和清除；更新检查使用实际保存的来源。公共仓库可不配置账户，私有来源使用用户已配置的GitHub账户，访问失败提供可操作提示。

点击已安装技能进入更新／来源管理；进入插件页会加载目录，并提供手动刷新入口。刷新中的重复请求和旧运行代际回调受到约束。

本地技能不会因与目录同名而被提示替换；更新必须先完成实际检查。同版本的真实文件修改仍可审阅更新。许可证、声明文件及示例随目录保留，传统技能的派生清单贯穿安装和保存后校验，不改写上游文件。

匿名资源下载保留原始二进制字节；目录更新包含脚本、资源及清单，并验证同一提交下的Git文件摘要。传统技能没有`floe.json`时派生Android清单，执行继续使用任务Linux环境中的`exec.shell`。来源备份恢复跟随新技能ID，不携带凭据、安装证据或执行授权。

This GitHub prerelease adds persistent GitHub skill sources, actionable access errors, byte-exact anonymous resources and complete directory updates. Traditional packages derive Android metadata and continue using the task environment through `exec.shell`. Backup source intent follows restored skill identities without credentials, installed-package claims or execution grants.

Installed rows open update/source management. The plugin page loads the catalog and provides an explicit refresh action, with duplicate-request and stale-root guards.

Catalog name matches cannot redirect local installations. Applying an update requires a real staged check, including same-version file changes. License/notice documents and examples stay in the verified package; derived manifests remain sidecars through installation and post-verification.

## Known issues / 已知问题

- 这是中间测试版。自动解锁、部分后台跨App接续、全局界面精修及其他N01–N08余项继续推进。
- 不同设备的Linux／图形环境仍需反馈；索尼Android9组件故障和早期VNC断连原因尚未闭合。
- 已配置账户的真实私有仓库仍需外测。公共目录读取可能遇到GitHub限流，按实际错误处理；不因开发者未实测账户而禁用用户配置。
- 技能定义按原备份策略停用恢复，不恢复执行授权，也不把来源记录当作已经安装完整软件包。

- Intermediate build: automatic unlock, some background cross-App continuation, interface polish and other N01–N08 work remain open.
- Linux/graphics behavior varies by device; the reported Sony Android9 component failure and earlier VNC disconnect remain unresolved.
- Configured private repositories need real-user feedback. Public directory reads can encounter GitHub rate limits; configured users remain able to call the service.
- Restored skill definitions remain disabled references and do not regain execution grants or claim that a complete package is installed.

版本源与配套Office源码入口已准备。实际APK、三星行为、公开附件字节和在线更新发现分别记录；此准备记录本身不代表这些步骤已经完成。
