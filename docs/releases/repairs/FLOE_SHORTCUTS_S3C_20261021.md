# S3-C：精确运行查询与最终文本（2026-10-21）

本包沿用既有服务图、权限、工作区与运行存储，提供同一次运行的身份、状态、有限等待、取消和最终文本。旧 Run Intent 继续返回 String；新增类型化入口可衔接后续动作。文件结果留 S3-D，真实系统定时留 S4。

## 结果边界

最终文本必须来自该 runID、所属会话及持久化 assistant 消息的精确配对。运行终止标记只记录真实保存成功的最终消息 ID，或成功保存的验证草稿经真实 CONFIRM 后的同一 ID。过程文字、空完成、无最终文本、失败保存及旧消息同文不能冒充最终回复；没有会话最新消息回退。未知或损坏状态、错误归属、等待超时、取消及重启后的状态分别返回，等待超时不自动停止任务。

运行与取消继续复用现有 App 服务；DEBUG 的 Intent 入口测试通过 TaskLocal 注入服务，Release 不包含该替换入口。最终回复生产证明直接执行 Runtime → ConversationRunService → SQLite，没有手工制造终止标记代替执行。
