# Floe Agent 1.8.58（379）

## 简体中文

- 音乐编辑器新增 8 个合成音色，共 49 个。可以试听、手动设计、导入和分享 JSON 音色，也可以让工程助手设计音色并保存到轨道。
- 总混音和单个音色的参考音都能在设备上导出为波形 PNG。普通聊天也可以导出工作区音频的波形，供视觉模型查看。
- 浏览器预览可直接关闭，交还网页时可以给模型附上备注。模型转去使用其他工具后，空闲网页会释放控制权并保留标签页。
- IDE 在识别到游戏工程或选中可运行文件时显示运行按钮。更多编辑器侧边栏支持快速收起。

## English

- Eight new sounds bring the music editor to 49 synth presets. Audition, design, import and share JSON timbres, or ask the project assistant to design a sound and save it to a track.
- Export the stereo mix or a single timbre’s reference note as a waveform PNG on device. Chat can also export a workspace audio file’s waveform for a vision model to inspect.
- Close a browser preview directly or add a comment when returning control. An idle page stays open when the model switches to another tool.
- The IDE shows Run for a recognized game project or a runnable file. More editor sidebars support quick collapse.
