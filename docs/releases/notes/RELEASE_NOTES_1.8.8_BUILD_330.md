# Floe 1.8.8 (330)

## 简体中文

- 设置新增“帮助与指南”，提供双语离线文档、搜索、章节定位和相关设置入口；助手回答可引用指南。
- 文件助手按文件收纳会话，可继续同一文件的对话，并在任务运行时选择引导当前任务或排队输入。
- 改善音乐录制的计时与对齐，保留已有片段，并可播放已有轨道作为伴奏。
- 会议支持连续录音和分段转写，提供说话人标签、改名与合并，方便整理记录和回听。
- 完善文件、回收站与关联助手的删除和恢复，改善化学、生物、地图及媒体编辑中的对象操作、撤销和保存。
- 改进任务完成状态、中断恢复和无效请求提示；任务等待保留原会话，倒计时支持暂停、继续和取消。
- 扩展工具箱的测量、换算、定位、扫描与计时功能；网络路径逐跳显示，停止后保留已有结果，可选下载离线 IP 资料库查看地区与 ASN 信息。
- 修正部分 Mac Bridge 1.1.3 命令和文件传输响应出错时误报版本不兼容的问题。
- 改善 iPhone 窄屏与展开布局中的导航、侧栏和弹窗，减少遮挡并保持当前编辑现场。
- 收紧绘画输入选项的布局，并将“流程图”入口统一命名为“思维导图”。
- 更新本地 Linux 组件与服务停止管理。请重点反馈 Linux 图形应用的启动、交互和停止体验。

本次为中间内测版本，新增的 Linux 视频硬件解码未纳入；应用内原有视频编辑与播放功能保留。请重点检查音乐录制与伴奏、会议标签整理、帮助阅读、返回原任务及保存重开。云端服务需自行配置；录音需授予麦克风权限。Siri 与快捷指令沿用已有功能。

## English

- Adds Help and Guides in Settings, with bilingual offline articles, search, section links and links to relevant settings. Assistant answers can cite the guides.
- Groups file-assistant conversations by file, with continued discussions and a choice to steer an active task or queue the next input.
- Improves Music recording timing and alignment, preserves existing clips, and lets existing tracks play as accompaniment.
- Supports continuous meeting recording and segmented transcription, with speaker labels, renaming and merging for organizing notes and reviewing recordings.
- Improves deletion and recovery for files, Trash and linked assistants, alongside object actions, undo and saving in chemistry, biology, maps and media editing.
- Improves completion status, interrupted-task recovery and invalid-request feedback. Task waits retain the original conversation; countdowns support pause, resume and cancel.
- Expands Toolbox measurement, conversion, location, scanning and timing tools. Traceroute updates hop by hop and keeps received results when stopped. An optional offline IP database adds region and ASN information.
- Corrects misleading version-compatibility errors for some Mac Bridge 1.1.3 command and file-transfer responses.
- Improves navigation, sidebars and presentations in compact and expanded iPhone layouts, reducing obscured controls while retaining the editing context.
- Makes drawing-input options more compact and consistently names the former Flowchart entry Mind Map.
- Updates local Linux components and service-stop handling. Please focus feedback on starting, interacting with and stopping Linux graphical applications.

This intermediate beta does not include the new Linux hardware video decoding work. Existing in-app video editing and playback remain available. Please check Music recording and accompaniment, meeting speaker labels, help articles, returning to the original task, and saving/reopening. Cloud services require your own configuration, and recording requires microphone permission. Existing Siri and Shortcuts features are retained.
