## 简体中文

- 停止屏幕控制或接管手机时，立即移除悬浮球和控制通知；迟到的显示回调重新核对当前控制状态。
- 悬浮球显示真实的等待用户状态，等待授权期间使用静止提示。
- 修复结构化界面翻页后，审核丢失上一页目标节点信息的问题。同一次观察保留有界节点证据；页面变化、重复冲突、失败和观察过期仍按原规则校验。

本版为 GitHub Full 预发布，通过完整安装包升级。复杂跨 App 任务仍可能需要授权或重新观察；单指令日历保存、重开及整轮宣传业务结果以独立实测记录为准。

## English

- Stopping screen control or taking over the device removes the floating bubble and its control notification immediately. Late presentation callbacks recheck the current control session.
- The bubble reflects an actual wait for user input with a static indicator.
- Structured UI pagination preserves bounded evidence for a target on an earlier page of the same observation. Changed screens, conflicting nodes, failed results and observation expiry retain their existing checks.

This GitHub Full prerelease uses a complete-package update. Complex cross-app work can still require approval or a fresh observation. Calendar save/reopen and the complete one-send promotional workflow have separate device acceptance records.
