仅内部测试及现有GitHub／Feather渠道。实际回收量以设备完成结果为准。

## English

- Fixes Optimize Storage becoming unavailable after an update by recognizing native closure receipts retained from an earlier recovery session.

For internal testing and the existing GitHub/Feather channels. Reclaimed storage depends on completed work on the device.
