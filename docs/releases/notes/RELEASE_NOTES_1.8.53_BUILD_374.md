# Floe Agent 1.8.53（374）

## 简体中文

修复了 Kimi 在任务开始时拒绝图表工具定义、导致普通对话也无法继续的问题。原生图表仍支持全部 40 种类型。

试玩时减少了对已校验游戏文件的重复读取。现在可以连续拖动多个虚拟按键，调整布局期间滑动不会传给游戏。保存后重新打开试玩会沿用调整好的位置。

## English

Fixed a chart tool definition that could prevent Kimi from starting even an ordinary task. All 40 native chart types remain available.

Game playback now avoids repeatedly reading unchanged, verified files. You can reposition multiple touch controls in one editing session without scrolling the game, then save and reopen the layout.
