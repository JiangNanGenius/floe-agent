# Floe Agent 1.7.73 (314)

## 简体中文

- 修复重新打开 App 后，已有任务的本机运行环境被误判为不可用、执行工具消失的问题。
- 恢复原来的运行位置、文件和已安装依赖，无需重新保存设置、重建任务或重置环境。
- 保留运行位置身份及重建校验；真正不可用的环境仍会如实提示。

## English

- Fixed saved tasks incorrectly losing their local execution tools after reopening the App.
- Restores the existing execution location, files and installed dependencies without re-saving settings, recreating the task or resetting the environment.
- Retains execution identity and rebuild checks, and reports genuinely unavailable environments.
