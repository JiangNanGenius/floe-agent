# Floe Agent 1.8.45（366）

## 简体中文

首次打开此版本时会显示用户协议。游戏助手会在建议工程目录和引擎后等待你确认，并使用工作区工具查看工程文件。缺少运行文件的 RPG Maker MV 工程现在可自动获取所需资源。

## English

This version presents the user agreement on first launch. The game assistant uses workspace tools for project files and waits for you to confirm its suggested folder and engine. RPG Maker MV projects that lack runtime files can now download the required resources automatically.
