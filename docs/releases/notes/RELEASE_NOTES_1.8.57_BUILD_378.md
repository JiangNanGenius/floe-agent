# Floe Agent 1.8.57（378）

## 简体中文

- 当原操作反复无进展，而助手已说明会改用其他方式时，会在当前任务内尝试替代操作。聊天顶部和回复下方会显示具体停止原因。
- 在 iPad 和 iPhone 聊天中运行网页游戏时，打开玩家界面前游戏也能绘制新帧。截图会为渲染较慢的场景留出更多时间。截图超时后可查看游戏日志并重试。
- 云模型首次响应较慢时，聊天会调整等待时间，并在自动重连期间显示进度。连续等不到响应时，可以从检查点继续。
- 诊断页优先显示最新日志。反馈提交后可直接复制完整编号。

## English

- When a tool route stalls and the assistant proposes a different approach, it can continue in the same run. The chat header and reply footer show why a run stopped.
- Web games run from chat on iPad and iPhone can draw new frames before you open the player. Screenshots allow more time for slower scenes to render. If a capture times out, check the game logs and try again.
- Chat adapts its first-response timeout and shows when the model is reconnecting. Continue from the saved checkpoint if the model still does not respond.
- Diagnostics shows the newest entries first. Copy the full reference number directly after sending feedback.
