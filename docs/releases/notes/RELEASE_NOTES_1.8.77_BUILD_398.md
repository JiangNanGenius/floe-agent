# Floe Agent 1.8.77（398）

## 简体中文

- 任务中心合并读取会话的最近运行状态，减少打开长历史时的数据库查询。
- 手记支持多选和批量移入回收站。可以在回收站里搜索标题和正文。
- 「新建任务」空白页的欢迎区固定居中。
- 配对设备同步会话和工作区文件时复用连接，减少中途重连。
- 发给运行中任务的引导按实际生效顺序显示，并保留原发送时间。

## English

- Task Center loads the latest run status for conversations together, reducing database queries for long histories.
- Select multiple documents in Notes and move them to Trash together. Search Trash by title or content.
- The New Task welcome stays centered on the empty screen.
- Paired devices reuse their connection when syncing a conversation and its workspace files.
- Guidance sent to a running task appears where it took effect, with its original send time.
