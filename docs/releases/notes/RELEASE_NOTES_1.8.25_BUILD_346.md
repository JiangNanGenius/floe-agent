# Floe Agent 1.8.25（346）

## 简体中文

增加字体设计作品的单项删除、多选、全选和批量管理。字体管理展示完整内置字体及用户导入字体，标记内置项目并保护其不被删除。

改善智能体首轮工具可见性；聊天、计划与智能体按各自用途提供工具，本地模型按需加载工具定义。保留所选模式在重试与会话恢复时的工具边界。

改善模型反复查询工具目录时的停转判断，按实际进展更新状态。

本次用于内部测试。换机后的储存整理、真实 Linux 清理与跨设备同步仍需设备验证；不把旧结果计作本版新增回收。不提交公开 TestFlight 或正式 App Store 审核。

## English

Adds single and batch deletion, multiple selection and Select All for font-design projects. Font management lists all bundled and user-imported fonts, identifies bundled items and protects them from deletion.

Improves first-turn tool visibility for agents. Chat, Plan and Agent modes expose tools appropriate to their purpose, while local models load definitions on demand. Preserves mode boundaries during retries and conversation recovery.

Improves stall detection during repeated tool-catalog queries by tracking real progress.

This build is for internal testing. Post-migration storage optimization, real Linux cleanup and cross-device synchronization still require device verification; earlier results are not counted as new reclamation. No public TestFlight or formal App Store submission.
