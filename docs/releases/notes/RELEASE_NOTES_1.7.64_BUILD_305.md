# Floe Agent 1.7.64（305）

## 简体中文

- 修复火山引擎 Agent Plan 添加与连接测试，更新套餐可选模型，并完善套餐图片生成。
- 完善阿里云按量服务与 Token Plan 的聊天、图片和视频接入，分别保留地址、凭据和模型选择。
- 画布和任务中的原生 3D 文档支持连续修改参数、撤销与重做，并可向助手提供真实视图。
- 新增自定义材质与个人材质库，支持颜色、金属度、粗糙度、透明度、自发光和贴图映射。
- 新增展示模式、灯光和环境设置，保留原有工程编辑视图及装配实例。
- 改进 GLB 材质与贴图导出、视图 PNG 导出，以及文档保存和重开。
- 支持具备工具能力的本地模型使用 CAD 工具；没有视觉能力的模型继续通过几何查询和测量工作。
- 保留已有供应商名称、密钥、自定义地址与能力设置，套餐和按量渠道独立使用。

## English

- Fixed Volcengine Agent Plan setup and connection testing, refreshed its model choices, and improved plan image generation.
- Completed separate Alibaba Cloud pay-as-you-go and Token Plan routes for chat, images and video while preserving saved endpoints, credentials and model choices.
- Native 3D documents in Canvas and tasks support continuous parameter editing, undo/redo and actual viewport images for the assistant.
- Added custom materials and My Materials, with colour, metallic, roughness, opacity, emission and texture mapping.
- Added Present mode with lighting and environment settings, alongside the existing engineering editor and placed assembly instances.
- Improved GLB material and texture export, viewport PNG export, document saving and reopening.
- Tool-capable local models can use CAD tools; text-only models continue through geometry queries and measurements.
- Existing provider names, keys, custom endpoints and capability overrides are preserved. Subscription plans remain separate from pay-as-you-go services.
