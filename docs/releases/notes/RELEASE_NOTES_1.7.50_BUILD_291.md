# Floe Agent 1.7.50（291）

## 简体中文

- 改善增强语音的加载、连续播放和停止响应。
- 修复火山引擎 Agent Plan 语音播放，支持配置 OpenAI 兼容语音服务地址。
- Office 打印与 PDF 导出集中到右上角，修改选项后自动更新预览，可选择是否包含笔迹。
- 改进 Excel 网格线、打印范围和缩放设置，为 Word 与 PPT 增加纸张、方向和打印缩放选项。
- 修复技能更新提示和同步设备列表。

## English

- Improved enhanced voice loading, continuous playback and stop response.
- Fixed Volcengine Agent Plan speech playback and added a configurable OpenAI-compatible speech service address.
- Office printing and PDF export are grouped in the upper-right menu, with automatic previews and an option to include handwriting.
- Improved Excel gridlines, print ranges and scaling, and added paper, orientation and print scaling options for Word and PowerPoint.
- Fixed skill update feedback and the synced-device list.
