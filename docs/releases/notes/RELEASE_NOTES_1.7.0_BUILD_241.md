# Floe Agent 1.7.0 — Build 241

## 简体中文

- 修复 PowerPoint 放映页面空白，支持放映换页后返回编辑。
- 减少 Linux 虚拟机的同步开销，提高单核与双核任务的运行效率。实际速度因设备和任务而异。
- 调整设置、文档和工作区提示，去除不必要的开发术语。
- 下载的 MLX 本地模型标注为 Beta／实验性，暂不推荐作为日常首选；Apple 系统模型不受此标注影响。

GitHub 以正式 Release 分发。TestFlight 公开测试需经过 Apple 的独立审核；送审不代表已开放安装。设备实际表现以安装后反馈为准。

## English

- Fixes blank PowerPoint slides during presentations and supports returning to editing after changing slides.
- Reduces Linux virtual-machine synchronization overhead for single- and dual-core workloads. Actual speed varies by device and task.
- Clarifies settings, document and workspace messages, removing unnecessary development terminology.
- Labels downloaded MLX local models Beta / Experimental and advises against using them as the daily default. Apple’s system model is separate.

Distributed as a normal GitHub Release. Public TestFlight access requires separate Apple review; submission does not mean installation is available. Device behavior remains subject to feedback after installation.
