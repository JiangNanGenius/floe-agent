# Floe Agent 1.7.47（288）

## 简体中文

- 新增聊天模式及每个会话的思考强度选择，保留独立的任务模式。
- 新增连续语音、说话打断、字幕与播放进度；朗读仅使用回答的最终正文。
- 新增增强语音模型、九种音色和多语言实时试听，语音输入、输出分别设置。
- 增加在线语音服务配置，并修复语音输入首次启动偶发失败。
- 联网搜索改为按需添加供应商，支持独立账户、测试搜索及可更新的供应商目录。

## English

- Added Chat mode with per-conversation thinking levels alongside Agent mode.
- Added continuous voice, interruptions, captions and playback progress. Read Aloud uses only the final answer.
- Added enhanced speech models, nine voices and live multilingual auditions, with separate input and output settings.
- Added online speech service configuration and improved first-start reliability for voice input.
- Search providers can now be added as needed, with separate accounts, test searches and an updatable provider catalog.
