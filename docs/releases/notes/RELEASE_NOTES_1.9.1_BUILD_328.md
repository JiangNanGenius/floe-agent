# Floe 1.9.1 (328)

## 简体中文

- 重新整理音乐、二维设计和媒体编辑器的布局，改善工具分组、播放控制、时间轴拖动、全屏编辑和触屏操作。
- 音乐增加五线谱、简谱与双 Deck DJ 工作流；乐谱可按声部选择合成乐器音色演奏，并将音频加入编曲时间轴。完善音色、节拍、Cue／Loop、混音、录制和保存。
- 扩展图片和视频创作工具，包括选区、变形、修复、合成、关键帧、色彩处理、复合片段与人声分离；完善原件、撤销、保存和导出之间的衔接。
- 支持 40 类原生图表，并能在回复段落之间展示；增加读值、筛选、缩放、全屏及图片／PDF 导出，改善 SVG 和其他正文内容的预览。
- 文件修改直接展示差异：小改动展开可见，较长内容提供增减统计和有高度上限的展开查看。文件名旁直接显示增减统计与展开入口；改善文件与回收站的批量管理。
- 补齐原生 Git 日常操作和 GitHub 问题、拉取请求、评审与检查流程；链接可查看原始来源并返回任务，助手复用相同操作链。
- 局域网发现增加常用设备范围、扫描进度、取消和结果复用；完善连接工具的历史输入与错误反馈，改进本地 Linux 网络传输。
- LaTeX 原生排版按文章补齐宏包和字体，生成 PDF 并保留目录、链接和阅读位置；改善 PCB 元件库、化学编辑器、手记与文档助手、苹果同步和任务状态提示。
- 修复图乐园产物提示与图标，增加独立的自动调用设置；改善新模型配置、导入、预览和多个页面的细节。

请重点反馈之前出现问题的界面与操作、保存重开、助手调用及连接工具。云端服务需要自行配置；人声分离可使用导入的兼容本地模型或已配置服务。图乐园受系统、设备和地区支持范围影响。原生 USB 串口驱动仍等待额外授权，本版不包含。

## English

- Refines music, 2D design and media editor layouts, including grouped tools, transport controls, timeline dragging, full-screen editing and touch input.
- Adds staff and numbered notation plus dual-deck DJ workflows. Perform each score part with synthesized instrument sounds and add the rendered audio to the arrangement timeline. Improves presets, beat analysis, Cue/Loop, mixing, recording and saving.
- Expands image and video tools for selection, warping, retouching, composition, keyframes, color, compound clips and vocal separation, with improved original-file, undo, save and export workflows.
- Supports 40 native chart types embedded between reply paragraphs, with value inspection, filtering, zoom, full-screen viewing and image/PDF export. Improves SVG and other inline previews.
- Shows file changes directly: small edits are expanded, while larger edits show added/removed counts and an expandable, height-limited diff. Line counts and the expand action sit beside the filename. Improves file and Trash batch actions.
- Completes native everyday Git operations and GitHub issue, pull request, review and check workflows. Source links open native details and return to the task; the assistant uses the same operations.
- Adds LAN discovery presets, progress, cancellation and reusable results, with improved connection history, feedback and local Linux networking.
- Adds native LaTeX typesetting with document-specific package/font downloads, PDF output, bookmarks, internal links and retained reading position. Improves PCB libraries, chemistry editing, note and document assistants, Apple synchronization and task status messages.
- Fixes Image Playground output feedback and icons, adds an independent automatic-use setting, and improves model setup, importing, previews and interface details.

Please focus feedback on previously affected screens and actions, saving/reopening, assistant tools and connection workflows. Cloud services require your own configuration. Vocal separation supports an imported compatible local model or configured service. Image Playground depends on system, device and regional availability. Native USB serial drivers await additional authorization and are not included.
