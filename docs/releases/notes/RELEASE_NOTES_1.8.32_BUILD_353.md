# Floe Agent 1.8.32（353）

## 简体中文

修复了打开尚未初始化 Git 的工作区时误弹「源码管理错误」的问题。现在可以直接初始化仓库，或克隆已有仓库。

源码管理侧栏的初始化、暂存、提交和同步按钮采用统一尺寸与样式。普通字号下操作按两列对齐，放大辅助功能字号后改为单列。

## English

Opening Source Control in a workspace without a Git repository now shows the options to initialize or clone a repository without an error alert.

Setup, staging, commit, and sync actions now share a compact button style. Actions line up in two columns at standard text sizes and switch to one column at accessibility text sizes.
