# Floe Agent 1.8.62（383）

## 简体中文

- CAD 草图的跟踪点跟随平移和缩放。只查看模型并退出时，工程会保留原来的保存版本。已有损坏且存在有效历史版本的工程可以查看并恢复副本。
- 「CAD 工具」按设计与场景分组。「加工」可直接打开 3D 打印和切削加工的入口。
- 打印逐层预览、加工工作台和加工仿真可展开查看。切换时保留当前层、工序或回放位置。
- 建筑工程可直接在二维平面和三维模型之间切换。需要独立工程时使用「另存为」。

## English

- CAD sketch points follow viewport pan and zoom. Viewing and closing an unchanged model preserves its saved revision. A damaged project with a verified previous save can be reviewed and restored as a copy.
- CAD Tools groups design and scene tools. Manufacture opens the entry points for 3D printing and machining.
- Expand the print layer preview, machining preview or simulation while keeping the selected layer, operation or playback position.
- Switch between the 2D plan and 3D model in the same building project. Use Save As to create an independent project.
