# Floe Agent 1.8.39（360）

## 简体中文

改进目标任务的续接和完成检查，减少执行中的额外开销。工具完成后及时更新状态，让等待模型回复的过程更清楚。

优化浏览器接管提示和多标签使用，并改进滚动、输入提交与文件下载的可靠性。Skill Hub 在较宽屏幕上显示更多精选项目，并可先显示已验证的缓存目录。

改进火山语音识别断线后的恢复；DeepSeek 连续语音支持分段转写。

## English

Improved goal continuation and completion checks, with less execution overhead. Tool status updates promptly when execution ends, making the wait for the model clearer.

Refined browser handoff controls and multi-tab use, with more reliable scrolling, input submission, and downloads. Skill Hub shows more featured items on wider screens and can display its verified cached catalog first.

Improved recovery after Volcengine speech recognition disconnects; continuous DeepSeek speech can be transcribed in segments.
