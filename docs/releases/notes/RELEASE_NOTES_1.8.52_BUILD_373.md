# Floe Agent 1.8.52（373）

## 简体中文

加快了大型游戏文件夹的导入。修复了复制资源时仅文件时间发生变化也可能导致试玩报错的问题。准备试玩时，游戏工作台会显示当前正在检查目录、准备环境还是加载游戏文件。

用户协议现在分段显示，同意和不同意按钮固定在底部。首次打开和设置页都可阅读更新后的协议，已同意的用户升级后可直接进入应用。

## English

Large game folders import faster. This update fixes a play error that could occur when a resource’s timestamps changed during copying even though its contents stayed identical. The game workbench shows whether it is checking the folder, preparing the environment, or loading files.

The revised user agreement is easier to read in sections, with the first-launch actions always within reach. It is also available in Settings. Users who have already accepted can continue directly after updating.
