# Android Alpha49

本次中间版本修正Linux图形查看器的单指拖动与双指缩放／滚轮冲突，以及失败终端等待其他会话结束的问题。补齐活动工作区中新输入的原子提交和原会话同步基线；图形会话的内部控制终端不再作为手动终端显示。显式释放文件来源授权时，清除当前界面自己的闲置选择引用，继续保留其他使用者和未完成恢复的保护。

首页没有启用的定时任务时，隐藏整个定时任务卡片及占位；有任务时继续显示。

已知问题：Office关闭和保存回执、部分手机观察失效、跨项目图形隔离、专业编辑器保存、系统条件任务及整体界面仍在逐项实测修复。本版不代表全应用验收完成。完整APK支持跨版本升级，安装前请保存正在编辑的文件。

English: This intermediate build separates single-pointer remote dragging from two-finger viewport gestures, settles a genuinely released failed terminal without waiting for unrelated sessions, and carries newly delivered workspace inputs into the original session's synchronization baseline. The graphical session's internal control terminal stays out of the manual terminal pane. Explicit source-grant revocation retires the current idle picker reference; other consumers and unfinished recovery remain protected. Home hides the scheduled-task card and its empty space when no schedule is enabled. Office close/save receipts, intermittent phone observations, cross-project graphical sessions, editor save workflows, conditional schedules and broader UI refinement remain under device testing. The full APK supports cross-version upgrades.
