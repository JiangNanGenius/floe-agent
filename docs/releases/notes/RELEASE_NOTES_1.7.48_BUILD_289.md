# Floe Agent 1.7.48（289）

## 简体中文

- 语音对话可直接打开，改善首次连接、短句识别和连续对话。
- 更新增强语音模型，支持分句播放和实时音色试听。
- 语音包显示下载百分比、大小和速度，成功替换后清理旧模型。
- 简化用户画像和 SOUL.md 的编辑，保留恢复上次内容。
- 更新入口集中到设置底部的“更新管理”。
- 从其他 App 导入文件时可选择手记、任务或画布，任务和画布支持选择已有目标或新建。

## English

- Open voice conversations directly, with improved startup, short-utterance recognition and continuous turns.
- Updated enhanced speech model with sentence-by-sentence playback and live voice previews.
- Voice downloads show percentage, size and speed, with retired-model cleanup after a successful replacement.
- Simplified user profile and SOUL.md editing with Restore Previous.
- Find content updates together under Updates at the bottom of Settings.
- Choose Notes, Task or Canvas when importing files from other apps, with existing or new task and canvas targets.
