# Floe Agent 1.8.36（357）

## 简体中文

优化云端模型流式响应和长任务聊天中的消息处理。修复打印工程修改设置后重新切片失败时，旧结果可能被当成当前结果导出的问题。优化安装包大小，并移除重复资源。

## English

Improved cloud model streaming and message processing in long tasks. Fixed an issue where a previous print result could be exported as current after a new slice failed. Reduced package size and removed duplicate resources.
