# Floe Agent 1.7.72 (313)

## 简体中文

- 修复点击停止后，文字和思考内容仍继续显示的问题。
- 修复任务文件区将 `.floecad` 当作文件夹展开的问题，可直接进入原生 3D 工作台。
- 长按自己发送的文字或助手回复可使用系统选区和复制；聊天查找保留在会话菜单中。
- 补齐共享 Linux 的整机关机、重启及占用查看，支持运行会话互发协调消息。默认保留其他任务正在进行的工作。

## English

- Fixed text and reasoning continuing to animate after Stop.
- Fixed `.floecad` packages expanding as folders in task files. Open them directly in the native 3D workbench.
- Long-press user messages or assistant replies for system text selection and copying. Find in Chat remains in the conversation menu.
- Added shared Linux machine shutdown, restart and occupancy inspection, with coordination messages between live tasks. Other active work is preserved by default.
- Repair reports when no recorded recovery is needed without resetting files or dependencies. CPU changes use online adjustment instead of outdated restart guidance.
- General settings now offers hardware Return behavior: New Line or Send. Shift–Return adds a line when Return sends.
