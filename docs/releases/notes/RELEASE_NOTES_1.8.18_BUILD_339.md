# Floe 1.8.18 (339)

## 简体中文

- 改善旧执行环境占用优化在中断、切换或恢复后的继续整理。
- 正常使用其他任务和工作区时，不再因无关状态变化打断整理；正在使用的资料仍受保护。
- 修复重点文件快捷入口误把工具说明和资源元数据当作真实文件的问题。

本次为窄范围内部修复；容量回收以设备实际完成结果为准。

## English

- Improves resuming storage optimization for older execution environments after interruption or recovery.
- Keeps unrelated task and workspace activity from unnecessarily interrupting cleanup, while protecting data that is in use.
- Fixes important-file shortcuts mistaking tool descriptions and resource metadata for actual files.

This is a focused internal repair. Reclaimed storage depends on the actual completed work on the device.
