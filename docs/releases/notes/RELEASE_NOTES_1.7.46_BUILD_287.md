# Floe Agent 1.7.46（287）

## 简体中文

- Excel 打印和 PDF 导出增加网格线选项、缩放滑块及精确百分比输入；设置下方的实际 PDF 预览自动更新。
- Skill 列表增加“官方／内部／外部”来源标签，无法证明来源的旧记录显示“未知”。
- 点快捷指令图标即可进入添加流程，移除重复按钮和自报确认开关；计划结束后弹窗提醒清理对应快捷指令及自动化。
- 新增折叠屏布局适配，系统识别后默认启用；可在“设置 → 通用”关闭，普通设备不显示该选项。

## English

- Added Excel print gridlines, a scale slider and exact percentage input. The actual PDF preview updates automatically below the settings.
- Added Official, Internal and External origin tags to skills. Older records with no provable source show Unknown.
- Tap the Shortcuts badge to add a shortcut. Removed the duplicate button and self-confirmation switch, and added a cleanup popup when a plan ends.
- Added adaptive foldable layouts, enabled automatically when supported hardware is detected. Turn them off in Settings → General; the option stays hidden on ordinary devices.
