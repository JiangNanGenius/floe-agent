# Floe Agent 1.8.31（352）

## 简体中文

可以在「设置 → 执行环境」提前设置 Linux 的图形内存。启动 Linux 后，可在同一处查看运行中的图形设备实际获得的额度。

启动旧版 Linux 环境时，可以选择保留资料并升级，或本次继续使用旧版。「设置 → 执行环境」和终端的虚拟屏幕也提供升级入口。确认前会说明升级会怎样影响正在运行的任务和已有资料。工作区文件继续可用，旧系统盘保留供恢复，原先装在 Linux 里的软件需要在新环境中重新安装。新版启用后，App 会清理已被替换且没有其他环境使用的旧镜像。

云端实时语音输入在短暂断线后会自动重连，并重新发送尚未确认的语音。已经确认的文字会保留。会议转写也会在录音期间尝试恢复连接。

## English

You can set the Linux graphics memory budget in Settings → Execution Environment before starting Linux. Once a graphics device is running, the same screen shows its actual allocation.

When starting an older Linux environment, you can upgrade and keep your data or use the current version for this start. You can also upgrade from Settings → Execution Environment or the terminal’s screen viewer. The confirmation explains what happens to running tasks and existing files. Workspace files stay available, and the old system disk is kept for recovery. Software installed inside Linux needs to be installed again in the new environment. Once the upgrade takes effect, the app cleans up superseded factory images that are no longer in use.

Live cloud dictation reconnects after brief network interruptions and resends speech that has yet to be confirmed. Confirmed text stays in place. Meeting transcription also tries to reconnect while recording.
