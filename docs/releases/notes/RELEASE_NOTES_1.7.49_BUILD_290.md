# Floe Agent 1.7.49（290）

## 简体中文

- 定位辅助与现有后台功能配合，任务可在后台按需获取位置并查询天气或附近地点。
- 首次打开时申请定位权限，可在后台设置查看定位状态。
- 修复首次定位授权和取消后重新查询可能失败的问题。

## English

- Location support works with existing background features, allowing tasks to request their location for weather and nearby searches while in the background.
- Location permission is requested on first launch, with location status available in Background execution settings.
- Fixed first-use location authorization and cancellation races affecting later requests.
