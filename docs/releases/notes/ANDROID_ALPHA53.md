# Android Alpha53 — phone control and pending-task recovery

This intermediate Android update narrows observation invalidation to relevant window events, preserves live action checks, and adds explicit background settings with real grant read-back. Returning to Floe queues a prompt attempt for the same durable pending schedule, without replacing an in-flight admission or creating a new occurrence. Linux graphical-session controls remember the application acknowledged by the running session.

Full and Play Kotlin compilation and 87 focused JVM regressions passed before the version-only packaging metadata change. The direct battery-exemption request is Full-only; Play retains ordinary system settings. A settings visit does not prove a grant, and exemption does not guarantee all background execution. Device findings and known issues accompany the published intermediate release. N01–N08 remains in progress.
