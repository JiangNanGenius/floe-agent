# Floe 1.8.10 (332)

## 简体中文

- 失败工具卡片支持手动收起，并在结果刷新后保持选择；精简回复操作栏。
- 独立二维 CAD 移除不适用的三维、加工和仿真入口；三维草图编辑时固定视角，退出后恢复。
- 更新图片编辑器的颜色调整、预览和导出功能。

- 编辑器中的 AI 助手与普通聊天分开，避免不同作品的会话混入聊天列表。
- 改善聊天列表中的失败、受阻和待处理提示，可打开原聊天查看原因并继续处理。
- 修正部分流式回复结束后的状态收尾，改善后台任务的进度、停止和结束提示。
- 改善会议录音的实时字幕衔接和说话人标记；离开录音页时可选择继续录音或停止。
- 改进工具箱的显示和常用操作，路由跟踪可配合本地信息库显示 IP 地区和网络信息。
- 三维编辑器的草图页可导入 DXF/DWG，也可从本 App 的二维 CAD 项目选择草图并加入当前草图。直接复制原生曲线和构造图形，原项目保持独立。

请重点检查作品助手与普通聊天的区分、回复结束与等待提示、录音页的继续和停止，以及工具箱操作。CAD 导入请检查多个源草图的选择、实际尺寸、取消和一次撤销；只复制图形，尺寸约束与关联留在原项目。

## English

- Simplifies reply actions. Failed tool cards respect manual collapse when results refresh.
- Removes unsuitable 3D, manufacturing and simulation actions from standalone 2D CAD. Editing a 3D sketch locks the view to its plane and restores the view when you finish.
- Updates image color adjustment, previews and export.

- Keeps editor AI assistants separate from ordinary chats, so conversations from different works do not appear in the chat list.
- Makes failed, blocked and pending states clearer in the chat list. Open the original chat to review the reason and continue.
- Corrects state handling at the end of some streaming replies and improves progress, stop and completion feedback for background tasks.
- Improves live captions and speaker labels during meeting recordings, with a choice to keep recording or stop when leaving the page.
- Improves toolbox displays and common actions. Traceroute can show IP region and network information using a local database.
- Adds DXF/DWG import on the 3D editor's sketch page. You can also choose a sketch from a 2D CAD project in Floe and add its native curves and construction geometry to the current sketch while keeping the original project separate.

Please check editor assistants versus ordinary chats, reply completion and waiting states, recording continuation and stopping, and toolbox actions. For CAD imports, check source-sketch selection, actual size, cancellation and one-step undo. Geometry is copied; dimensions, constraints and links remain in the source project.
