# Floe Agent 1.8.41（362）

## 简体中文

修复游戏文件夹导入时的路径错误。改进创意模式的画布入口和删除操作，统一画布编辑与保存。

工作区可创建和编辑 Studio 视频工程，并通过代码生成逐帧画面。新建 Linux 环境可尝试图形和视频加速；已有环境保留原版本，可选择升级。

## English

Fixed a path error when importing game folders. Improved canvas controls and deletion in Creative mode, and unified canvas editing and saving.

Create and edit Studio video projects in a workspace and generate video frames with code. Try graphics and video acceleration in new Linux environments; existing environments retain their current version and can be upgraded explicitly.
