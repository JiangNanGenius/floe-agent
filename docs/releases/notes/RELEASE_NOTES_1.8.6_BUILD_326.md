# Floe 1.8.6 (326)

## 简体中文

- 空间接入更多原生工作台，包括原理图与 PCB、LaTeX、生物学及 CAD 工程分析；完善从编辑、预览到保存和再次打开的操作。
- PCB 支持直接在画布中编辑、检查设计规则及原理图与 PCB 同步；新增从 PCB 更新原理图的差异预览与确认。
- LaTeX 增加源码折叠和 PDF 全文搜索，优化源码、项目面板和预览的布局，保留切换全屏后的阅读与搜索状态。
- 增强音乐编辑与预制音色，完善原生科学计算、CSV 处理和正文内图表等内容的工具调用；修复部分编辑参数与工具结果格式问题。
- 改善 iPhone 顶部导航与任务中心布局、文件预览与批量管理、连接工具历史及蓝牙串口的自动发现与错误反馈。
- 完善 Linux 软件源与依赖安装路径，升级时按已有运行环境识别原镜像，避免误用新的默认镜像。

本版用于内部及公开 TestFlight 测试。请重点检查新工作台入口、触屏与鼠标编辑、预览、保存重开、助手调用及之前报告的界面问题。部分高级 PCB 编辑和仿真分析仍在完善，原生 USB 串口驱动未包含。正式 App Store 提交及发布设置保持不变。

## English

- Adds more native workbenches in Space, including schematic and PCB editing, LaTeX, biology and CAD engineering analysis, with improved editing, previews, saving and reopening.
- PCB editing uses the canvas, design-rule checks and schematic/PCB synchronization. Updating a schematic from its PCB now includes a change preview and confirmation.
- Adds LaTeX source folding and PDF full-text search. Refines the source, project-panel and preview layouts, and preserves reading and search state across full-screen changes.
- Enhances music editing and preset sounds, native scientific tools, CSV workflows and inline content such as charts. Fixes several editor-argument and structured-result issues.
- Improves iPhone navigation and task-center layout, file previews and batch management, connection-tool history, and Bluetooth serial discovery and feedback.
- Improves Linux package sources and dependency installation. Existing runtimes retain their original image selection when a new default image becomes available.

This build is for internal and public TestFlight testing. Focus on workbench entry points, touch and mouse editing, previews, saving and reopening, assistant actions, and previously reported UI issues. Some advanced PCB and simulation capabilities remain in development. Native USB serial drivers are not included. The existing App Store submission and release settings are unchanged.
