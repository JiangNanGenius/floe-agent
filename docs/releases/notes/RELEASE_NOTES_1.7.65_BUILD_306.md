# Floe Agent 1.7.65（306）

> 候选发布文案；编译、行为验证及各渠道发布状态以本轮交付记录为准。

## 简体中文

- 修复长消息自动换行、光标跟随与展开编辑，改进分屏和大字体下的输入体验。
- 浏览器支持多标签页，改进原生导航、网站设置与下载；高级网站数据功能需明确确认后开启。
- 完善工具定义、完整结果回读与上下文压缩，慢调用和运行环境准备显示实际状态。
- 增强原生 3D 局部编辑、装配、工程图和简单动画，支持助手继续修改并查看真实结果。
- 可为任务选择和迁移运行位置，查看准备进度并在中断后继续；默认位置变化不会移动已有任务。
- 技能依赖按实际系统和架构准备，保留版本与恢复记录。
- 新增 DeepSeek 搜索供应商。
- 助手可在对话卡片中提问，支持语音回答及普通会话的通知答复；权限审批仍独立处理。
- 新增对话内查找、多关键词会话搜索，以及定时任务倒计时、详情、立即运行和跳过。
- 修复后台挂起期间的存储释放路径，并改进取消和旧回调隔离。

## English

- Fixed long-message wrapping, caret visibility and expanded editing, including split views and larger text.
- Added browser tabs and improved native navigation, website settings and downloads. Advanced website data access requires explicit consent.
- Improved complete tool definitions, full result retrieval and context compaction, with actual status for slow calls and environment preparation.
- Expanded native 3D editing, assemblies, drawings and simple animation, including continued assistant edits and actual viewport results.
- Choose or move a task’s execution environment, follow preparation and continue after interruptions. New defaults leave existing tasks in place.
- Skill dependencies follow the actual system and architecture, with versioned recovery records.
- Added DeepSeek as a search provider.
- Assistants can ask questions in conversation cards, with voice replies and notification replies for saved chats. Permission approvals remain separate.
- Added in-chat find, multi-keyword conversation search and schedule countdowns, details, Run Now and Skip.
- Repaired storage release during background suspension and improved cancellation and stale-callback isolation.
