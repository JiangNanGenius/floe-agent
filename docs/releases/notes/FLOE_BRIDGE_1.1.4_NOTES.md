# Floe Bridge 1.1.4（7）

## 简体中文

- 支持读取所选 Mac 工作区以外、已获授权的文件和图片，供 Floe Agent 的文件读取与图片查看功能使用。
- 改进文件传输响应校验，并继续遵守配对、文件访问权限和敏感路径限制。
- 适用于 Apple Silicon Mac，要求 macOS 15 或更新版本。新增读取能力需搭配支持该功能的 Floe Agent。
- DMG 已完成 Developer ID 签名、Apple 公证与装订。

## English

- Supports authorized reads of files and images outside the selected Mac workspace for Floe Agent's file-reading and image-viewing tools.
- Improves file-transfer response validation while retaining pairing, file-access permissions and sensitive-path restrictions.
- Requires an Apple Silicon Mac running macOS 15 or later. The new reading capability requires a compatible Floe Agent version.
- The DMG is Developer ID signed, notarized by Apple and stapled.
