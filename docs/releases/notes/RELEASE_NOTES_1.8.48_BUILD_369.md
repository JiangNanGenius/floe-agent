# Floe Agent 1.8.48（369）

## 简体中文

游戏工作台在同一工程修订内复用已经识别的引擎和目录，保存选择时会显示进度。RPG Maker MV 和 MZ 的标准数据库和地图文件不再占用其他游戏引擎的识别额度。试玩时按路径索引读取打包的游戏资源。

## English

The game workbench reuses recognized engines and folders for the same project revision and shows progress while saving a choice. Standard RPG Maker MV and MZ databases and maps no longer consume the detection budget for other engines. The player looks up packaged assets by path.
