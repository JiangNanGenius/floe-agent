# Floe Agent 1.8.80（401）

## 简体中文

- 修复长会话加载末尾消息后偶尔停在较早位置的问题。
- 点向下箭头可立即跳到最新消息。阅读较早消息或查看搜索结果时，保留当前位置。

## English

- Fix an issue where a long conversation sometimes stayed above the latest messages after they loaded.
- Jump straight to the latest message with the down arrow. Keep your place while reading earlier messages or viewing a search result.
