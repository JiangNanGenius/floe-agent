# Floe Agent 1.8.37（358）

## 简体中文

AI 操作浏览器时可以实时旁观、缩放和接管；接管后可交还，并在长时间无操作时获得提醒。改进浏览器在窗口大小变化和旧网页上的显示，以及网页表单和弹窗的操作。

修复生物工程和地图工程在助手工作期间关闭、重新打开时可能出现的问题。改进建筑编辑器的退出入口、编辑器助手的关闭按钮、文件修改汇总和 Mac Bridge 文件同步。

## English

Watch, zoom and take over the browser while AI is working, then hand control back; a reminder appears after a period of inactivity. Improved browser display when the window changes size and for older websites, as well as web forms and pop-up handling.

Fixed issues closing and reopening biology and map projects while the assistant is working. Improved the building editor's exit control, editor assistant close buttons, file change summaries and Mac Bridge file synchronization.
