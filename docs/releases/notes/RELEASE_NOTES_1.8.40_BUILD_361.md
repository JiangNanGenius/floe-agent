# Floe Agent 1.8.40（361）

## 简体中文

改进游戏工程界面和大文件夹、ZIP 工程的导入；导入时保留完整文件，并根据可用空间处理较大的工程。

减少云端语音识别启动时重复检查配置的工作。文件修改记录按回复展示已确认的操作，并改进本地运行环境的恢复和错误提示。

## English

Improved the game project interface and import of larger folders and ZIP projects. Imports retain the complete set of files and account for available storage.

Removed redundant configuration checks when starting cloud speech recognition. Confirmed file changes are shown with their replies, and local execution environment recovery and error messages have been improved.
