# Floe 1.8.1 (321)

## 简体中文

本构建用于整批预研接入的内部测试。请优先检查菜单、页面能否打开、按钮是否齐全，以及布局是否符合原先确认的方案。

- 空间整合个人文件与作品，默认列表，可切换缩略图；保留手记原笔记库和创意模式内的混合画布入口。
- 接入绘画／图片、视频、二维／三维 CAD、图示、音乐、会议、打印、加工和网络工具箱的原生界面、保存服务与 AI 工具。
- 打印增加机型、坐标原点、喷头偏移、自定义开始／结束／换头 G-code 和光固化平台方向；文件及 CAD 可准备独立打印工程。
- 会议从手记进入，个人笔记、转写和纪要分别使用；补齐模板、导出及待办回流。音乐保留编曲、键盘、混音和 DJ 工作流。
- 加入化学工程，连接原生结构编辑、计算记录、手记结构图与工程引用；重计算按实际配置的执行环境提供。
- 同步接入 Siri／快捷指令增强、交互内容保存、后台资料与记忆及通知设置。

本轮未做完整功能与稳定性重验证。尚未接通的引擎、协议或服务会显示实际状态；通知服务当前仍需可信首登及部署接线。315 正式审核和自动发布选择保持不变。本构建不提交公开 TestFlight。

## English

This internal build brings the predevelopment work into the App. Please focus on menus, pages opening, available controls and the previously agreed layouts.

- Personal files and editable works share Space, with a default list and optional thumbnails. Notes keeps its library; the mixed canvas remains in Creative mode.
- Integrates native interfaces, persistence and AI tools for drawing and images, video, 2D/3D CAD, diagrams, music, meetings, printing, manufacturing and the network toolbox.
- Printing adds machine configurations, coordinate origins, head offsets, custom start/end/tool-change G-code and resin platform orientation. Files and CAD can prepare independent print projects.
- Meetings open from Notes, with separate personal notes, transcription and minutes, plus templates, export and follow-up actions. Music retains arrangement, keyboard, mixer and DJ workflows.
- Adds chemistry projects with native structure editing, calculation records and structure images and project references in Notes. Heavy calculations use configured execution environments.
- Also integrates Siri and Shortcuts improvements, saved interactive content, background sources and memory, and notification settings.

This round does not repeat comprehensive functional or stability qualification. Unconnected engines, protocols and services retain their actual availability status; notifications still require trusted enrollment and deployment wiring. The existing Build 315 formal review and automatic release choice remain unchanged. This build is not submitted to public TestFlight.
