# Floe Agent 1.7.56（297）

## 简体中文

- 改善在线语音与增强语音模型在连续对话中的播放连贯性。
- 修复音频转换后播放进度计算不一致、回答无法正常结束的问题。
- 播放无法启动时及时显示重试提示，避免持续空转。

## English

- Improved playback continuity for online and enhanced voices in voice conversations.
- Fixed playback progress accounting after audio conversion, which could prevent a reply from finishing.
- Added a timely retry message when playback cannot start, avoiding repeated stalled attempts.
