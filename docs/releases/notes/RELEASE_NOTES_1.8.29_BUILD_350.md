# Floe Agent 1.8.29（350）

## 简体中文

修复换机后点「优化占用」可能在第一份旧磁盘就停止的问题。整理会沿用已经核验的维护目录，并在改写前后核对文件内容。诊断详情现在可以区分维护记录写入失败和磁盘文件发生变化。

工具箱终端助手可以在你正在看的终端里运行命令，命令和输出出现在同一会话里。侧栏只保留一个聊天输入框。收起助手后可以继续使用工具，再次展开即可接着聊。离开工具会结束这次助手会话。

## English

Fixed an issue that could stop Optimize Storage at the first legacy disk after moving to a new device. Optimization reuses the verified maintenance directory and checks file contents before and after rewriting. Diagnostics distinguish a failure to save a maintenance record from a change to a disk file.

The Toolbox terminal assistant can run commands in the terminal you have open. Commands and output appear in that session. The sidebar now has one chat composer. Hide the assistant to make room, then reopen it to continue the conversation. Leaving the tool ends the assistant session.
