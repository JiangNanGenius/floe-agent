# Floe Bridge 1.1.3 (6)

## 简体中文

- 自动更新源迁移到主分支，配合仓库分支整理。
- 保留旧版客户端升级到此版本的入口；更新后继续从新地址检查更新。
- 保留已有配对、设置、终端、文件传输和任务数据。

## English

- Moves the automatic update feed to the main branch.
- Keeps an upgrade path for existing clients; this version uses the new feed for later updates.
- Preserves pairing, settings, terminals, file transfer and task data.
