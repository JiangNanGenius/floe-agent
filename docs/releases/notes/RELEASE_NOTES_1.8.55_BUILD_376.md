# Floe Agent 1.8.55（376）

## 简体中文

- 在回复下方点文件名，可以就地查看或收起本轮保存的差异。回看旧回复时保留当时的记录。
- 从聊天打开游戏工程文件会进入 IDE。游戏工程主页和 IDE 都可以直接运行。可在本地播放的网页游戏无需先准备 Linux，创建模板时可点整行选择引擎。
- 工作区里即使有已移动的 Studio 目录，其他文件仍可打开。
- 编辑器助手默认跟随全局审批方式，也可以为当前工程单独设置，再切回跟随全局。
- 主助手可以把独立工作交给后台子任务，同时继续处理其他事项。展开进度摘要可查看或单独停止子任务，停止整轮会同时停止该轮子任务。

## English

- Select a filename below a reply to expand or collapse its saved changes inline. Earlier replies retain their original records.
- Game project files open in the IDE from chat. Run the game from the project home or the IDE. Games ready for on-device web playback can start without preparing Linux. Tap anywhere on an engine row to select a starter.
- Other workspace files remain accessible if a Studio folder has moved.
- Editor assistants follow the global approval setting by default. Set an override for a project or switch it back to the global setting.
- The main assistant can continue working while independent subtasks run in the background. Expand the progress summary to inspect or stop a subtask. Stopping the turn also stops its subtasks.
