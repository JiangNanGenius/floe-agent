# Floe Agent 1.8.49（370）

## 简体中文

游戏工作台将试玩放在首位。只有一个可识别游戏时自动选中目录和引擎。工程有多个可识别游戏时，可以选好目录后继续刚才的操作。修复首次试玩时误报助手已有历史运行、RPG Maker MV 标题画面黑屏，以及已发布的 Twine 网页无法打开的问题。更新了用户协议，已有的同意记录在后续升级时继续有效。

## English

Play is now the first action in the game workbench. The workbench selects the folder and engine automatically when it recognizes a single game. When it finds several games, choosing one continues the action you started. This update fixes a false assistant history warning on first play, a black title screen in RPG Maker MV, and playback of published Twine HTML stories. It includes the updated user agreement and remembers existing consent across future updates.
