# Floe Agent 1.7.43（284）

## 简体中文

- 快捷指令新增“运行定时任务”，可选择已有计划，并把对应运行交给查询、等待和结果动作。
- 计划列表新增系统定时设置入口，提供与计划时间、时区对应的设置步骤。
- 重复触发同一次计划时复用同一运行；改进中断、保存异常和完成状态的恢复。
- 修复系统动作摘要显示及单次计划设置步骤的文案。

定时自动化需要在系统“快捷指令”中设置并启用。执行时间和后台行为由系统决定。

## English

- Added Run Scheduled Task in Shortcuts. Select a saved plan and pass its exact run to status, wait and result actions.
- Added a system automation setup entry with the plan’s time and timezone.
- Duplicate triggers reuse the same run. Improved recovery after interruption, storage failures and task completion.
- Fixed the system action summary and one-time setup instructions.

Set up and enable time automations in the system Shortcuts app. Execution timing and background behavior are controlled by iOS.
