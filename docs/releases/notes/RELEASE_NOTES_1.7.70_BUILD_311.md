# Floe Agent 1.7.70 (311)

## 简体中文

- 本机运行环境升级为 ARM64，项目共用运行资源，并分别管理文件和依赖。
- 增加重新下载和恢复初始状态。恢复会重置运行环境及依赖，保留项目文件、聊天和已安装技能。
- 改进网页服务端口转发、运行状态和准备进度，修复升级后部分任务无法访问原工作区的问题。
- 完善技能管理与依赖准备，支持更新、回退和重新准备。
- 改进 Mac 上的 Bridge 配对、重试和连接状态；其他设备不显示 Mac 连接设置。

## English

- Upgraded the on-device runtime to ARM64. Projects share runtime resources while keeping their files and dependencies separate.
- Added re-download and Restore Initial State. Restore resets the runtime and dependencies while preserving project files, conversations and installed skills.
- Improved web-service forwarding, runtime status and preparation progress, and fixed access to managed task folders after App updates.
- Improved skill management and dependency preparation, including updates, rollback and re-preparation.
- Improved Bridge pairing, retry and connection status on Mac. Mac connection settings stay hidden on other devices.
