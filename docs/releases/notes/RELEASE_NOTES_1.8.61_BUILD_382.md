# Floe Agent 1.8.61（382）

## 简体中文

- 设置向导从「聊天与模型」添加对话服务。在「设置 → 通用」可以重新打开向导并回到上次进度。首次启动延后到实际使用相关功能时再请求定位。
- 联网搜索按所选服务检查配置，支持无需密钥的搜索服务。
- 目标模式从检查点恢复后会继续验证目标。普通轮次正在运行时可以恢复长期目标，等该轮结束后继续执行。
- 记忆会标出已删除的来源任务。自动整理也能归并重复的待确认记忆，生成的总结仍需确认。

## English

- The Setup Guide opens the chat-provider form from Chat & Models. Reopen the guide in General settings to continue from the saved step. Location permission is requested when you use a feature that needs it.
- Search setup checks what each service requires, including services that work without an API key.
- Goal mode returns to verification when a restored round finishes. Continue a paused Goal while a regular turn is running and it can advance after that turn ends.
- Memories show when their source task was deleted. Automatic organization can consolidate duplicate pending memories into summaries for review.
