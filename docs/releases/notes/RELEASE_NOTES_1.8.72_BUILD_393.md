# Floe Agent 1.8.72（393）

## 简体中文

- 确认升级 Linux 后，聊天会显示升级进度。尚未执行的命令会等待升级完成，并在核验原运行位置后从同一任务继续。
- 如果已在设置中开始升级，当前任务会等待同一次升级完成。

## English

- Confirming a Linux upgrade shows its progress in chat. Commands that have yet to start wait for the upgrade, then resume in the same task once the original execution location is verified.
- Tasks join an upgrade already started in Settings and wait for it to finish.
