# Floe Agent 1.7.39 (280)

## 简体中文

- 画中画背景音替换为冥想钢琴氛围曲，采用本地循环音源；保留原有音量、开关、播报和提示音设置。旧雨声／棕噪声设置会自动迁移。
- 修复 Office 画笔模式下的双指缩放入口，保留连续书写、原生矢量保存与手记封面链路。
- 本版本统一使用同一源码和归档产物交付内测、无签名 IPA 及 Feather；发布说明与版本元数据在标签冻结前完整提交。

本轮音频代码通过完整 App 编译和 45 项相关模拟器测试，Office 严格双指缩放／工具栏验收及五项实时笔迹、落点与保存／封面检查分别通过；这些测试不代表真实 Pencil 的压力、手掌防误触或设备手感验收。音乐听感、长期后台／锁屏行为仍待设备反馈。零移动点状笔迹，以及部分首次预览补生成提示仍在处理。

无签名 IPA 需自行签名安装，支持 iOS／iPadOS 26 及以上。各渠道实际可用状态单独核验；本说明不代表正式 App Store 上架。

## English

- Replaces synthesized PiP rain/brown noise with a bundled, looping meditation piano track. Existing volume, switches, narration and cues persist; retired choices migrate automatically.
- Repairs two-finger Office zoom while drawing mode stays enabled, preserving continuous writing, native vectors and the Notes cover pipeline.
- Internal TestFlight, unsigned IPA and Feather use the same frozen source and archived device artifact. Release copy and version metadata are committed before the source tag is frozen.

The audio change passed a full App build and 45 focused Simulator tests. Strict Office pinch/toolbar acceptance and five live-ink/placement/save/cover cases passed separately; they do not establish physical Pencil pressure, palm rejection or device feel. Musical preference and long background/lock behavior still need device feedback. Stationary ink dots and some first-open preview backfill messages remain under investigation.

The unsigned IPA requires signing for installation and supports iOS/iPadOS 26+. Availability is verified separately for each channel; these notes do not claim a public App Store release.
