# Floe Agent 1.8.73（394）

## 简体中文

- 在「设置 → 同步」里独立开启「与 Mac 同步会话」。
- 在「配对与共享」里添加 Mac，选择要共享的会话，并同步对方明确共享的聊天文字和历史消息。

## English

- Turn on Sync Conversations with Mac from Settings → Sync.
- In Pairing and Sharing, add your Mac, choose which conversations to share, and receive chat history that the other device has shared with you.
