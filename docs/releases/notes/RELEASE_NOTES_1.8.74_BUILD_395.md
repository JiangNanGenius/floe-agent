# Floe Agent 1.8.74（395）

## 简体中文

- 选定会话支持分页同步和断点续传，重复拉取会去重。
- Linux 设置向导显示实际校验和安装进度。任务网页服务中断后，可从原任务的预览重新启动。
- 自动纪要会补上录音结束时迟到的转写。Studio 将视频、字幕和工程导出保存到原工作区。
- 减少长会话中工具卡片状态的重复计算。

## English

- Sync selected conversations in batches, pick up after an interruption, and skip messages already received.
- Linux setup shows verification and installation progress. Restart an interrupted web service from its task preview.
- Automatic meeting minutes include transcript updates that arrive as recording finishes. Studio saves video, captions, and project exports to the original workspace.
- Reduce repeated work when updating tool cards in long conversations.
