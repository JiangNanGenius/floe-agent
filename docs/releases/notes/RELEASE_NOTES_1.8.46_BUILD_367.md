# Floe Agent 1.8.46（367）

## 简体中文

游戏工作区现在可以稳定地重新打开，工程导入和编辑器交接已修复，关闭试玩会话时不再卡住。首次试玩会继承你在工程中选择的根目录和引擎。批量导入工程时减少了重复的磁盘写入，引擎识别失败后可以重试。更新 App 后，Space 游戏的引擎选择和恢复记录仍会保留。首次使用时的用户协议已更新。

## English

Game workspaces now reopen reliably, with project imports and editor handoffs repaired, so closing a play session no longer hangs. The first play session inherits the root folder and engine you selected in the project. Importing projects in bulk now performs fewer duplicate disk writes, and a failed engine identification can be retried. After updating the app, Space engine choices and recovery journals are retained. The first-use agreement has been updated.
