# Floe Agent 1.7.45（286）

## 简体中文

- 新增系统分享入口，将链接、文字、图片和文件加入草稿，保留原有输入，由你决定何时发送。
- 新增任务小组件和“文件”中的 Floe 位置，改进文档打开、保存和冲突恢复。
- 补齐定时计划的快捷指令导入与结束后的清理提醒。系统时间自动化仍需在“快捷指令”中设置并启用。
- 扩展联系人、本地媒体、系统闹钟、只读健康查询和前台 NFC 读取；可用范围取决于设备、系统版本和授权。
- 改进 Office 指定范围和对象操作、公式验证、图表格式保留及项目符号显示。打印与 PDF 导出新增实际文件预览，并扩展 Excel 工作表、打印区域和缩放选项；修复导出后保存返回时退出及封面更新问题。
- 扩展媒体处理中的 HDR、透明度和目标帧率支持；增强模型的可用性以模型目录中的实际安装状态为准。
- 改进 Linux 有序软重启、不同任务的浏览器会话及子 Agent 中断恢复；结果不确定的写操作不会自动重放。
- 移除内部提示词页面中不完整的章节展示，保留版本、更新与回退操作。

- 修正健康与 NFC 的系统兼容配置。

## English

- Added a system share extension for links, text, images and files. Existing draft input is preserved; you choose when to send.
- Added task widgets and a Floe location in Files, with improved document opening, saving and conflict recovery.
- Added Shortcut import for saved schedules and cleanup reminders when a plan ends. Set up and enable time automations in Shortcuts.
- Expanded contacts, local media, system alarms, read-only health queries and foreground NFC reading. Availability depends on the device, system version and permissions.
- Improved Office range and object targeting, formula verification, chart formatting preservation and bullet rendering. Printing and PDF export now preview the actual file, with more Excel worksheet, print-area and scaling options. Fixed exiting after a PDF export when saving and returning, and updating the saved document cover.
- Expanded HDR, transparency and target frame-rate handling. Enhancement models are available according to their actual installation status in the model catalog.
- Improved orderly Linux restarts, task-owned browser sessions and interrupted subagent recovery. Writes with uncertain outcomes are not replayed automatically.
- Removed the incomplete chapter listing from internal prompt settings, retaining version, update and rollback controls.
- Corrected Health and NFC system compatibility declarations.
