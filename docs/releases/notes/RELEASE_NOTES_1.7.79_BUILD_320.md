# Floe 1.7.79 (320)

## 简体中文

- 整理浏览器地址栏与标签页：窄面板分行显示操作，给网址留出更多空间；保留标签页、全屏、下载和浏览器设置。
- 精简本机与远程终端的操作条，统一显示、剪贴板和快捷键菜单；端口入口合并到状态栏，给终端内容留出更多空间。
- 对话文件继续从原有检查器菜单打开，移除重复的独立文件夹按钮。
- 保留 319 的运行环境多核优化、存储空间提醒和终端启动修复，以及背景音音量恢复修复。

本构建用于 TestFlight，现有 315 正式版审核保持不变。性能收益因设备和负载而异。

## English

- Refined browser tabs and navigation. Narrow panels put navigation actions on a separate row to leave more room for the address, retaining tabs, full screen, downloads and settings.
- Streamlined local and remote terminal controls, with grouped display, clipboard and shortcut actions. Port management now sits in the status bar to leave more room for terminal output.
- Task files remain in the existing inspector menu; removed the redundant standalone folder button.
- Retains Build 319's local runtime multicore improvements, storage warnings and terminal startup fix, together with the background sound volume restoration fix.

This build is for TestFlight. The existing Build 315 App Store review remains unchanged. Performance gains depend on the device and workload.
