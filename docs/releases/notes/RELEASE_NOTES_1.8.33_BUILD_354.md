# Floe Agent 1.8.33（354）

## 简体中文

图片工作台把羽化放进选区边缘设置。可直接用 Apple Pencil 在画布上勾选、绘画或擦除。画笔和橡皮会遵守落笔时的选区与羽化边缘，重新打开项目后仍保留笔迹。

Linux 终端新增 OpenGL 和 OpenCL 检查。可以在当前 Debian ARM64 环境中离线安装加速工具，运行一次矩阵计算，并查看实际使用的设备。OpenCL 计算和视频编解码取决于当前环境中的驱动与设备。

游戏工作台增加了可创建和预览的工程。建筑项目也可从工作台打开，保存后继续编辑。

## English

The image workbench now groups feathering with selection edges. Use Apple Pencil directly on the canvas to select, draw or erase. Each stroke follows the selection and feathering in effect when you draw it and is preserved when you reopen the project.

The Linux terminal adds OpenGL and OpenCL checks. Install the acceleration tools offline in the current Debian arm64 environment, run a matrix calculation and inspect the device that performed it. OpenCL computation and video codecs depend on the drivers and devices available in that environment.

The game workbench includes more projects to create and preview. Building projects can also be opened, saved and edited again from the workbench.
