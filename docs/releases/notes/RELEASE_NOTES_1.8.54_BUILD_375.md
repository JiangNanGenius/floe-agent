# Floe Agent 1.8.54（375）

## 简体中文

聊天成批收到消息时会跟随最新内容，向上阅读时可以留在原处。修复旧对话中部分消息重复占用同一行标识的问题，减少长对话显示工具结果时的重复计算。

编辑器助手可以在自己的会话中设置审批方式。普通任务里创建的游戏可以直接从聊天记录试玩。Linux 环境安装 Python 包时减少了预编译等待。

## English

Chat follows incoming batches of messages while letting you scroll back to read. Fixed duplicate row identifiers in older conversations and reduced repeated work when displaying tool results in long threads.

Editor assistants provide access to the conversation’s approval settings. You can play games created in an ordinary task directly from its chat history. Python package installation in Linux spends less time precompiling bytecode.
