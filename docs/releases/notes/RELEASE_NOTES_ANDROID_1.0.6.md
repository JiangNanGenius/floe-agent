# Floe Android 1.0.6

## 简体中文

- Linux 任务遇到未经请求的清理动作时，助手可放弃尚未执行的命令，继续尝试保留文件的解决办法。需要用户确认的动作继续使用现有审批流程。
- 明确非交互终端的 POSIX shell 用法，减少目录创建和状态判断错误。
- 衔接 1.0.5 的计划转执行、进度重置、文件成果预览、轻量文本编辑和通知返回。

本版仍为自行分发预发布。复杂任务的规划和操作速度受模型影响；硬件能力和第三方应用的差异保留各自限制。采用完整安装包升级，兼容已有设置和数据。

## English

- When a Linux task proposes an unrequested cleanup, the assistant can abandon the command before execution and try an approach that preserves files. Actions requiring user confirmation continue through the existing approval flow.
- Clarifies the POSIX shell contract for noninteractive commands, including explicit paths and per-step exit-status checks.
- Builds on 1.0.5 plan execution, progress reset, output preview, lightweight text editing, and notification recovery.

Self-distributed prerelease. Complex planning and interaction speed depend on the configured model. Hardware and third-party application differences retain their individual limits. Updates use the complete installer and retain existing settings and data.
