# Floe Agent 1.8.75（396）

## 简体中文

- 配对设备可以同步选定会话的工作区文件。两端同时修改的文件会保留冲突副本。
- 已生效的引导会按发送时间显示为你的消息。长会话会补回已经滑出最近一页的引导。

## English

- Paired devices can sync workspace files for selected conversations. If a file changes on both devices, the incoming version is saved as a conflict copy.
- Guidance that reaches the model appears as your message at its original send time. Long conversations recover guidance that has moved beyond the latest message page.
