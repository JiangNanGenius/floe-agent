# Floe Agent 1.7.62（303）

## 简体中文

- 新增完整设置向导和四种推荐配置，逐步设置模型、搜索、语音、工作空间、记忆及同步。
- 语音包、模型和运行环境准备不阻塞设置流程，可继续下一步并稍后查看进度。
- 新用户的 Apple Intelligence 默认关闭，已有选择保持不变。
- 修复任务中安装技能的授权衔接，在当前会话处理需要的审批并继续安装。
- 完善 Skill Hub 列表图片、技能封面与详情展示。
- 完善网页创作结果导出和文件交付。

## English

- Added a complete setup guide with four recommendations for models, search, voice, workspaces, memory and sync.
- Voice packs, models and environment preparation no longer hold up setup; continue and check progress later.
- Apple Intelligence is off by default for new users, while existing choices are preserved.
- Fixed skill installation approvals within tasks, keeping required approvals and installation in the current conversation.
- Improved Skill Hub list artwork, covers and detail pages.
- Improved file export and delivery for web-based creative work.
