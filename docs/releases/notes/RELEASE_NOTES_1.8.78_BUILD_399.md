# Floe Agent 1.8.78（399）

## 简体中文

- 优化切回 App 和打开长会话的加载，后台任务状态会随当前运行结果更新。
- 提问和任务进度更新直接执行。审批模型默认关闭思考，可在「Agent 与权限」开启。
- 配对设备可同步用户附件。工作区文件的改名和删除可以单独开启同步，同步前会保留冲突版本。
- 游戏工作台加入原生运行支持。游戏可以从工作台或 IDE 运行，存档按工程保留。
- Studio 支持导入程序生成的像素帧并导出视频。语音接入 DeepSeek 流式输出。
- 更新 App 内图文帮助，补充工作台用途与操作步骤。

## English

- Return to the app and open long conversations more quickly. Background task status follows the current run outcome.
- Questions and task progress updates run directly. Approval model reasoning is off by default and can be enabled in Agent & Permissions.
- Paired devices can sync user attachments. Workspace rename and deletion sync has its own setting, with conflicting versions preserved.
- The game workbench adds native runtime support. Run games from the workbench or IDE, with saves kept per project.
- Studio can turn programmatically generated pixel frames into video. Voice playback supports DeepSeek streaming.
- In-app illustrated help explains what each workbench does and how to use it.
