# Floe 1.7.77 (318)

## 简体中文

- 新增设备存储空间提醒，显示可用空间和处理方法。保存或下载因空间已满失败时，释放空间后可重试。
- 启动时本地数据无法打开，会明确提示存储问题及恢复方法，不自动删除聊天、项目或技能。
- 修复终端正在启动时切换全屏导致连接取消的问题，保留主动结束和重新连接操作。
- 延续本机运行环境调度与背景音音量恢复修复，保留现有项目、文件和已安装内容。

本构建用于 TestFlight。多核效率仍在持续优化，不承诺固定性能提升。现有 315 正式版审核保持不变。

## English

- Added device storage warnings with available space and recovery guidance. Free up space and retry saves or downloads that failed because storage was full.
- Startup storage failures now explain how to recover. Chats, projects and skills are never automatically deleted.
- Fixed terminal startup being cancelled when switching to full screen, while retaining explicit stop and reconnect controls.
- Includes the local runtime scheduling and background sound volume restoration fixes, preserving projects, files and installed content.

This build is for TestFlight. Multicore efficiency remains under active optimization; no fixed performance gain is promised. The existing Build 315 App Store review remains unchanged.
