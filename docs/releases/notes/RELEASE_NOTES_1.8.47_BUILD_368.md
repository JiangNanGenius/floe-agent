# Floe Agent 1.8.47（368）

## 简体中文

游戏工程现在可以在本地导出源码 ZIP 并通过系统分享表分享。通过外部编辑器或 CI 进行远程构建前，会先请求你的授权。聊天中的游戏助手会话在应用重启后会自动恢复。Phaser 3.90 运行资源已内置在应用中（约 1.1 MB），离线可用。还为游戏引擎准备了 AI 工作流模板。

## English

Game projects can now export their source as a local ZIP and share it through the system share sheet. Starting a remote build through an external editor or CI now asks for your authorization first. Game assistant sessions in chat restore automatically after the app restarts. The Phaser 3.90 runtime is bundled in the app (about 1.1 MB) and works offline. AI workflow templates are also prepared for game engines.
