# Floe Bridge 1.1.2 (5)

## 简体中文

- 修复菜单栏设置窗口未出现的问题。
- 支持关闭设置后重新打开，并保留通用、存储和权限页面。
- 保留本机认证配对、终端、文件传输及自动更新。

## English

- Fixed the settings window failing to appear from the menu bar.
- Settings can be reopened after closing, with General, Storage and Permissions available.
- Retains authenticated local pairing, terminals, file transfer and automatic updates.
