# Android Alpha54 — live task history and compact phone controls

This intermediate candidate connects committed scheduled conversations to history refresh on both ordinary and late admission. A real foreground-lease settlement also invalidates history without polling. Base/archive rows and content-search matches have separate projections; refresh retains the current query, filter and selection, and stale query replies cannot replace current rows. Actual search snippets and durable pin values are preserved.

Phone typography, grouped spacing and switch visuals are adjusted through the existing design system. System font scaling and48dp touch targets remain; tablets retain their regular typography and split navigation. The batch passed37 focused regressions and actual Full/Play Kotlin compilation; physical acceptance remains pending, and visual parity is still under refinement.
