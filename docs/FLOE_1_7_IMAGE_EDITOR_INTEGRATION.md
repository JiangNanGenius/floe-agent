# Floe 1.7 图像编辑器集成

## 选型与来源

采用 [ZLImageEditor 3.0.0](https://github.com/longitachi/ZLImageEditor/tree/3.0.0)，固定提交
`6a0f56fb631a8b3f3e70c08895a3e71d921fd4cd`，MIT 许可，无额外包依赖。
源码位于 `FloeAgent/ThirdParty/ZLImageEditor`，许可证随 App 打包。
上游文件摘要和本地修改记录分别保存在 `upstream-sha256.json`、`FLOE_PROVENANCE.md`。

比较了 Mantis、SwiftyCrop（侧重裁剪）与 LWPhotoEditor（聚焦裁剪、绘制、文字）。
ZLImageEditor 同时提供裁剪、绘制、文字、马赛克、滤镜和调色，适合这次画布升级。

## 使用方法

选中一张本机图片 → 画布操作菜单 → **编辑图片**。

- 涂鸦标注与橡皮擦。
- 自由裁剪，以及方形、横竖 4:3 和横竖 16:9 比例。
- 文字贴纸，可修改文字、颜色并移动、旋转、缩放；支持中文。
- 马赛克、滤镜，以及亮度、对比度、饱和度调整。
- 顶部可以撤销、重做和查看原图；底部六个工具均显示图标与文字。
- 点击右上角 **完成**，直接生成 PNG 素材和关联原图的画布节点并返回画布；失败时保留编辑状态供重试。
- 编辑界面跟随日间／夜间主题，图像内容不受主题影响。

原图不覆盖。PNG 在保存前重新解码核对像素尺寸。画布切换或节点删除时，不将
成品插入错误的画布；已登记的素材保留在素材库中，可恢复插入。

## 明确边界

图片贴纸需要额外素材选择器，当前不显示该工具。文字和标注保存时合并为图片；
同一次编辑页面内可以继续编辑，尚不提供跨重启恢复的分层图像工程。
单张图片当前限制 2400 万像素、单边 16384 像素；超限明确拒绝，不静默降低原图质量。
上游默认的导出后 JPEG 压缩已移除，以保留 PNG 像素与透明度。
