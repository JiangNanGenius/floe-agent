# Floe iPad 图文指南与操作验收

2026-11-24，iPad mini（A17 Pro）Simulator，iPadOS 27.2，已安装的 Floe 1.8.72（393）调试构建。使用现有 iPad 横屏界面和合成测试素材。首次启动核对了用户协议页面，随后以应用的调试测试入口进入主界面。对应版本的发布源为 `258c0c51ffe59cd287d7db9188de440cce0f95e8`。

两轮共记录 23 个操作场景和 26 张截图。主要步骤已写入[使用手册](../USER_GUIDE.zh-CN.md)与[空间与专用工作台](../WORKSPACES_GUIDE.zh-CN.md)。手册按用途介绍各个工作台，详细讲解自由画布。Office 的逐步验收与成果截图保留在本页，中英文手册仅保留常用步骤和 PDF 预览要点。

## 操作逻辑

- **普通草稿进入临时会话时需要说明会发生什么。** 气泡展开后，已有文字移入临时会话，返回新建任务会按临时会话规则丢弃文字，附件留在原任务。源码确认这是为避免保留第二份持久草稿而设计的。现在入口只有图标，用户在动手之前难以知道文字会被移动。可在现有入口的说明或无障碍名称表达该行为。[步骤 3](#验证步骤) · [草稿转移实现](../../FloeAgent/FloeApp/Home/HomeLaunchpadViewModel.swift)
- **帮助首页的模型配置入口重复。** 393 的“快速开始”和“模型与设置”列出同一章节，且在 iPad mini 上同时可见。新版帮助包将该节保留在“模型与设置”，并添加会议和工具箱的直达条目。[393 帮助首页](../assets/guide/ipad-help-center.png)
- **优先改善 CAD 的模式反馈。** 关闭“触屏绘图”时，同一拖动手势用于浏览视图。首次打开矩形工具时，当前平面及工具已显示，绘图模式还要从小图标判断。建议在选工具或第一次拖动时提示当前是绘图还是平移。简体中文里的 `Choose a sketch plane`、`Exit Sketching` 和 `New Body` 也中断了中文操作步骤。[草图](../assets/guide/ipad-cad-sketch.png) · [二维开关](../assets/guide/ipad-cad-rectangle.png)
- **地图需要明确说明首次视野与导入失败。** 图层计数为 1，而全球视野看不到很小的面。选中具体图层并缩放后即显示，首次导入成功提示可以加入“缩放至图层”。截断文件被拒并且没有生成工程，适合把英文解析错误改成中文的“文件内容不完整，请重新导出或复制”。[首次可见结果](../assets/guide/ipad-map-fit.png) · [解析错误](../assets/guide/ipad-map-invalid.png)
- **Office PDF 的预览锁符合交付逻辑。** 更改范围后必须刷新，避免把旧范围的 PDF 分享出去。此前手册写成自动更新，已按实际按钮和状态修正。演示文稿的 `Duplicate Slide` 在简体中文里仍显示英文，已在手册并列说明，便于找到。[PDF 预览](../assets/guide/ipad-excel-pdf-refresh.png) · [复制幻灯片](../assets/guide/ipad-slides-duplicate.png)
- **“任务中心”进入后显示“工作台”。** 侧栏名称与页面标题不同，安排任务依赖无文字的日历图标。说明按侧栏实际名称书写；日历按钮可考虑加清晰的提示，方便首次使用。[步骤 4](#验证步骤)
- **保存结果可从作品返回核对。** 手记与画布用“返回／完成”回到各自文库并重开，Word 和视频有可回读的成果文件。会议保留左侧笔记和右侧转写、重点、助手，导入音频能回到底部播放器。这些路径与独立作品的产品设计一致。[产品说明](../../PRODUCT.md) · [操作步骤](#验证步骤)

## 离线帮助包初稿核验

1.3.0 内置资源和内容源各有 50 个文件，逐文件一致，每份 5,673,491 字节。使用 `python3 FloeAgent/scripts/build_help_content.py build` 生成后，`check` 确认输出可复现。两种语言原有章节锚点均保留，各新增的四个小节已进入对应索引和正文。

文档目录、帮助包生成与图像编码共通过 21 项 Python 测试。使用 Xcode 27.2（27B52）编译并运行 `FloeAgent/Qualification/HelpCore/run_help_core_qualification.sh`，Swift 帮助核心的 43 项检查全部通过，包括搜索、图片资源读取、索引和摘要校验。首轮遇到的文章数量断言已按旧版实际的 7 篇清单更新。
