# 统一 3D 与共享设计流程：迁移与恢复

状态：本页依据 **下一更新** 的源码候选编写（2026-10-11），尚未发布、尚未安装、尚未验收——你当前安装的版本可能不包含这些功能。不要在只有一份重要数据时仅凭本页直接迁移；安装状态以 [CURRENT_STATUS.md](CURRENT_STATUS.md) 为准。

相关文档：[使用手册](USER_GUIDE.zh-CN.md) · [Floe 1.7 迁移与恢复](FLOE_1_7_MIGRATION.md) · [设计流程](FLOE_DESIGN_WORKFLOW.zh-CN.md) · [设计流程工具契约](DESIGN_WORKFLOW_TOOLS.zh-CN.md)

## 1. 本次变更

- 3D 创建入口统一。画布顶部原来的两个 3D 创建按钮已移除；底部插入菜单（**+ ▸ 3D 模型（统一工作台）**）会在画布内创建一个原生 `.floecad` 模型节点，并打开与其他入口相同的全屏工作台。**3D 全景** 仍是独立的全景查看节点。
- 既有旧版 3D 场景节点**不会**因升级被删除或自动转换：在你明确打开编辑（首次编辑）之前，它保持只读预览。
- 设计流程的四个入口（创作起始、当前文件、原始聊天附件、画布节点）共用同一套流程与服务；不会新建主工作区、隐藏画布或平行副本存储。
- 原生 `.floecad` 节点和既有画布设计子文档不受影响：新增字段对旧数据解码为缺省，旧 `canvas.design*` 画布工具保持兼容。

## 2. 更新前

1. 记录当前版本与构建号（设置 → 诊断与关于）。
2. 导出重要文档和画布，并在 App 之外保留一份副本。
3. 在核对更新效果前，保留设备上的现有 App 数据，尤其是仍在使用旧版 3D 场景时。

## 3. 转换旧版 3D 场景（首次编辑）

1. 打开包含旧 3D 场景节点的画布，此时仍是只读预览。
2. 双击该节点（或使用其编辑操作）：这个明确动作就是首次编辑。Floe 会先校验整个场景。
3. 可以转换时：先在本机写入可恢复备份，创建一个画布持有的 `.floecad` 文档并完成转换，然后显示 **3D 场景迁移** 面板，列出已知视觉差异。从该面板打开工作台。
4. 被拒绝时：不会写入任何内容；面板列出具体不可用的值，节点保持只读预览。
5. 转换完成后先核对模型，再用 **应用到画布** 更新原节点，或用 **创建分支** 新建分支节点。核对结果前请保留 App 数据。

## 4. 转换保留与不保留的内容

保留：节点 ID、名称、位置、尺寸和连线；各对象的位置、旋转、缩放、颜色/粗糙度/金属度与隐藏状态；相机位置/目标/FOV；灯光与背景。五种旧图元（圆角方盒、球体、圆柱、圆锥、平面薄板）会成为工作台毫米单位下的真实网格（旧版米 ×1000）。

不伪造：转换不会编造参数化特征树或建模历史——结果是普通几何体，与其他图元一致。导入的 DWG/DXF 图纸不同：其二维图元仍可编辑，而 3D 图元、块、外部参照、样条和代理内容保持只读。图纸不是原生 3D 模型，并非所有 3D 文件都可编辑。

写入前即拒绝（原件保持不变）：非有限数值、零/负或超范围缩放、无效颜色/相机/灯光值、重复对象 ID。

## 5. 已知视觉差异

- 光照：强度按工作台比例归一化并有界；精确原值保留在场景备份中。
- 阴影：以平面地面投影近似旧版方向光阴影贴图。
- 曲面为细分网格；旧版圆角为真实几何，弦高误差有界。

光照与阴影两项差异都会显示在迁移面板中，并随转换后的文档记录，重新打开时仍可核对。

## 6. 出现问题时

- 保留原件：排障期间不要删除 App 数据、画布备份或迁移备份。
- 重试：可重试的失败会复用同一个已预留文档；不会产生部分提交的节点。
- 反馈时附上：安装版本/构建号、画布与节点名称、界面提示，以及可公开的脱敏截图。

## 7. 设计流程数据

- 既有画布设计工程仍是节点的画布子文档，没有迁移步骤。
- 文件、聊天附件与创作入口通过既有构件权威保存设计信封。原文件/附件保留；只有 Floe 可写入的来源才会就地更新，否则结果以新内容返回（聊天附件会在原任务中返回为新附件）。
- 采纳必须由你在面板中明确确认，并且只发送到原始任务（没有来源任务的目标只能直接采纳）。确认授权一次性有效：App 重启后不会保留，已认领的尝试失败后也需要重新确认。来源在冻结后发生变化时，候选会以修订冲突被拒绝；手动修改和晚到结果都会保留，不会静默覆盖。
- 只有实际接通的能力才提供“生成首个结果”（目前是已配置模型时的图片生成）；Floe 不能生成的输出类型不作承诺。生成结果未知时不会自动重新提交——需明确放弃未知尝试才能重新生成；生成期间设计发生变化时，结果会保留，可绑定到当前修订。

## 8. 更新后核对

1. 旧 3D 场景节点在编辑前仍以只读预览打开。
2. 用一份测试场景（副本，或可承担转换的场景）验证：出现迁移面板并能打开工作台。
3. 既有原生 `.floecad` 节点与画布可打开；转换进行中切换画布文档时，结果只会在原文档中出现，不会改动新选中的文档。
4. 文件预览 → **设计流程** 可在可写工作区文件上打开；带文件/图片附件的消息出现聊天附件菜单；任何采纳前都会请求确认。
5. 服务商配置保持并可保存；待处理的 iCloud 同步可重试，无需重新输入密钥。
