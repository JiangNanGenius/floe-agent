# 3D 仿真与动画代码推进记录

更新：2026-11-08（保留各批次原验证边界）。执行范围见[预研发计划](FLOE_3D_PHYSICS_CAE_ANIMATION_PREDEVELOPMENT_PLAN.zh-CN.md)。本批优先铺开各域代码，完成原生组件与相关代码检查，不进行上游全量数值资格重验证。

## 已落代码

- `FloeSimulationKit` 包含 Core、Geometry、Physics、Animation、Engineering、Fields、Runtime、UI 和 Samples 九个模块。
- Rapier 固定至 0.36.1，完成 Mac arm64、iphoneos arm64、iOS Simulator arm64 分片及 Swift 调用链。当前包装覆盖刚体、碰撞、关节/驱动、运动学关键帧、规则柔体、粒子与力场；柔体拓扑单独保存，避免逐帧重复。
- 现有 tet4 静力和稳态热已经进入统一请求、结果、单位和保存路径。高级结构、流体、声学、电磁、射频和耦合已经建立配置、边界、验证及驱动接合接口。
- 第二批完成 Netgen 6.2.2507 与 MFEM 4.8 的 Apple arm64 原生分片、C ABI 和 Swift 实际调用。iOS 的 B-rep 路径只复用既有 OCCT 7.8.1，macOS 使用带标签封闭曲面路径。
- 动画图支持关键帧层、骨骼/FK/IK、物理绑定、相机与 Morph；物理缓存和动画求值共用采样，运动可烘焙并导出数据。
- UI 与工具使用同一提交工作区，编辑通过代次比较，计算使用来源和研究修订围栏；任务由服务持有，取消后等待原生工作实际结束再放行队列。
- 结果按字段分块、校验和及原子提交保存，可索引、重开、分页查询和导出。新增独立 iPad 宿主，保留现有 App/CAD 并行修改。
- 网格服务接通尺寸、局部细化、进度、停止与保存；来源面对应精确体单元面，避免曲面节点集合把端盖误加为载荷面。共用网格及复材子材料改变时使所有受影响研究失效。
- UI 与 AI 使用同一默认配置。AI 可读取完整参数/实体模板、SI 材料参数名、区域/源面与边界范围，再创建、编辑、运行、读取实际结果和导出。序列化写入参数包含上次读取的代次，避免宿主刷新上下文后覆盖较新编辑。
- 新增项目会话注册表，面板和工具复用同一模型；关闭工作区等待原生工作返回，旧模型/工具停止写入。重开较新几何时清除旧网格绑定，保留历史结果，拒绝把旧动画预览套到新来源。
- 第三批接入实际 App 的 CAD 工具栏、Space 原件与注册工具 `studio.simulation`。由真实 CAD 生成带身份的源快照，仿真结果使用现有 CAD Metal 渲染器；位置/旋转与动画缓存按源对象原点绑定，结果不回写 CAD 几何。动画可选实际零件名称、播放、烘焙并导出 JSON。
- CAD 修改同步禁止旧结果继续作为当前结果展示，求解开始与保存结果时再次核对宿主来源；关闭项目合并并发关闭请求，保存待提交设置、等待原生停止，再释放文件归属。源文件及仿真伴随目录的整理/删除受同一会话守卫约束。
- 重开时复用 CAD 已校验的持久化 B-rep 档案，不重新序列化同一实体作为身份；显示网格和临时命名缓存不进入该实体的几何摘要。曲面路径按实际缓冲区、对象与放置计算身份，面分组从保存的网格派生，避免保存/移动后的误过期和边界面改名。
