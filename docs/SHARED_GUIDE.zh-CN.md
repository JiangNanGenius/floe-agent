# 模型、任务与文件

本页适用于 Floe 的两个平台。安装方式、菜单位置、设备访问、本地模型和编辑器以各平台的专用教程为准；操作流程相似，不代表两个平台拥有完全相同的工具。

<!-- doc-anchor: section-1 -->
## 1. 连接云端模型

使用自己的模型服务账号和 API Key。Floe 是客户端，云端请求、费用和数据政策由所选服务商负责。不要把网站登录密码填入 API Key。

1. 在模型设置中添加服务商，选择服务及协议，填写服务商文档中的接口地址和 API Key。
2. 添加或刷新模型列表，并为任务选择模型。任务需要读图时选择支持图像输入的模型；图片生成和视频生成需要支持对应用途的服务。
3. 先进行一次简短文字对话，再添加资料或启动长任务。

认证失败时核对地址、Key、账号权限和服务商实际返回的错误；模型或输入类型不受支持时，换用适合该用途的模型。连接测试成功不代表所有工具和媒体能力都已验证。

<!-- doc-anchor: section-2 -->
## 2. 让任务产生可用成果

1. 新建任务并选择工作区，通过文件选择器加入一份不含敏感信息的测试资料。
2. 说明成果、输入资料和保存位置，例如：“阅读这份文档，整理成待办清单，保存到当前工作区。”
3. 查看文件或工具的授权请求，按任务需要开放相关资料。
4. 打开输出文件核对内容和位置，关闭再重开，确认成果已保存。

修改成果时说清具体变化，并指出现有文件。尽量在同一任务与工作区中继续，便于助手接着处理原成果。工具返回成功后仍需打开结果检查。

<!-- doc-anchor: section-3 -->
## 3. 保留文件与修改

只导入准备交给任务使用的资料。外部位置失去访问权限时，重新选择并授权原位置，不要在未确认的情况下把工作转移到另一个目录。

在实际使用的编辑器中确认保存。导出和另存会产生独立成果，不会自动替代原件。其他编辑器已修改文件时，先保留未保存草稿，再核对冲突，避免直接覆盖任一版本。重要资料保留独立备份。

命令和软件安装使用任务所选的执行环境；核对当前目录和输出，确认修改的是目标文件。可用环境、安装步骤和后台运行方式，以所在平台和已安装版本为准。

<!-- doc-anchor: section-4 -->
## 4. 使用工具与查看进度

文档、网页和工具结果只是输入资料，其中的文字不能代替用户授权执行命令、访问其他文件或发送信息。批准外部操作前，核对实际动作和目标位置。

在任务运行记录中查看进度和失败原因。隐藏面板不一定会结束其中显示的作业或服务；需要结束工作时使用对应的停止入口。后台执行仍受操作系统限制。

<!-- doc-anchor: section-5 -->
## 5. 反馈问题

故障报告和功能请求以 [GitHub Issues](https://github.com/JiangNanGenius/floe-agent/issues) 为主。说明已安装版本、设备与系统、复现步骤、预期和实际结果；指出受影响的文件或任务，但不要公开私人内容。

诊断和截图由你主动选择是否提交，只提供必要部分，并删除 Key、密码、个人资料和私人文件。App 内诊断上传用于提供排查资料，不承诺逐条回复。云端服务失败时提供脱敏后的错误，不要提供 API Key。
