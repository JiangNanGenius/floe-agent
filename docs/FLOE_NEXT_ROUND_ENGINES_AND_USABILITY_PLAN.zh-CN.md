## 空间与文件的操作方案

空间保留“概览、手记、文件、工具箱”结构和原有外层分栏。概览上方使用可横滑的常用入口，下方按现有工作台关系呈现功能目录，宽屏可两列，窄屏单列。最近项目显示实际内容预览、名称与上次使用信息，点击回到同一原件。具体分组和排序在界面候选中核对，避免借首页改版另造一套菜单层级。

文件页继续使用路径、文件夹和文件列表。列表与网格共用选中身份，长按菜单提供“选择”，并保留单项操作；进入选择后点击条目用于勾选，明确显示数量、全选当前结果、取消和批量删除。搜索和目录切换需要清楚界定选择范围，禁止不可见条目被静默追加到删除集合。

批量删除沿用最近删除，覆盖文件和文件夹，去除父子项重复选择。先逐项检查编辑占用、修订、关联资源及后台任务；已有 CAD／仿真 sidecar、会议录音、化学作业和生物项目的生命周期规则继续有效。操作展示实际成功与失败项，未删除项保留以供处理；取消或失败不能先丢原件。批量恢复及返回原目录同时验收。

## 历史与快捷复用

连接工具区分三类内容：过去填写的目标与参数、保存的连接配置、一次实际运行的结果。页面下方首先提供目标与参数历史，并标示上次使用时间；常用项可固定、单项移除或清空。去重与排序依据工具、协议、规范化目标和相关参数，不把不同端口、DNS 类型或请求方法混成同一项。

| 功能组 | 可复用内容 | 再次操作 |
| --- | --- | --- |
| Ping、路由、DNS、端口、局域网发现 | 目标、端口／记录／服务类型及相应检测参数 | 从历史快速再次检测，也可先载入修改。 |
| 漫游与 Wi-Fi | 最近探测目标、间隔、已保存的追踪记录 | 默认仍跟随当前可取得的网关；手动目标优先，历史目标不能覆盖用户输入。BSSID 变化、缺失与观察间断分别展示。 |
| HTTP、WebSocket、MQTT、串口助手 | 可保存的地址、协议配置、订阅和消息模板 | 先恢复配置；发送、发布与写寄存器仍由用户当前操作或既有授权任务触发。 |
| 终端、VNC、远程文件、浏览器 | 既有已保存机器、位置与会话恢复信息 | 复用原机器和环境绑定；临时机器继续按原不保存策略，禁止因快捷入口自动执行历史命令。 |
| 其他工作台 | 最近项目、导入来源、明确保存的机器／分析／导出预设 | 复用各领域已有对象和服务；不把所有历史塞进一个无上下文列表。 |

历史不保存密码、令牌、认证头、Cookie 或包含凭据的 URL／请求体；显示用的目标由允许保存的字段构成，凭据继续引用现有钥匙串或凭据服务。执行与结果依旧绑定当前请求，不把旧成功当成新结果。历史失败也可帮助用户修改后重试。

## 会议录音 转写与助手

录音、实时转写、纪要和会议助手是可以同时工作的能力。录音持有原音频和时间轴；转写消费录音数据；助手读取当前会议并按自然语言提问、整理笔记和待办。提问与修改由模型识别，用户不需要切换两种助手模式。

优先检查实际麦克风权限、音频路由／中断、PCM 写入、分段队列、识别服务选择、积压与失败恢复，再检查转写提交、去重和重开。为录音与转写分别显示状态；ASR 失败时保留录音并提供靠近当前上下文的重试入口。临时服务忙与配置缺失采用不同处理，不能每段反复打断用户，也不能无限重试未确认的外部请求。

当前默认 15 秒分段不等于持续的文字流。需要测量实际首字和后续更新延迟，评估现有流式能力或适当缩短分段；待确认文字与已保存正文分开，不用虚构时间戳。停止录音后结清尾段，剩余识别允许继续，保存和重开保留对应录音、时间及来源。

M4 针对性复核覆盖：开始录音并得到真实转写；边录边向助手提问／修改笔记；打开关闭侧栏与键盘；暂停继续；一次服务失败后的恢复；停止后的尾段保存重开。先采集能区分原因的日志，再按实际改动增加检查。Device Hub 的视频流／输入错误独立保留，不直接当作会议 App 转写故障的根因。

## 绘图输入与内容预览

所有涉及草图和绘制的编辑器采用相同规则：鼠标主键及 Apple Pencil 在已选绘图工具下默认编辑；手指绘图开关只控制手指。默认手指用于导航，已有明确保存的选择予以保留；开启后按当前工具绘制，关闭后仍能正常选择、平移与缩放。不能因为用过一次 Pencil 就暗中修改鼠标或手指行为。

该规则覆盖二维 CAD、三维 CAD 的平面草图、化学结构、绘画／图片、原有画布及其他支持绘制的面板。三维相机、对象选择、数值输入与控件操作沿用相应工具逻辑，不把关闭手指绘图解释成禁用触屏。各编辑器保留自己的选择、会话和撤销；统一输入约定不合并编辑状态。

橡皮擦按领域擦除真实内容：化学为原子／键等结构，CAD 为草图实体，笔迹为已有笔迹对象。工具状态、命中反馈、取消、撤销重做和保存回读要一致，不能只画一条遮盖线当作删除。

| 内容 | 预览应显示的内容 |
| --- | --- |
| 文档、PDF、手记 | 实际页面或可读正文，沿用已有受保护的 PDF／Office 路径。 |
| 图片、绘画、混合画布、图示 | 当前内容缩略图、画布或节点局部，点击放大。 |
| 视频、音频、音乐 | 视频实际画帧／片段；音频实际波形、时长，必要时提供简明测量值。 |
| CAD、建筑、Mesh | 实际几何与当前视角；草图有二维预览，工程图有实际页面。 |
| 加工、打印 | 实际工件／刀路／层和结果入口，切片结束进入名为“预览”的页面；保留原切削仿真问题账。 |
| 化学、生物 | 结构、谱图、序列、图像、网络与适用结果图，随真实对象类型显示。 |
| 物理、有限元与动画 | 几何／网格、结果场、图例和单位，或动画关键帧及播放；历史结果标明所属来源。 |
| 工具箱与其他组件 | 适用的曲线、表格、记录摘要或内容快照；无需图像的内容保持可读，不为每一行强造图片。 |

预览同时覆盖工作台内部素材、子对象和计算结果，不限于文件封面。手机／窄屏优先保留可看清的主预览，参数、列表和 AI 使用可收起面板；键盘不能盖住关键按钮。生成采用按需、有界、可取消缓存，按对象修订失效；过期、失败和未准备好的预览有明确状态，打开预览不能隐式启动分析或修改原件。

## 模型工具链的完整核查

这项覆盖整个 App 的当前可用能力目录，并对全部新增模块逐功能展开。检查工具类型声明、注册、动态发现、用户配置／模型能力过滤、参数、授权、运行器、结果展示和持久化的真实路径。通用工具的多个 action 也逐项列账，不能用“已有 studio.run”盖住内部未实现能力。

每个可由模型操作的功能建立同一组记录：

1. 实际 UI 功能及当前原件／项目／任务身份。
2. 模型当前能获得的工具名、参数及读写分类，是否被错误过滤。
3. 当前状态和内容的读取，包括选中对象、修订、分页及输入格式。
4. 观察能力：结构化数据、实际图片／视口或波形，及可访问的产物引用。
5. 参数与编辑如何进入同一服务、撤销／修订校验和真实原件。
6. 计算／导入／导出的实际后端、环境和任务归属。
7. 进度、状态、取消与实际退出确认，迟到结果如何拒绝。
8. 结果取回、图像／数值解释、保存、重读及打开同一原件。

| 功能族 | 本轮重点审查 |
| --- | --- |
| 文件、项目与通用工作区 | 有效目录、作用域和文件引用；列出、读取、预览、整理、删除／恢复及返回。 |
| 手记、会议与录音 | 当前会议绑定、笔记读写和回读、转写来源引用、录音和波形观察、助手与采集并行。 |
| 旧画布、混合画布、图示、交互内容 | 实际内容／选区、允许编辑的对象、预览、运行结果与保存；避免生成孤立的第二份编辑状态。 |
| 图片、绘画、视频 | `studio.media` 的实际可执行清单、素材导入、时间线／选区、图像观察和导出；目录中未实现的命令逐项补齐或如实描述，不能伪装为可执行。 |
| 音乐与通用音频 | 已有 `inspectAudio` 和 `AudioWaveformInspector` 继续复用；核对音乐之外的会议／视频音轨及授权音频是否也能被模型观察，不能只会播放／转写而无法检查波形。 |
| CAD 二维、三维、建筑、Mesh、渲染 | 几何／草图／属性读写、选择和单位、实际视口观察、任务与导出；托管原件不用猜测文件路径。 |
| 加工与 3D 打印 | 机床／打印机、工艺、材料与路径配置，真实几何计算，进度取消、切削／分层预览及已有结果读取；不以重复计算替代读取。 |
| 化学原生及环境计算 | `studio.chemistry` 与环境工具的能力、对象修订、配置、计算、状态、取消、结果应用和导出各自可达。 |
| 生物 | 适配器注册一次并将授权后的有效描述加入模型目录；22 个工具逐项映射实际 App，UI 的 AI／工具／计算／插入手记回调接真实服务。 |
| 物理、动画与 CAE | `studio.simulation` 的定义、对象、材料、研究、网格、运行、查询、字段、取消和导出；UI／AI 使用同一几何快照与保存会话。 |
| 工具箱全部入口 | 终端、连接、浏览器、远程文件、诊断、漫游、编码与记录服务分别核查；历史复用不绕过当前任务和连接身份。 |
| 其余既有工具 | 现有文档、媒体、浏览、设备、环境、安装、调度、推送及其他已注册族按实际目录盘点，检查过滤、运行、回包和结果消费的缺口。 |

每条记录分别标注“已接且有证据”“已接待验证”“发现缺口”“确实不适用”，附具体断点和负责人。开始、取消、保存等会改变状态的操作继续使用既有权限；临时会话保持只读，过期修订、跨项目和未知命令仍拒绝。生物科学作业复用解析后的 Linux 环境与 `exec.shell`／jobs；物理与 CAE 按其已确定方案原生计算，不另造解释器或主机回退。
