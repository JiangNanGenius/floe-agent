Floe Agent 1.7.30 (Build 271), bundle org.floeagent.ios, is an iPad-first workspace with iPhone support.

No Floe account or demo login is required. Files, Notes, Canvas and manual media/drawing editing can be reviewed without an AI provider. Optional cloud AI uses a tester-supplied provider key; no provider credit is included. No purchase or Linux environment download is required for the manual review below.

Suggested review using synthetic files:
1. Open an image from Files or a Canvas node. Use the media workbench to edit layers, selections, drawing or color, undo/redo, save, reopen and export. Canvas owns its editor drafts and adopted results; making a variant is an explicit action.
2. Import short videos, arrange the main track, trim clips, adjust captions/music, preview and export. Narrow layouts use drawers; full screen preserves the editing session.
3. Open a supported two-dimensional DWG or DXF drawing. Use the existing drawing editor to select objects, draw or modify supported geometry, inspect layers, measure, save a copy and reopen it. Unsupported objects or formats show capability limits. Three-dimensional drawings remain view-only. PDF/PNG exports are presentation copies, distinct from editable drawing files.
4. Open Drawing Assistant from the drawing. Without a configured model, AI unavailability is shown. With a configured provider, changes are proposed for review and confirmation; document changes invalidate outdated proposals. Asking a question does not itself overwrite the original drawing.
5. Open a Canvas node and choose Design workflow from the Canvas menu (More). Save a brief or specification, freeze the node's current content with Use current node content, review a proposed revision, then Adopt or Reject. Assistant adoption requires the explicit Authorize assistant adoption action. Export verified exports only the recorded format and reopens it with the real parser first. No provider is required for the local freeze/export path.
6. Create a native 3D model from the bottom insertion menu (+ > 3D Model). Orbit/zoom, switch views from the orientation cube, enter fullscreen, change the camera there and tap Done: the presenting viewport keeps that camera and the face controls keep targeting the visible model. Then save, close and reopen the model; cancelling a new untouched model from fullscreen removes the unsaved work instead of leaving it behind. An existing legacy 3D scene node keeps a read-only preview until an explicit first edit migrates it after a recoverable backup and a known-differences notice; the original node is unchanged until you apply a result.
7. Open Notes or supported Office documents. Available editing operations depend on the document and engine. Read-only or unsupported operations are identified rather than reported as completed edits.
8. In Settings, Storage diagnostics shows read-only size estimates (logical vs allocated, clone/estimate labels) and a cleanup section limited to explicitly registered, task-owned candidates; scanning never deletes user data. Optional provider configuration can be tested and saved. Connection testing and saving are separate actions. No credentials are included with the app or required for the manual steps above.

Please use synthetic content and redact credentials/private information from feedback. This beta does not claim universal DWG/Office compatibility, professional HDR mastering, or engineering certification. On-device background work may be suspended by iOS. Optional provider results and physical-device performance remain subject to testing.
