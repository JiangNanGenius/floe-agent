Floe Agent 1.7.62 (Build 303)

Floe uses the user's configured AI providers. No Floe account or demo account is required. Paid cloud AI and speech require the reviewer's own provider settings; no provider credentials are included. Existing formal App Store submissions are unchanged.

This beta expands the native setup guide. Recommendations prefill choices but do not skip sections or automatically download models, enable permissions or make paid requests. The guide can be exited and resumed. Downloads, verification and installation do not block Next or completion. Resources are shown as ready only after installation succeeds. System limits still govern background execution.

Apple Intelligence is off by default for new users. Unsupported devices can configure other providers and complete setup. Existing settings are preserved.

Skill installations requested in a task use its existing approval policy. When approval is required, it appears in the owning conversation. Approving continues the same installation. Official catalog entries retain signature, digest and compatibility checks. External imports retain their applicable review. Installation does not grant broader future device or account access.

Suggested checks: open setup and select a recommendation or Custom; visit all groups and leave optional settings for later. Start an optional resource download, continue immediately, exit and return to see its progress. Check the final overview and Skill Hub native covers/details. Ordinary Notes, Files and Canvas can be explored without a paid provider. Cloud-generated output is not required for these setup and navigation checks.
