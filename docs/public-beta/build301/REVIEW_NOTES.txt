Floe Agent 1.7.60 (Build 301)

Floe is a task assistant using the user's configured AI provider. No Floe account or demo account is required. AI responses and cloud image/video generation require the reviewer's own provider configuration; no paid provider credentials are included.

Skill Hub now opens with featured cards and categories. Swipe the featured row, inspect a skill and use Get to review its source and requested capabilities. Installed skills support inline multiple selection and shared update actions. Bundled skills are protected from deletion; externally installed skills can be removed. Rollback appears only when an actual backup is available. Reviewed official skills may prepare their declared dependencies for the selected local Linux task environment. External skills keep the existing task permission controls.

Settings > Models and providers offers forms for chat, image and video providers. Each form shows the fields and model choices supported by its integration. Saving a configuration does not request paid generation. The chat composer supports wrapped long text and an expanded editor. Tool activity indicates when a tool call is being prepared. The terminal supports the task's existing local Linux or remote environment.

Settings > Background execution separates Enhanced background, Background audio, Picture in Picture and Screen feedback. Enabling a dependent option enables its prerequisites. Background audio provides user-selected ambient music, volume, narration and cues during eligible work. Picture in Picture shows task progress, or screen feedback while recording is actually active and authorized. Task Center > Background work starts or stops a user-initiated work session for the current queue and enabled plans. iOS may interrupt background execution; the app does not guarantee exact scheduled start times. Background location assistance ends when no eligible task or service owns it. Image results offer Save to Photos and request photo-library permission only when used.

Suggested checks: browse Skill Hub, swipe featured cards, inspect an installed entry and enter inline selection; open provider creation and compare chat/image/video forms; enter a long draft and expand it; start and stop background work while observing the task state. These beta changes do not publish or replace the existing formal App Store submission.
