## Floe Agent 公开 Beta 审核演示说明 / Public Beta Review Walkthrough

Baseline: version 1.7.0, build 178, previously delivered to internal Floe QA. Public/external Beta review has not been submitted.

基线：1.7.0（178），此前已交付 Floe QA 内部 TestFlight；尚未提交公开／外部 Beta 审核。

Build 184 (beta.41) is undergoing cloud qualification and is not uploaded. Build 183 passed dependency and module gates but failed App compilation in the CAD cover bridge; this candidate repairs that transfer and revalidates cloud-job queries. Build 178 remains the latest confirmed internal TestFlight release. Earlier unsuccessful candidates and their original evidence remain recorded.

184（beta.41）正在云端验收，尚未上传。183 通过依赖与模块检查，但在 CAD 封面桥接处编译失败；本候选已修复异步传递并强化云任务状态回读。178 仍是最后确认的内部 TestFlight 版本；此前失败候选及原始证据均已保留。

Floe is an iPad-first workspace for AI tasks, Notes, documents and creative canvases, with iPhone compatibility. Cloud providers are configured by the user.

Floe 以 iPad 为优先，整合 AI 任务、手记、文档与创意画布，同时兼容 iPhone；云端模型由用户自行配置。

No developer-funded AI key or cloud credits are included. Apple Foundation Models and downloaded local models have different capabilities; the reported iPad downloaded-model chat crash still requires re-testing.

不提供开发者付费 Key 或云端额度。Apple Foundation Models 与下载的本地模型能力不同；已报告的 iPad 下载模型聊天闪退仍需复核。

Use the separate two-page file Floe-公开Beta送审示例.pdf for import, handwriting, search and selection exercises.

另附两页「Floe-公开Beta送审示例.pdf」，用于导入、手写、搜索及选区练习。

## 01  开始与导航 / Start and navigate

Open the app. The main sidebar provides New Task, Task Center, Notes, Creative Mode and Plugins. Settings is at the lower left.

打开应用。主侧栏包含新建任务、任务中心、手记、创意模式和插件；设置在左下角。

Notes is a separate document workspace above Creative Mode. Its files and undo state are independent of a chat task or canvas.

手记是独立文档空间，入口位于创意模式上方；文件和撤销状态独立于聊天任务与画布。

Use synthetic or backed-up files. Grant file, photo, microphone or other permissions only for the operation being exercised. Declining an optional permission should leave unrelated features usable.

使用示例或已备份文件。按实际操作授予文件、照片、麦克风等权限；拒绝可选权限不应影响无关功能。

Start on iPad, then repeat compact navigation and full-screen editing on iPhone. Pencil-specific checks require compatible physical hardware.

先检查 iPad，再在 iPhone 重复紧凑导航和全屏编辑；Pencil 专属操作需要兼容真机。

The delivery supports iOS/iPadOS 26 compatibility. Version 27 native interfaces depend on the actual build SDK and device availability.

保留 iOS/iPadOS 26 兼容；27 原生接口取决于实际构建 SDK 与设备可用性。

The owner reports that Apple Foundation Models work. Downloaded MLX models have passing real-weight macOS host diagnostics, which do not establish iPad chat stability. Record the final review build, exact model and hardware before relying on this path for review.

用户报告 Apple Foundation Models 可用。下载的 MLX 模型已通过 macOS 真实权重宿主测试，但不代表 iPad 聊天稳定。采用该路径送审前需记录最终构建、具体模型与硬件。

## 02  手记资料、导入与搜索 / Notes library, import and search

In Notes, open the cover library and create a note or import the supplied PDF. Opening a document should enter full-screen editing. Return to the library without deleting the document.

在手记封面列表中新建笔记或导入示例 PDF；打开文档应进入全屏编辑，返回列表不会删除文档。

Use + → From Floe Workspace to import a document generated by a conversation or project. The imported copy is managed independently by Notes.

通过「＋ → 从 Floe 工作区导入」选择会话或项目生成的文档；导入副本由手记独立保存。

Search for lantern garden 472 or 星河手记验证 from outside the editor. The supplied PDF should match page 1 after indexing. Check the snippet and source location.

在编辑器外搜索 lantern garden 472 或「星河手记验证」；索引完成后应命中示例 PDF 第 1 页，检查摘要与来源位置。

Switch document tabs and return to the original page. Closing a tab must not delete its document. Collapse the title/tab header while keeping writing tools available.

切换文档标签后返回原页面；关闭标签不得删除文档。收起抬头／标签栏时保留书写工具。

## 03  画笔、选区与保存 / Pencil, selection and persistence

Tap the active pen or color control to choose among eight native brush styles and adjust color, width and transparency. In the candidate, 0% transparency means solid ink; each brush retains its own values and preview.

点击当前笔或颜色控件，选择八种原生笔型并调整颜色、粗细和透明度；候选版的 0% 透明度表示实心，各笔型独立保存参数和预览。

Finger drawing is a separate option. With Pencil-only input, use a finger for navigation rather than adding ink. Write on the sample, switch documents, then reopen.

手指书写是独立选项。仅 Pencil 书写时，手指用于导航；在示例中书写、切换文档，再重新打开检查保存。

A compatible Pencil squeeze toggles the tip tool arc. Tap a tool to confirm; moving or lifting the tip alone must not commit. Squeeze again or tap outside to dismiss. Arc placement is configurable.

兼容 Pencil 捏压切换笔尖工具弧；轻触工具确认，移动或抬笔不直接切换。再次捏压或点空白关闭，可设置工具弧位置。

Use lasso for ink operations and AI selection for a page region. Ask a question only with a model that can process the selected content. Physical squeeze behavior remains for device acceptance.

套索用于笔迹操作，AI 选区用于页面区域提问；仅用具备相应能力的模型处理所选内容。真实捏压仍需真机验收。

## 04  PDF、Office 与导出 / PDF, Office and exports

Import the sample PDF, navigate pages, add ink, undo and redo, then close and reopen. Check that original page content and saved annotation placement are retained.

导入示例 PDF，翻页、添加笔迹、撤销与重做，再关闭重开；检查原页面内容与批注位置是否保留。

Select a region containing both background and annotation. The assistant must identify the source document/page and use only the permitted context. Text extraction is not equivalent to image understanding.

选中同时包含背景与批注的区域；助手应保留文档／页码来源并使用授权上下文。提取文字不等于理解图像。

Open a backed-up Word, spreadsheet or presentation file from Notes in the integrated Office editor. Make a small edit, save, exit and reopen. Check whether the change survives.

从手记打开已备份的 Word、表格或演示文件，进入集成 Office 编辑器；小幅修改、保存、退出并重开，核对改动。

Switching away from Office should not silently discard an unsaved or failed save. If a format cannot be written, the app must report the failure rather than claim successful persistence.

离开 Office 时不得静默丢弃未保存内容或保存失败；格式无法写入时应明确报错。

Export an annotated PDF and reopen the actual output in another viewer. Compare page count, text, orientation and annotation placement. Use the editable Notes archive when editability must be preserved.

导出带批注 PDF 后用其他阅读器重开实际文件，比较页数、文字、方向与批注位置；需要继续编辑时使用手记可编辑归档。

Word pen markup, broad format conversion and presentation playback require their own final-build acceptance. Do not describe the app as guaranteeing Microsoft Office-level fidelity. Excel enhancement is deferred.

Word 画笔、广泛格式转换与放映需分别完成最终构建验收，不承诺 Microsoft Office 级格式保真；Excel 暂缓增强。

Acceptance example: add a short bilingual paragraph, save twice, reopen and verify both languages. Keep originals and report any conversion loss.

验收示例：添加简短中英文段落，保存两次后重开核对；保留原件并记录任何转换损失。

## 05  AI 访问与实际能力 / AI access and actual capabilities

Cloud models use the user’s own provider configuration and key. This review preparation includes no developer-funded text, vision or image-generation credits.

云端模型使用用户自己的提供方配置与 Key；本审核准备不提供开发者付费的文本、视觉或生图额度。

Downloaded local models currently expose text and a restricted tool set. The public inference path omits direct vision. Apple Foundation Model tools are separately restricted to Apple capabilities.

下载的本地模型目前提供文本及受限工具集合，公开推理路径不开放直接视觉；Apple 系统模型的工具另限制在 Apple 能力内。

For local review, choose an installed supported model, ask a short text question and inspect a permitted tool operation. Record the model and supported device; do not imply that all Agent tools are available.

本地演示应选已安装的受支持模型，进行短文本提问和允许的工具操作；记录模型与设备，不暗示全部 Agent 工具均可用。

Before a no-cloud demonstration, ensure that the selected operation does not silently call a paid auxiliary model, search provider or other service.

无云端费用演示前，确认所选操作不会隐式调用付费辅助模型、搜索服务或其他服务。

For cloud features, supply exact setup instructions and a genuine recording as supplementary evidence. Do not assume the reviewer will purchase credits or bring personal credentials.

云端功能提供准确配置步骤及真实操作视频作为补充；不假定审核员会购买额度或提供私人凭据。

Local inference and video do not automatically satisfy review of every cloud feature. If Apple requires additional access, explain the BYOK architecture and seek an accepted arrangement before submission proceeds.

本地推理与视频不自动满足全部云端功能审核；若 Apple 要求额外访问，需解释 BYOK 架构并确认认可的安排。

Do not hide features during review, fabricate model output, embed a shared upstream key or advertise a free hosted AI service that is not provided.

不在审核时隐藏功能、伪造模型输出、内置共享上游 Key，或宣传并未提供的免费云端 AI。

## 06  Agent 任务与交互 / Agent tasks and interaction

Create a task and send a short request. Subsequent messages continue that task with visible execution records. Select the intended workspace/environment before a file or code operation.

创建任务并发送简短请求；后续消息延续任务并保留执行记录。文件或代码操作前选择目标工作区／环境。

Before tokens arrive, the status should say Waiting for model response. Reasoning uses its own stable-height box. Earlier consecutive tool groups collapse as the next round begins.

首个响应到达前应显示「等待模型响应」；思考使用独立且高度稳定的框。进入下一轮后，前面的连续工具组自动折叠。

Inspect tool name, progress, result or error. Stop an active operation, then verify that another task can run and that cancellation does not leave misleading success output.

检查工具名、进度、结果或错误。停止运行后，确认其他任务可继续，取消操作不得显示误导性的成功结果。

Supplementary recording: floe-real-agent-demo-build175.mp4 shows the actual Build 175 Agent using Ark DeepSeek to create and read back review-demo.md, then completing successfully. The key was configured privately and is not supplied to reviewers. Later-source qualification remains separate.

补充录屏 floe-real-agent-demo-build175.mp4 展示真实 Build 175 Agent 通过火山引擎 DeepSeek 创建、回读 review-demo.md 并成功结束任务。Key 在录屏外配置，不提供给审核人员；后续源码仍单独验收。

Unknown commands and failed operations must report useful errors. Tool availability reflects actual enabled/configured capabilities; unconfigured search providers must not appear as usable choices.

未知命令和失败操作应报告有效错误；工具可用性反映实际启用与配置状态，未配置搜索不得表现为可用。

Cloud visual questions require a compatible configured model. Saved capability overrides and model settings should survive relaunch without pressing Save again.

云端读图需配置兼容模型；模型能力覆盖与设置应在重启后直接生效，无需再次点击保存。

For a multi-step request, the assistant should create or update its checklist early and report meaningful progress. Queued follow-up messages can be withdrawn or edited before insertion; check that withdrawn text is never sent.

多步骤请求应及早建立或更新任务清单，并报告有意义的进展。排队的引导消息在插入前可以撤回或编辑，需检查已撤回内容不会发送。

## 07  画布、导图与媒体 / Canvas, mind maps and media

Create a canvas, add content and reopen it. Test folders, content search, moving and deletion; deleted canvases should not reappear in Recent or private lists.

新建画布、添加内容并重开；检查文件夹、正文搜索、移动和删除，已删除画布不应重新出现在最近或私人列表。

Canvas assistant state is separate from Notes assistant state. Check the compact panel, voice entry, generation cancellation and access only to the selected material.

画布助手状态独立于手记助手；检查面板尺寸、语音入口、停止生成及仅访问已选择资料。

Create a standalone mind map, add topics and images, then edit branches. Layout should reflow as content changes. A map may also be attached to a document or opened in a PDF window.

独立创建思维导图，添加主题与附图并编辑分支；内容变化时应自动排版。导图也可关联文档或在 PDF 小窗中打开。

For image editing, use a disposable image to check crop, drawing, text, mosaic, filters and color controls. Save and reopen the produced file; compare actual pixel content.

图像编辑使用测试图片，检查裁剪、涂鸦、文字、马赛克、滤镜与颜色参数；保存重开产物并比较像素内容。

For video, use a short test clip to check trim, captions, export settings and cancellation. Reopen the export and compare duration, orientation, audio and subtitles.

视频使用短测试片段，检查剪裁、字幕、导出参数和取消；重开产物比较时长、方向、音频与字幕。

Advanced media/model catalogs are not a promise of installed or verified inference. Unsupported combinations must fail clearly; the app is not presented as a full professional multitrack editor.

高级媒体／模型目录不代表资源已安装或推理已验证；不支持的组合需明确失败，不宣称完整专业多轨编辑器。

## 08  语音、运行环境与网络 / Speech, environments and network

Start the optional Whisper Small download, leave Settings and return later. Check resumed progress and successful installation before dictation. Use Mandarin, English and a simple mixture.

开始可选 Whisper Small 下载，离开设置后再返回；检查继续下载及安装成功，再用普通话、英语与简单混合语音听写。

Whisper is the preferred local path; Apple speech recognition is the fallback when unavailable or unsuccessful. Apple fallback may use system services, so not every speech path is offline.

Whisper 优先走本地，不可用或识别失败时回退 Apple 语音识别；Apple 回退可能使用系统服务，不能把所有语音都描述为离线。

Open Settings → Execution Environments. Select the actual project/session environment and inspect dependencies, usage, package tasks and errors. Install only compatible supported packages.

打开「设置 → 执行环境」，选择实际项目／会话，查看依赖、容量、软件包任务与错误；仅安装兼容且受支持的软件包。

Environment layers separate dependencies, files and lifecycle; they do not provide strong process isolation for in-process native code. Stopping/deleting an environment must respect task ownership.

环境分层隔离依赖、文件与生命周期，并非同进程原生代码的强安全隔离；停止／删除环境需遵守任务归属。

Use Shell for apt commands and pip/npm/pnpm installation. Node.js and the JavaScriptCore fallback are identified separately. Package-manager selection belongs to the current environment; conflicting project lockfiles require an explicit choice.

在 Shell 中使用 apt 及 pip/npm/pnpm 安装命令，Node.js 与 JavaScriptCore 回退分别标识。包管理器选择属于当前环境；项目锁文件冲突时需明确选择。

A local Node or Python preview server is an owned service. Closing a browser preview does not imply stopping it. Stop it from service management; task/environment termination must stop only the corresponding owned workers.

本地 Node 或 Python 预览服务器由服务系统管理。关闭浏览器预览不等于停止服务；可在服务管理中关闭，任务／环境终止时只停止所属服务。

Direct HTTP/API and HTTPS paths can operate without opening browser UI. Browser panels should open automatically only for explicit human-interaction handoff. Keep TLS verification enabled.

直接 HTTP/API 与 HTTPS 可不打开浏览器界面；只有明确请求人工交互时才自动呈现浏览器面板，保留 TLS 校验。

The official signed APT catalog and the full package/model catalog are not fully delivered. Do not confuse working PyPI/npm cases with a complete Linux software ecosystem.

官方签名 APT 目录及完整包／模型目录尚未完全交付，不把部分 PyPI/npm 用例可用等同于完整 Linux 生态。

## 10  IDE 与工程图纸 / IDE and engineering drawings

In build 178 and the current candidate, open a workspace file, then use Open in Editor to expand the full-screen IDE. Use the file tree, tabs, code editor and existing document editors. Syntax highlighting does not imply that every programming language can execute locally.

178 与当前候选版中，打开工作区文件，再通过「在编辑器中打开」进入全屏 IDE，使用文件树、标签、代码及现有文档编辑器。语法高亮不代表所有语言都能在本地执行。

When an Agent changes a file while the user is editing, preserve the user draft, compare the file version and review overlapping changes before overwriting. Independent edits can be merged; conflict copies remain recoverable.

Agent 与用户同时编辑文件时保留用户草稿、比对文件版本，并在覆盖前检查重叠修改；独立修改可以合并，冲突副本可恢复。

Open synthetic DXF or DWG drawings. Basic line, circle and text edits, undo and saving are supported by the candidate. Reopen the exported drawing. Complex entities and full-fidelity DWG round trips are not claimed.

打开示例 DXF 或 DWG；候选版提供直线、圆、文字等基础图元编辑、撤销与保存。导出后重新打开检查，不承诺复杂图元和完整 DWG 无损往返。

STEP, IGES and BREP provide bounded read-only mesh previews. Mesh and supported Gerber/Excellon previews are viewing tools, not full 3D or PCB editors. Native KiCad project support is not yet qualified.

STEP、IGES、BREP 提供有资源上限的只读网格预览；网格及已支持的 Gerber/Excellon 查看器不属于完整 3D 或 PCB 编辑器，原生 KiCad 项目尚未验收。

Ask AI opens a review form containing the actual viewport and bounded drawing metadata. A configured model is required only when sending the question. With no selected chat, sending creates a review task. A text-only model must not be described as having inspected the image.

「询问 AI」打开包含实际视口与有界图纸信息的审图表单，发送问题才需要已配置模型。没有选中聊天时，发送后创建审图任务；纯文本模型不能被描述为已看过图片。

Native RDP connection and certificate checks have separate qualification evidence. RDP host settings, viewer and Agent registration are incomplete and are not offered as usable App features in this candidate. Existing VNC is independent.

原生 RDP 连接与证书检查有独立验证证据，但 App 主机设置、查看器和 Agent 注册尚未完成，本候选版不将 RDP 声明为可用功能；已有 VNC 独立保留。

## 12  云端构建与重开恢复 / Cloud builds and relaunch recovery

Connect your GitHub account in Settings. In the full IDE, choose GitHub Actions cloud build, then explicitly select the repository, base branch and workflow and review the source snapshot. Cloud builds use your own GitHub account and allowance.

在设置中连接自己的 GitHub 账户。完整 IDE 中选择 GitHub Actions 云端构建，明确选择仓库、基础分支和工作流并查看源码快照；使用自己的 GitHub 账户与额度。

Installing a Floe template is a separate visible action on the default branch and may require workflow authorization at sign-in. Existing workflows are not overwritten. Cloud output is a Linux/macOS build artifact, not an installable iOS executable.

安装 Floe 模板会明确写入默认分支，可能需要登录时授予工作流权限；不会覆盖已有工作流。云端产物属于 Linux/macOS，不能当作 iOS 本机可执行文件安装。

Start a small build, close the panel and reopen the App while GitHub is still running. The existing run should reappear and update automatically. The App polls while active and re-reads unfinished records on foreground; remote CI continues while the App is closed.

开始一个小型构建，关闭面板并在 GitHub 仍运行时重开 App；原任务应重新出现并自动更新。App 在前台轮询，回到前台时回读未完成记录；关闭 App 不会停止远端 CI。

No model sleep loop is needed. An uncertain submission must not create duplicate runs. Cancel remains pending until GitHub confirms the result. Read the job log and download a non-expired artifact; a digest mismatch must leave existing files unchanged.

无需模型循环等待。提交结果不明时不能重复触发；取消需等待 GitHub 确认。读取日志、下载未过期产物；摘要不匹配时必须保留原有文件。
