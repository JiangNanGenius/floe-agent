Floe Agent 1.7.65 (Build 306)

This beta improves message editing, browser tabs, native 3D editing, tool-result recovery and task execution environments. Existing formal App Store submissions are unchanged.

Floe uses the user's configured AI providers. No Floe account or demo account is required. Cloud chat, search, images, video and speech require the reviewer's own provider settings; no provider credentials are embedded. Saving a provider does not generate paid media. Explicit connection tests may consume the selected service's allowance. Listed plan models do not establish account entitlement, and calls do not silently switch billing channels. DeepSeek is added as a search provider.

Long messages wrap to the available width, keep the caret visible and can open an expanded editor. Browser tabs and website settings use the existing browser. Advanced website data access is off until the user explicitly confirms its disclosure risk: data used by an assistant may be sent to the user's configured model service. It can be disabled in Settings. Browser and tool access remains subject to task permissions; temporary chat retains its public-web/read-only boundary and memory-only content.

Native 3D modeling runs locally. Open Creative Mode, open or create a Canvas, then create a 3D Workbench document from its add menu. Sketches, solid features, selection, materials, assemblies, drawings and simple keyframe animation can be edited without a paid AI provider. Edit and Present share one document; the non-AR Present view does not require camera access. Textures use Files or the system photo picker. Save/reopen retains geometry and appearance. Export formats preserve their documented capabilities. An assistant can edit only its bound documents, with ownership, revision, undo and save checks; it cannot gain access merely by supplying an arbitrary path.

A saved task's menu offers its execution environment. New defaults do not move existing tasks. Moving a task checks destination access, dependencies, files and current operations before committing the new binding. An interrupted or uncertain remote operation is not automatically replayed. Local built-in features remain available without downloading Linux. External commands need a ready on-device environment, configured SSH host or the optional same-Mac companion. Companion installation and connection are user-initiated.

Suggested checks: enter a long message and expand/return; open browser tabs and inspect advanced-data confirmation; use in-chat Find; inspect a schedule's countdown, details and Skip. Assistants can ask ordinary questions in conversation cards; answers do not grant tool permissions. With a local CAD document, change dimensions, undo/redo, edit a material, preview an assembly or animation, save/reopen and export. None of these manual CAD checks requires paid AI generation. Existing Notes, Files and setup navigation remain available without a paid provider.
