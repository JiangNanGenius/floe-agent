Floe Agent 1.7.2 (Build 243), bundle org.floeagent.ios, is an iPad-first AI workspace with iPhone support.

No Floe account or demo login is required. Notes, document organization, PDF annotation, and Canvas can be reviewed without an AI provider. Cloud AI is optional and uses a provider key supplied by the tester; the app includes no provider credit. Downloaded MLX models are optional Beta features. Apple’s system model is a separate path when available.

Suggested review:
1. Open Notes, create a note, annotate a sample PDF, close and reopen it, and confirm the content persists.
2. Open the IDE in a file workspace backed by a Git repository. Check that the Git pane and compact sidebar sync controls describe that workspace’s repository state.
3. If you configure your own AI provider, read a long task history across pages and confirm that continuation remains available. Cancel a running task and check that it ends in a recoverable state.
4. In optional local-model testing, use a negated instruction such as “do not call web.search” and check that it does not force a search.

The app’s core review does not require network AI access. Please use synthetic documents and redact private content and credentials from feedback. The existing in-app feedback flow can include optional diagnostics or images after the tester submits them.
