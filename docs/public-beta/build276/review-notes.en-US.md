Floe Agent 1.7.35 (Build 276), bundle org.floeagent.ios, is an iPad-first workspace with iPhone support.

No Floe account is required. Files, Notes, Canvas and manual document editing can be reviewed without an AI provider. Steps that run an assistant task need a provider configured by the reviewer; cloud AI uses a tester-supplied key and no provider credit is included. No purchase is required for the checks below.

Suggested review:
1. Open a Word, Excel and PowerPoint file (synthetic copies), add ink in different colors and widths with the visible toolbar, save, close and reopen each file. The strokes should remain and stay editable. Apple Pencil pressure and palm rejection need a physical device; the visible tool menu works without Pencil Pro hardware.
2. Open a presentation with a chart. Change a category name, a value and a Chinese label, add a data series and then remove one, save and reopen. The chart should show the edited values and the other chart data should stay intact. The embedded engine may normalize chart styling or default fonts.
3. On iPad, type a long message in the composer and expand the input field. Send the message, open Notes, then return to the conversation: the sent text should be cleared and any newly typed unsent text should remain.
4. Open an attachment from a conversation, edit it, and return to the same conversation. Check the message and attachment ownership are unchanged. Open an HTML attachment in the IDE, start and stop the local preview, and confirm the conversation is not cancelled by stopping the preview.
5. With a provider configured, ask for a short local task and open the generated document or image. The first local-environment use may download a prepared Linux image and needs network access and storage. Document editing itself does not require a provider.
6. Send feedback from Settings with a device description; remove private content and credentials from screenshots.

Limits: some Office formatting may change when saving, and chart embedded-workbook defaults or unused styles may be normalized. Physical Apple Pencil feel and palm rejection remain device checks. Local tasks and previews are ordinary app features, not a general remote desktop or a native-code security boundary. Simulator and component results do not replace physical-device acceptance.
