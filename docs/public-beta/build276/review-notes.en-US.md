Floe Agent is a free workspace for iPad and iPhone. Cloud AI is optional and uses the user's own provider configuration; the app does not include provider credit.

This update improves Office handwriting, presentation chart editing, iPad text entry, attachment navigation and local task execution.

Suggested checks with sample files:
1. Open Word, Excel or PowerPoint, add ink with different colors and widths, save and reopen.
2. In a presentation chart, change a label and value, add or remove a data series, save and reopen. Chinese labels are supported.
3. On iPad, type a long message and expand the input field. With a provider configured, send a message, visit Notes and return. Sent text stays cleared and a new unsent message is retained.
4. Open an attachment from a conversation, edit it and return to that conversation. An HTML file can be opened in the IDE for local preview.
5. With a provider configured, ask for a short local task and open the resulting document or image.

Document editing does not require an AI provider. Local previews and tasks may download a prepared Linux image on first use and require network access and available storage. Some Office formatting may change on save. Apple Pencil pressure and palm rejection require a physical device.

Feedback is optional and is submitted from Settings. No Floe account is required.
