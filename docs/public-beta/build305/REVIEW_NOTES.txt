Floe Agent 1.7.64 (Build 305)

This beta improves provider setup and native 3D editing. It retains the setup guide, optional same-Mac companion, speech tools and existing privacy controls from Build 304. Existing formal App Store submissions are unchanged.

Floe uses the user's configured AI providers. No Floe account or demo account is required. Cloud chat, images, video and speech require the reviewer's own provider settings; no provider credentials are embedded. Saving a provider does not generate paid media. An explicit subscription connection test sends a small request to the selected chat model and may consume that plan's allowance. Listed plan models are candidates, not proof of account entitlement; tests and media calls never silently switch billing channels.

Native 3D modeling and material editing run locally. To explore without a cloud provider, open Creative Mode, open or create a Canvas, and use its add menu to create a 3D Workbench document. The engineering editor offers sketching, solids, selection, history and materials. The same document can switch between Edit and Present; Present uses a non-AR scene and does not require camera access. Material textures are selected through Files or the system photo picker. Library entries are copied into the document so removing a personal-library entry does not remove an applied material. Geometry, appearance and presentation settings are saved together. GLB and PNG export are available; engineering exchange formats retain their existing format limits.

The assistant operates within the current task's permissions. Ordinary document edits retain ownership, revision and save checks. Canvas CAD access is limited to the documents bound to that assistant; an arbitrary path does not grant access. Temporary chat retains its existing read-only boundary. Text-only local models use geometry queries and measurements rather than claiming visual inspection.

Suggested checks: add or edit a subscription provider and choose a candidate without using model discovery; separately test the selected chat model. With a CAD document, change a dimension, use Undo and Redo, open Material, adjust a colour or finish, switch to Present, change the environment, save/reopen and export. These local editing checks do not require paid AI generation. Existing Notes, Files and setup navigation remain available without a paid provider.
