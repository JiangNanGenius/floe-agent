Floe Agent 1.7.24 (Build 265), bundle org.floeagent.ios, is an iPad-first workspace with iPhone support.

No Floe account or demo login is required. Files, Notes, Canvas and manual media/drawing editing can be reviewed without an AI provider. Optional cloud AI uses a tester-supplied provider key; no provider credit is included. No purchase or Linux environment download is required for the manual review below.

Suggested review using synthetic files:
1. Open an image from Files or a Canvas node. Use the media workbench to edit layers, selections, drawing or color, undo/redo, save, reopen and export. Canvas owns its editor drafts and adopted results; making a variant is an explicit action.
2. Import short videos, arrange the main track, trim clips, adjust captions/music, preview and export. Narrow layouts use drawers; full screen preserves the editing session.
3. Open a supported two-dimensional DWG or DXF drawing. Use the existing drawing editor to select objects, draw or modify supported geometry, inspect layers, measure, save a copy and reopen it. Unsupported objects or formats show capability limits. Three-dimensional models remain view-only. PDF/PNG exports are presentation copies, distinct from editable drawing files.
4. Open Drawing Assistant from the drawing. Without a configured model, AI unavailability is shown. With a configured provider, changes are proposed for review and confirmation; document changes invalidate outdated proposals. Asking a question does not itself overwrite the original drawing.
5. Open Notes or supported Office documents. Available editing operations depend on the document and engine. Read-only or unsupported operations are identified rather than reported as completed edits.
6. In Settings, optional provider configuration can be tested and saved. Connection testing and saving are separate actions. No credentials are included with the app or required for the manual steps above.

Please use synthetic content and redact credentials/private information from feedback. This beta does not claim universal DWG/Office compatibility, professional HDR mastering, or engineering certification. On-device background work may be suspended by iOS. Optional provider results and physical-device performance remain subject to testing.
