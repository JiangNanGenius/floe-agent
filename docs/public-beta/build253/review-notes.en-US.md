Floe Agent 1.7.12 (Build 253), bundle org.floeagent.ios, is an iPad-first AI workspace with iPhone support.

No Floe account or demo login is required. Notes, document organization, PDF annotation, and Canvas can be reviewed without an AI provider. Cloud AI is optional and uses a provider key supplied by the tester; the app includes no provider credit. Downloaded MLX models are optional Beta features. Apple's system model is a separate path when available.

Suggested review:
1. Open Notes, create a note, annotate a sample PDF, close and reopen it, and confirm the content persists.
2. Tap the microphone in a chat. During setup, a progress indicator appears. Speak at an ordinary volume and check that the waveform follows the microphone input. Stop and start again.
3. If a verified Linux guest image is installed, open a Linux environment and ask the assistant to inspect its CPU count and start it with three guest cores, then start a second one-core guest if the device has enough memory. The assistant should inspect the guest state before using the shell. This build allows four guest cores in total, with at most three in one guest; older two-core images remain capped at two. A running guest may require a hard restart to change its core count; this is optional for core review.

Notes drawing covers recover after a temporary viewer failure or a library scroll/relaunch. The app's core review does not require network AI access or a Linux guest download. Please use synthetic documents and redact private content and credentials from feedback. The existing in-app feedback flow can include optional diagnostics or images after the tester submits them.
