Floe 1.8.10 (332)

简体中文
本次更新改进编辑器助手与普通聊天的区分、任务状态提示、会议录音字幕和说话人标记、工具箱操作，以及三维草图页导入。

建议检查：
1. 打开一份作品并进入其 AI 助手，再返回普通聊天列表，确认不同作品和普通聊天保持独立。
2. 在已配置的模型服务中发送消息，检查回复结束、失败和等待处理时的提示；可打开原聊天查看原因和继续入口。
3. 打开会议录音，检查字幕与说话人标记；离开时分别选择继续、取消离开和停止，确认录音及返回流程。
4. 打开工具箱中的水平仪、二维码和路由跟踪。IP 信息库在设置中由用户下载，下载后可查看对应地区和网络信息。
5. 在三维 CAD 中进入草图，导入 DXF/DWG；也可选择本 App 的二维 CAD 项目和其中一张草图，检查加入当前草图、实际尺寸、取消和一次撤销。只复制图形，源项目及其尺寸约束和关联保留。

此次提交仅用于 TestFlight 测试，不替换现有正式 App Store 版本。

English
This update improves separation between editor assistants and ordinary chats, task-state feedback, recording captions and speaker labels, toolbox actions, and imports on the 3D sketch page.

Suggested checks:
1. Open a work and its AI assistant, then return to the ordinary chat list. Conversations for different works and ordinary chats remain separate.
2. Send a message using a configured model service. Check completion, failure and pending states, then open the original chat to review its reason and available continuation.
3. Open a meeting recording and check captions and speaker labels. When leaving, try continuing, cancelling departure and stopping, then check the recording and return flow.
4. Open the level, QR tools and Traceroute. Users download the IP information database from settings before viewing region and network information.
5. Enter a sketch in 3D CAD and import DXF/DWG, or select a 2D CAD project in Floe and one of its sketches. Check insertion into the current sketch, actual size, cancellation and one-step undo. Only geometry is copied; the original project, dimensions, constraints and links remain in the source.

This submission is for TestFlight testing and does not replace the existing App Store release.
