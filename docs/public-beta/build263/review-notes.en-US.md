Floe Agent 1.7.22 (Build 263), bundle org.floeagent.ios, is an iPad-first AI workspace with iPhone support.

No Floe account or demo login is required. Notes, document organization, PDF annotation and Canvas can be reviewed without an AI provider. Cloud AI is optional and uses a provider key supplied by the tester; the app includes no provider credit. Downloaded MLX models and the Linux environment are optional Beta features. Apple's system model is a separate path when available.

Suggested review:
1. Open Notes, create a note, annotate a synthetic PDF, close and reopen it, and confirm the content persists.
2. Open a chat's browser panel, enter a public HTTPS address, expand to full screen and return. The same page remains open. During user takeover, the assistant can continue other authorized work but cannot click, type or navigate the browser. Returning control saves a notification for the original task; an ended task requires an explicit Continue action.
3. Open the local terminal. If Linux is not installed, a visible install prompt appears. If installed, verify Chinese output, line wrapping, font and keyboard controls, and full-screen transitions. Services and terminals use the selected environment. Stopping a VM asks for confirmation about affected sessions; saved disk data and port rules remain.
4. Port management is shared across Settings, browser, terminal and service views. Rules distinguish saved configuration from actual listening ports. Local-only is the default; LAN forwarding uses the existing permission policy. Forwarding does not start a web server or configure router/public internet access.
5. Open a long conversation, load earlier messages and expand a long tool result. Older output is displayed in bounded sections without changing model context policy.

Core review does not require network AI access or downloading a Linux image. Services run on device and are not guaranteed to continue while iOS suspends or terminates the app. Please use synthetic documents and redact private content and credentials from feedback. Optional diagnostics and images are submitted through the existing in-app feedback flow.
