Floe Agent 1.7.41 (Build 282), bundle org.floeagent.ios, is an iPad-first workspace with iPhone support.

No Floe account or demo login is required. Notes, local Office editing and PDF annotation can be reviewed without cloud AI. Optional cloud AI requires the tester's own configured provider; no provider credit is included.

Please test consecutive Office pen strokes and two-finger zoom, with drawing enabled or disabled and the assistant sidebar open. Use a synthetic document, explicitly save it, return to Notes and reopen it to inspect the saved content and ink. The permanent Document Commands form has been removed.

Shortcuts can start a task and use its run reference to query status, wait for a bounded interval, cancel or retrieve final text from that same run. AI task execution requires a configured provider and model.

Known beta limitations: some Office assistant edits fail parameter validation, and Office edits may require an explicit save. Automatic saving and assistant-requested viewing of document regions beyond the visible page are being addressed in the next build.

Optional PiP background music has four local tracks and an adjustable volume. Raise the in-app music volume to hear playback. Music, narration and cues have separate controls.

This beta submission leaves the existing formal App Store submission unchanged.
