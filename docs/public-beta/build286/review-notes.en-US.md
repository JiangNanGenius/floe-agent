Floe Agent 1.7.45 (Build 286), bundle org.floeagent.ios, is an iPad-first workspace with iPhone support.

No Floe account or demo login is required. Notes, local Office editing and PDF annotation are available without cloud AI. Optional AI tasks use the tester's own configured provider; no provider credit is included.

In Notes, create or import a synthetic Excel workbook, edit cells and add ink. Print and Export PDF open output options and a generated preview. Excel supports worksheets, cell or print regions, paper, orientation, margins, scaling and final PDF pages. Generate the preview, inspect pagination, then print or share/save that same output. Return to Notes and reopen the workbook to inspect saved content and its preview.

System features include document sharing, Home widgets and a native scheduled-task Shortcut template. Add the Shortcut, select an existing Floe schedule in the Shortcuts editor and save it. Time-based personal automation is configured and controlled by the user in Apple's Shortcuts app. Ending a schedule offers cleanup guidance for its external Shortcut. AI execution requires a configured provider and model.

Optional Health access is read-only; NFC scanning runs in the foreground on supported hardware. Permission denial is supported. Optional PiP music has local tracks and adjustable in-app volume; raise that volume for audible playback. Music, narration and cues have separate controls.

Physical Pencil feel, real printers, hardware-specific capabilities and unattended system scheduling are part of beta testing. Please use synthetic files and redact private content in feedback. This beta leaves the existing formal App Store submission unchanged.
