Floe Agent 1.7.23 (Build 264), bundle org.floeagent.ios, is an iPad-first AI workspace with iPhone support.

No Floe account or demo login is required. Notes, files, Canvas and manual media editing can be reviewed without an AI provider. Cloud AI is optional and uses a provider key supplied by the tester; no provider credit is included. No purchase is required for the manual review below.

Suggested review:
1. Import a synthetic image in Files, open Media workbench, add text or drawing layers, adjust crop/color, undo and redo, save the project, close and reopen it from the project list. Original media is retained.
2. Export PNG or JPEG with explicit dimensions. The workbench verifies the file and exposes the result for sharing/saving. Unsupported transparency/format combinations show an error.
3. Import short synthetic videos, arrange the primary track, trim/change speed, add music or a caption, preview, and export H.264. Wide iPad uses side panels and a bottom timeline; narrow layouts use drawers. Full screen retains the editing session.
4. Open the AI drawer without configured models: it clearly reports unavailability. Configured cloud generation shows model, materials and parameters before confirmation; generated media is a candidate until accepted. Video jobs use the existing durable job manager. Interrupted image submissions with unknown outcomes are not automatically retried.
5. Existing Notes, browser, terminal and local environment features remain available. Downloading a Linux image or invoking a paid AI service is not required for core review.

Please use synthetic media and redact credentials/private content from feedback. On-device services and work may be suspended by iOS. This beta is not a professional HDR mastering tool; real-device performance and optional provider results remain subject to testing.
