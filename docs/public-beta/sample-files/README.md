# Bilingual review sample

[floe-public-beta-sample.pdf](floe-public-beta-sample.pdf) is a two-page, synthetic English/Chinese handout with selectable text, an embedded chart image and room for handwriting. It contains no personal data.

1. Import the PDF into Notes, open full-screen and annotate page 1.
2. Switch documents, reopen and check that the ink remains.
3. Search outside the editor for `lantern garden 472` or `星河手记验证`. The expected match is this document, page 1. This is a test expectation, not a recorded app pass.
4. Select the chart on page 2 and ask which day is highest and the total. The fixture answer is Tuesday, 80 minutes. A configured working vision model is needed to test the image path; the selectable text also supports a text-only comparison.

Artifact checks: two pages; English and Chinese phrases extracted after reopening; one embedded image; both rendered pages visually checked. These checks validate the sample PDF, not the next submitted app build.
