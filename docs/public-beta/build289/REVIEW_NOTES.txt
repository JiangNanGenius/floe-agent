Floe Agent 1.7.48 (Build 289), bundle org.floeagent.ios, is an iPad-first workspace with iPhone support.

No Floe account or demo login is required. Notes, local Office editing and PDF annotation work without cloud AI. Optional AI chats and tasks use the tester's configured provider; no provider credit is included.

The voice waveform button opens a voice conversation directly within the current chat. Dictation remains on the microphone button. Speech reads the completed answer body. Please try short utterances, multiple turns, pausing, resuming, interruptions, and stopping and restarting dictation. A configured AI provider is required for generated answers.

In Settings > General, Voice Input and Voice Output are separate pages. Voice Output > Voice offers system voices and an optional smaller enhanced speech pack. Download its pack, select a voice, or tap a play button to synthesize the editable audition text on demand. Chinese, English, Japanese and mixed-language text are supported. Downloads show progress and speed. A successful replacement retires the old output pack. Online voice services are optional and require the tester's credentials; no automatic paid fallback occurs.

External file sharing opens a destination picker for Notes, Task or Canvas. Choose an existing task/canvas or create one. Task imports preserve the existing composer content and do not automatically send or run it. Canceling keeps the source files and current content.

User profile and SOUL.md settings edit current content and can restore the previous content. Content updates are grouped under Updates at the bottom of Settings. Web Search lists only configured providers, with Add Provider and catalog updates.

This beta has local App compilation, simulator behavior and UI qualification. Physical-device audio remains beta feedback; no physical-device audio acceptance is claimed. Use synthetic content and redact private information in feedback. The existing formal App Store submission is unchanged.
