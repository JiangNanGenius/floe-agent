        Security and honest limits
        

          
The pairing key stays in this browser when you choose Remember. Every RPC is encrypted locally; the key is never sent in a URL or request body.

          
Forget key removes only the local copy. To end this client's access, open Floe Bridge → Clients on the device and revoke it there.

          
If an action times out or reports an unknown outcome, check the device screen before trying again. This page never replays a gesture or text automatically.

          
This page only talks to the same origin that served it. It does not scan the LAN, open ports, load remote scripts, or use analytics.
