# Floe Bridge app icon

The Bridge icon preserves the original Floe folded ribbon and cyan-blue-violet glass material, with a bridge integrated into the central opening. The bridge was raised and then enlarged after visual review.

`AppIcon-master.png` is the selected built-in image_gen output. `AppIcon-provenance.json` records the exact prompt sequence, the original Floe reference/hash, output hashes and the native sips conversion command. Re-run that command from FloeIOSBridge/ to prepare the opaque1024 RGB asset; no standalone-bridge vector generator remains in this directory.
