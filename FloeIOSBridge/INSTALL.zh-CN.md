# Floe iOS Bridge 安装与使用

> 本文适用于独立 Bridge App；可用安装包与各版本的验收范围请查看[版本中心](https://www.floe-agent.com/releases?platform=ios-bridge)。

Floe iOS Bridge 是独立的自签 App，兼容 iPhone、iPad 和 iOS/iPadOS 26 及以上系统。本轮不接入 Floe 主 App。一个 IPA 包含宿主、本机开发隧道和自动化引擎，运行时不需要安装其他 VPN 或调试辅助 App。

## 首次准备：使用一次电脑

准备具备 Network Extension 权限的开发签名、开发证书，以及匹配宿主和 Packet Tunnel 扩展的描述文件。首版不保证免费 Apple ID 或任意重签工具兼容，也不在 App 内登录 Apple ID 或签发证书。

1. 获取正式发行页中的 unsigned IPA 和对应 `.sha256`，先核对 SHA-256。公开包不包含开发者描述文件、设备标识或配对资料。
2. 获取同一个发行标签中的源码，使用其中的[签名脚本](scripts/sign_bridge_ipa.sh)和自己的签名材料重签。运行脚本的 `--help` 查看参数；脚本负责嵌套框架、VPN 扩展、测试包和宿主的签名顺序及权限检查。不要只签最外层 App。
3. 使用开发者自己注册的宿主 Bundle ID；扩展 ID 为宿主 ID 加 `.tunnel`。保留默认 ID 的开发者需持有与其匹配的描述文件。不要修改可执行文件中的字符串来换 ID。
4. 连接设备、解锁、启用开发者模式并安装签好的 App；按系统要求在设备本机完成信任确认。
5. 在电脑生成这台设备的 **RemotePairing 开发配对文件**，通过 Bridge 的首次设置导入。它不是普通 Lockdown 配对文件，也不是客户端控制密钥；请勿分享或上传到公开位置。具体步骤见下方。
6. 在 Bridge 内安装自带的本机 VPN 配置。系统要求的锁屏密码只能在设备本机输入。
7. 结束电脑开发工具连接，在设备上打开 Bridge，完成运行环境下载或导入，然后启动服务。

DDI 按需下载或导入，不随 IPA 分发。首次准备可能需要联网；后续可复用已验证的本机缓存。隧道仅用于本机开发服务地址 `10.7.0.1/32`，不添加普通上网默认路由或替换 DNS。

### 生成开发配对文件

在电脑使用 [idevice_pair 官方工具](https://github.com/jkcoxson/idevice_pair#usage)，优先通过 USB 完成一次设置：

1. 连接并解锁设备，按系统要求确认信任，保持设备停在主屏幕。
2. 在工具中选择设备，类型选 **Remote pairing**，点 **Load / Create**，再保存为文件；可用时使用 **Validate** 检查。
3. 将文件保存到受保护的本机位置，传入设备后，在 Bridge 的首次设置中导入。不要选择 **Lockdown**；普通 `idevicepair pair` 或 SideStore 的配对文件不适用于此处。

工具也提供 Wi-Fi 引导，其说明将引导会话标为内存状态，无法仅据此确认重启后仍可用；恢复能力以对应 Bridge 版本的实测记录为准。Bridge 内的“客户端配对”是另一套授权，不能替代本步骤。

首次挂载请连接 Wi-Fi 并保持联网，Apple 可能需要为设备签发个性化票据；缓存镜像不代表所有挂载都能离线完成。

## 日常使用：在设备上完成

打开 Bridge 后查看首页状态，点“启动服务”。只有真实就绪后，首页才显示可用地址。设备重启后先解锁，再打开 Bridge；如果此前希望服务运行，Bridge 会尝试恢复。主动停止后应保持停止，不承诺开机自动运行。

系统可能再次要求确认 UI 自动化权限或输入设备密码。请在设备本机完成；Bridge 不绕过锁屏和系统鉴权。

主要连接地址是本机的 `http://127.0.0.1:8200` 和 `http://[::1]:8200`。客户端第一次连接须请求配对，并在 Bridge 中确认；本机连接也需要授权。可以在客户端页面撤销授权，或随时停止服务。

使用同机 Safari 遥控时，发起配对后切回 Bridge 批准，再返回 Safari。后台到达的请求会等待这次确认，超时则拒绝，不会自动授权。

Bridge 自身的界面需要在设备上直接操作；已配对客户端不能通过自动点击或输入，自行批准客户端或修改权限。

第三方 App 密码框输入需要为对应客户端单独开启敏感输入权限，默认关闭。该权限不允许自动输入系统锁屏密码或处理系统鉴权。

## 可选局域网连接

局域网访问和同网发现默认关闭，只在需要其他设备连接时从设置开启。发现仅用于同一局域网，不提供点对点附近连接。来自局域网的新客户端也必须在设备端确认配对。

关闭局域网访问不影响本机连接。停止服务会关闭服务入口；撤销客户端授权会终止其后续访问和流连接。浏览器遥控页面与其他客户端使用同一份认证和运行状态。

## 恢复与最少必要操作

| 状态 | 操作 |
| --- | --- |
| 签名或描述文件到期 | 使用有效材料重新签名并安装；优先覆盖安装同一 Bundle ID 的 App。 |
| 客户端授权失效或被撤销 | 在客户端重新配对，并在 Bridge 中确认；不需要重新生成设备开发配对文件。 |
| 设备开发配对失效 | 按首次准备流程重新生成并导入 RemotePairing 文件；这一步可能需要电脑。 |
| 运行环境缺失 | 在 Bridge 内重新下载或导入并恢复，查看诊断中的实际结果。 |
| 安装结果未知 | 保留当前状态，按 Bridge 提示先检查实际挂载状态，不连续重复安装。 |
| 自动化引擎初始化故障 | 完全关闭并重新打开 Bridge；不要在同一进程重复初始化。 |
| VPN 配置被拒或与已有 VPN 冲突 | 在设置中检查授权和冲突；Bridge 不会代为删除其他 VPN 配置。 |

更换 Bundle ID 或签名团队可能形成新的 App、钥匙串及 VPN 配置，不能假定旧资料自动迁移。系统升级后的兼容性以实际运行结果和发行说明为准。

配对文件、签名材料和客户端密钥均属私密资料。提交问题时使用诊断页面的脱敏信息，不附原始配对资料、密码、描述文件或未经检查的录屏。

## 验收边界

编译、签名安装、真机运行和公开下载分别记录。iPad 按项目所有者决定采用兼容性假定，不据此声称完成 iPad 真机验收；具体 iPhone 验证范围以对应版本的发行说明为准。
