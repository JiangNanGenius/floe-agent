# Public end-to-end repository fixture

Generated by the production `scripts/build_floe_repo.py` publisher using an
independent GnuPG Ed25519 qualification key. The private key and temporary keyring
were destroyed after generation. This public key is not a production trust anchor.

Five test package versions exercise signed Release → Packages.gz → deb integrity,
versioned installation, dependency upgrades, ownership collisions and maintainer
script rejection. No network access is used by the Swift fixture downloader.
