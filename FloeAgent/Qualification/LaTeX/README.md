# LaTeX qualification

The production package, App integration, real Linux toolchain, and native
experiment have separate evidence. Passing one does not qualify the others.

## Real Linux toolchain

`verify_linux_toolchain.py` runs the real fixed worker with installed programs
and checks the resulting PDF text, page count, artifact hashes, helper phases,
reference convergence and relative SyncTeX paths. Cases cover all four engines,
Chinese, nested files, BibTeX, Unicode Biber, indexes, glossaries, nomenclature,
TikZ/PGFPlots, chemistry, long tables, Beamer and isolated offline builds.
Bibliography fixtures are explicitly synthetic.

Install the required TeX packages inside a disposable Linux test environment,
then copy the worker and this script into it:

```sh
python3 -B verify_linux_toolchain.py \
  --worker ./latex_worker.py --output ./evidence-01
```

The output directory must be new. `--case NAME` can select a changed or failed
case for another run without overwriting the original failure. `pdfinfo` and
`pdftotext` are required. A private network namespace must work; an unavailable
namespace is an explicit failure. `bubblewrap` is required for every build;
source/toolchain mounts are read-only and all document processes have private
network/PID namespaces. `verify_linux_isolation.py` additionally checks private
file/environment visibility, source immutability, actual timeout/cancellation
and descendant exit. Do not run these checks with an Apple host
interpreter and describe them as Linux execution.

This independent environment does not prove the App's real environment lease,
authorization, file-return path, background lifecycle or iPad performance.

## Independent iPad host

`project.yml` generates the standalone Xcode project. It explicitly uses the
quarantined `Native/Experiment` package, whose copyleft closure is excluded
from the production App. Native binaries are generated by the pinned native
build procedure and are not an approved App distribution dependency.

Build with Xcode 27.2, an explicit task-owned DerivedData path and bounded
compiler jobs. Use the repository's canonical iPad selector and its lock for
all actual Simulator runs; disable parallel Simulator destinations. Preserve
the shared device's applications and data, and shut down only an instance
started by the task after its run completes.

The host tests actual PDF/BibTeX/SyncTeX, cancellation recovery, rapid visual
editing, source completion, source/visual switching, formula insertion,
typesetting and persistence after reopening. They preserve original failed
results and screenshots. They never create a main-App grant or bypass its
runtime permissions.
