# Glimmerfen (RPG Maker MZ)

Original Floe starter project in the standard RPG Maker MZ layout.
The project data, map, events, plugin and synthetic art are original and
MIT-licensed. No licensed `rmmz_*.js` core scripts, RTP, fonts or sample
commercial art are bundled.

Open with a licensed RPG Maker MZ editor/runtime. The editor/runtime is an
explicit user prerequisite; this project can still be created, inspected,
edited and versioned without it. See licenses/ENGINE-NOTES.md and
licenses/FLOE-STARTER-MIT.txt.
