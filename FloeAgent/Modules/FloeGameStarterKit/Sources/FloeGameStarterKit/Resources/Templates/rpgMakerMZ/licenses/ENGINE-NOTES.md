# Engine prerequisite

This project uses the standard RPG Maker MZ data and resource layout but
does not include the proprietary `rmmz_*.js` core scripts, the MZ editor,
RTP or sample commercial assets. The user must supply a licensed RPG Maker
MZ installation to play the project. The original Floe project data,
plugin and synthetic art are MIT-licensed; the engine and any imported
assets retain their own terms.
