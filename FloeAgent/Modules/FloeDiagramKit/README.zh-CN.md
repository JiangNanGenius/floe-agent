# FloeDiagramKit

思维导图、混合图形和项目计划的独立原生 Swift 组件包。编辑、布局和渲染使用 SwiftUI、UIKit、CoreGraphics/CoreText、PencilKit；没有内嵌 Web 图编辑器。

本轮交付组件、独立宿主与接入合同。主 App 的手记/文件入口、SQLite 存储、同步、AI 提供方和任务执行服务尚未接入；没有进行发布。

[English](README.md) · [主线接入交付单](../../../docs/FLOE_DIAGRAM_KIT_PREDEVELOPMENT_HANDOFF.zh-CN.md) · [独立原生宿主](../../Qualification/DiagramKit/README.md)

## 组件边界

| 产品 | 内容 |
| --- | --- |
| `FloeDiagramCore` | 多页文件、节点/容器/连线、富内容、任务与依赖；身份和结构校验；选区与锁定；修订/CAS/幂等批次；会话、撤销、真实文件仓库；排期、进度汇总、笔迹几何识别 |
| `FloeDiagramLayout` | 多种树布局、Dagre 流程图布局、混合容器、折叠、空间索引、裁剪、路由与命中 |
| `FloeDiagramUI` | iOS/iPadOS 26+ 原生编辑器，画布/大纲/看板/甘特图、检查器、图文编辑、键盘/触控、Pencil、文件和打印界面 |
| `FloeDiagramExchange` | 原生文件包、外部格式的支持子集、原生 PDF/PNG/SVG、项目视图投影 |
| `FloeDiagramIntegration` | 资源与宿主回调；旧手记桥接；字段补丁、三方合并、恢复副本、复制和跨页移动 |

Core、布局、格式与导出也支持 macOS 15+。编辑 UI 当前只提供 iOS 版本。macOS 的 PencilKit 渲染必须在具有 App bundle identifier 的宿主中使用；无 App 身份的命令行进程会明确返回不支持。原生归档仍可完整保留可编辑笔迹数据。

## 接入方法

完整、可运行的调用方式见独立宿主 [App.swift](../../Qualification/DiagramKit/App/App.swift)。[英文说明](README.md#minimal-runnable-caller)给出了最小创建示例。

1. 通过既有文件身份打开 `DiagramDocument`，注入唯一的 `DiagramRepository`、`DiagramAssetStore` 和既有服务回调。
2. 在手记或文件特性内部嵌入 `DiagramEditorView(model:)`，保留主 App 外层导航。
3. 每个编辑器持有自己的 `DiagramEditorModel`。真实关闭/换文件时调用 `await model.close()`；普通 View 重建不用关闭会话。
4. 用既有 Notes/文件事务、历史和资源服务实现协议。示例 `FileDiagramRepository` 是可工作的独立存储，不应与生产存储同时写同一个作品。

所有编辑走同一批次：文件 ID、预期修订、请求 ID、命令。写入失败与冲突保留待保存批次；旧会话的异步结果不会转写到新文件。关闭前会提交该编辑器尚未刷新的笔迹。

## 操作与语义

- 编辑器内部采用系统 `NavigationSplitView`、工具栏、`searchable` 大纲，以及 Floe 式 SwiftUI 检查器侧栏和系统表单。接入到功能的专注编辑页面，保留 Floe 外层导航，避免再包一条文档工具栏。浮动控件使用 iOS 26 Liquid Glass，图形卡片仍保留文档样式。窄屏导航/检查器共用已有弹层协调；紧凑宽度或辅助功能大字下，撤销/重做收进文件操作菜单。
- 控件样式对齐 Floe 手记：继承强调色及语义表面、44 点操作范围、轻量按压反馈与小圆角选中态。底部分页在宽屏为手记式标签，窄屏/辅助功能大字下为系统页面菜单。玻璃材质限于浮动控件，添加主题不使用放大的强调按钮。
- 画布优先：导航默认收起，常规宽度按需展开较窄侧栏；缩略导航由文件菜单开启。分页改为有宽度上限的浮动小条，不再预留横贯画布的底栏；页面较多或标题较长放不下时转为当前页菜单，窄屏/辅助功能大字同时使用缩放菜单。保留 44 点触控范围，不靠缩小字体换取空间。
- 导图分支自动排版，默认拖动整支，落到主题上可换父级；流程图、自由主题手动摆放。整理、对齐和分布可限定选区，并保护锁定内容及携带锁定子项的父级。
- 多页可混合主题、流程图形、分组、外框、概要、泳道和关联线。父子与容器分别建模；流程环路合法，归属和任务依赖不能成环。
- 曲线、正交折线、直线采用同一套几何。可创建、重新连接端点、拖动路点和标签，设置固定端口、粗细、虚线和箭头。避让有计算边界，不能保证永不交叉。
- 双击原生输入框编辑标题；Tab/Return 加子级/同级，Command-C/X/V 复制/剪切/粘贴，Command-Z/Shift-Command-Z 撤销/重做。空白处长按后拖动框选。大纲提供层级、搜索、排序、拖放和连线列表。
- 内容支持富文本、图片、公式、代码、表格、备注、附件、来源、标签和跨页链接。检查器表单点击“应用修改”；画布内标题在结束输入时提交。字段补丁保留其他字段的并发修改，同一字段冲突保留当前草稿并拒绝覆盖。
- 看板与甘特图使用同一批任务。拖动看板改状态，拖动/拉伸甘特条改日期；排期、依赖和进度变化不会自动执行 Floe 任务。日期按文件日历时区计算，处理夏令时的日历日跨度。
- 笔迹保存为世界坐标中的 PencilKit 数据。方框/椭圆/箭头可提升为可编辑对象；可选择保留原笔迹。系统文本输入支持随手写，Vision 可识别笔迹文字。合成笔迹验收不能替代真实 Pencil 的精度与延迟验收。
- 支持分支拆页、跨页移动/链接、批量样式、格式刷、层次、主题、模板、聚焦、演示及打印导出。跨页移动保留节点 ID，跨出页面的关系转为页面链接。

## AI、资料与执行

宿主注入 `openSource`、`askAssistant`、`refreshSources`、`execute`；没有接入的动作不显示。生产接入应复用现有服务；提供方配置不应因开发者账号未实测而被禁用。

AI 请求包含选中的节点、连线、任务、依赖和实际锁定身份。模型返回补丁，宿主决定选区和解锁权限，文件内容不能授予权限。单次物化助手上下文上限为 2,000 个元素，大图先选择分支。选中连线仅授予连线修改范围；项目模式使用任务范围。独立新任务根须由宿主明确允许，选中任务的子任务仍受范围和锁定约束。画布的“另做一页”会映射原选区后修改副本。

资料刷新由宿主提供最近共同基线和新资料版本，先生成三方合并结果，由用户选择应用。同一字段冲突保留当前内容，并先保存另一版本的恢复副本。反向链接登记、云端传输和真正的 Floe 任务绑定由现有服务负责。导入文件的 `floeTaskID` 不能作为执行授权。

## 格式与限制

| 格式 | 已实现范围与边界 |
| --- | --- |
| `.floemap` | 当前文档和资源的完整归档，含多页、富内容、任务、笔迹及保留的来源数据；本地撤销历史仍属于仓库，不是数据库备份 |
| XMind | 新式 ZIP/JSON、旧 XML 读取；多页树、浮动主题、备注、基本样式、图片、关系线的可编辑输出；每张输出页须有根主题，纯流程页需先转换或使用其他格式；装饰、特殊结构和样式按支持子集处理 |
| FreeMind | 树、备注、基本颜色/字体、链接和关联；多根会增加中心根并给出说明 |
| OPML / Markdown | 可编辑大纲、文字、任务子集；图形位置、富媒体和完整项目字段不能无损保留 |
| draw.io | 普通/压缩 XML、基本图形/容器、端口、环路、标签、路点；自定义模板、富 HTML 和图片存在限制，不运行外部内容 |
| Mermaid | 原生解析导图、流程/子图和基本甘特；不运行 JS，也不覆盖完整语法；`after` 依赖可能重新计算手工日期 |
| PDF / PNG | 共用原生绘制；PDF 每图一页，PNG 限单边 8,192 像素及 2,400 万像素；图片逐个解析绘制，缓存回收不会漏掉前面的图 |
| SVG | 矢量形状、线和文字，嵌入图片；公式/笔迹用原生渲染图像，系统符号图标会提示省略；文字换行受阅读器字体影响 |
| 旧 `.floenote` | 按既有清单/资源合同转换根导图，不递归转换关联文档；旧 JSON 导出仅限原身份且可表达的内容，拒绝静默压平新能力 |

归档限额：压缩后输入/输出 128 MiB，单条目 64 MiB，展开总量 512 MiB，最多 20,000 条目；XML 另有深度、节点与文字限额。独立文件仓库记录含历史上限 256 MiB。图片按静态缩略图展示，解码最长边不超过 1,024 像素，原始字节仍保留。GIF 等栅格格式导出 SVG 时会转成 PNG 预览。

项目日历用 `metadata["calendarTimeZone"]`，缺省 UTC；新建调用方可设置用户时区。外部文件互通始终保留转换说明，建议同时保留原生文件。没有宣称外部软件的完整格式等价或全部实机往返验收。

## 验证与复用

测试与运行命令见[英文说明](README.md#verification-and-examples)和[原生宿主说明](../../Qualification/DiagramKit/README.md)。样例可生成十种格式、看板/甘特成品和 500 图文/万级节点基准。基准测量宿主的校验、布局、编解码和进程累计峰值内存，不等于设备帧率；500 图文样例共享图片与公式，另有 20 张独立图片的缓存回收回归。

新组件遵循仓库 MPL-2.0。复用代码保留上游许可和独立字体许可，固定版本及逐文件 SHA-256 见 [Vendor/PROVENANCE.json](Vendor/PROVENANCE.json)：SwiftDagre `92efb78…`、SwiftMath `0b0222e…`、ZIPFoundation `0.9.20`。
