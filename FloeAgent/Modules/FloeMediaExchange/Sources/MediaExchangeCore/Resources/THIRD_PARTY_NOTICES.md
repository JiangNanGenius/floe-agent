small number of pinned third-party components. No third-party binary framework,
XCFramework or prebuilt library is vendored.

## Not included

- `psd_sdk` (BSD-2-Clause) remains rejected for the iOS runtime; its source and
  build evidence stay in the private formats qualification only.
- OpenTimelineIO Python/C++ implementation is not embedded. The OTIO adapter is
  a native Swift JSON implementation of a documented schema subset.
- No example brush, image, font or media asset from an upstream repository is
  copied. All fixtures are synthetic or generated by the qualification code.
