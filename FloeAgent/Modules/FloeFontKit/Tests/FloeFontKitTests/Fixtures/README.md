# Font compiler fixtures

Original synthetic outlines and source programs, authored for Floe under MPL-2.0. No system or third-party font is copied. Regenerate with the pinned WebBuild toolchain and generate-font-fixtures.mjs.

`multi-axis.zip` and `static-layout.zip` are generated by `Tests/Web/run-tests.mjs` with `FLOE_FONT_WRITE_FIXTURE` set to this directory's `multi-axis.zip`. They include an original two-axis family with a correction master, per-master kerning, vertical metrics, and a static family with ligature / mark anchors.

`static-layout.otf` is the native fontc 1.0.0 static TTF converted by the module's real CFF encoder / sfnt assembler. The Swift test requires and loads this fixture; it is not a system font or renamed TTF. Regenerate by running Swift tests with `FLOE_FONT_TEST_ARTIFACTS`, running the Web tests with `FLOE_FONT_NATIVE_TTF` pointing at the resulting `static-layout.ttf`, then copying the resulting `static-layout.otf` here.
