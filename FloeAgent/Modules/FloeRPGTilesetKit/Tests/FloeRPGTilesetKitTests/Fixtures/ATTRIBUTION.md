# Synthetic fixture attribution

Every PNG in this directory is generated by `Tools/generate_fixtures.py` using
solid deterministic colors and simple borders. Every binary data file is
generated by `Tools/generate_binary_data.rb` using real Ruby Marshal 4.8 and
original record content. No RPG Maker RTP, Enterbrain artwork, default scripts,
fonts or other proprietary assets are present. These fixtures are test-only and
are not shipped to users.
