# RPG tileset rendering — public-safe summary

The auxiliary RPG map editor source now implements actual RPG Maker tileset
art rendering instead of colored tile IDs. It resolves XP, VX, VX Ace, MV and MZ tileset
records and images, draws ordinary atlas cells and four-quarter autotiles
(A1–A5/B–E), keeps multiple layers and event markers, and provides a visual
tile palette with a shape sheet for autotile edges/corners/water/walls.

The implementation is original Swift over public SwiftUI/CoreGraphics/ImageIO.
Layout facts come from the official RPG Maker MV CoreScript (MIT) and
qnighy/tapir (Apache-2.0 OR MIT, MIT selected); full notices are retained. No
proprietary RTP, Enterbrain artwork, default scripts or fonts are bundled.
Fixtures are original deterministic PNG/data files generated by the package
tools.

Missing images are reported without mutating the map; the original tile data
is retained. Encrypted assets and RTP installation lookup are deliberately
unsupported. VX/Ace A1 and XP autotile animation are presented at a stable
representative frame; MV/MZ frame metadata is available. MV/MZ shadow/region
channels are preserved but not rendered.

This is a private predevelopment component, not an App integration or release.
Native Swift tests, iOS object compilation and iPad touch/visual acceptance are
pending the App native window.
