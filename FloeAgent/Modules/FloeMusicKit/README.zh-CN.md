# Floe 音乐模块

完整音乐工作台的独立预研发底座。当前包含工程核心、电子琴面板与真实音频服务；正式 Floe App 的导航、存储和音频会话尚未接入。完整目标继续以[设计与 QA 计划](../../../docs/FLOE_MUSIC_WORKBENCH_QA_PLAN.zh-CN.md)为准。

| 位置 | 已实现的职责 |
| --- | --- |
| `Sources/FloeMusicCore` | 音频/MIDI 轨与片段、样本时间/速度图、通道和发送路由、效果状态、自动化数据、原子编辑批次、修订及会话隔离、撤销/重做、保存重开接口、双碟状态 |
| `KeyboardUI` | 复用 AudioKit/Keyboard 的触摸琴键，延音/弯音/调制控制，音色描述注入，原归属释放与迟到事件隔离，中英文本地化 |
| `Native` | 原生离线混音、真实 EQ/混响发送、逐样本音量自动化、声像、合成器发声、SMF 音符与速度导入、PCM 录音写入、WAV/MP3 导出、双碟音频验证路径 |
| `Qualification/Music` | 独立 macOS 音频验证程序、iPad 电子琴测试 App 与 UI 测试、合成素材和独立解码检查工具 |

## 当前验证

使用 Xcode 27.1、Swift 6.4；模块兼容目标为 iOS 26 / macOS 15。

- 工程核心 56 项、电子琴事件控制 26 项、原生输出归属 2 项组件测试通过。
- Core、Native 与电子琴通过 arm64 iOS 对象编译；独立 iOS Simulator App 和两项 UI 测试通过编译与链接。
- 导出后的 macOS 验证程序可独立运行。真实工程经历录入、保存、移动目录、重开、修改、再次保存重开及混音导出。
- 20 项独立 FFmpeg 音频检查通过，核对实际声音、声道、音高、收声、EQ、自动化、双碟、循环与倒放；MP3 实际解码为 48 kHz 双声道、240000 帧，时长 5 秒。
- 共享 iPad 模拟器被其他任务占用，设备锁阻止本轮启动 UI 测试。未获得本轮界面运行、多指触控或真机听感证据。

详见[交接记录](../../../docs/FLOE_MUSIC_WORKBENCH_PREDEVELOPMENT_HANDOFF.zh-CN.md)及[公开安全的组件证据](../../../docs/evidence/music-predev-20261103/qualification.json)。不能把本页结果理解为正式 App 功能已可用。

## 接入规则

`MusicProjectStore(document:repository:)` 只创建工程；已有工程使用 `open(projectID:repository:)`。所有手动或 AI 修改提交为 `MusicEditBatch`。失败批次不改变当前文档，旧修订不能覆盖新修订；关闭/失活会话也会撤销尚未到达原子提交点的写入资格。

主线适配器必须实现 [CORE_CONTRACT.md](CORE_CONTRACT.md) 的 CAS 与提交栅栏，通过现有持久化和资产服务落盘。当前资格宿主的文件仓库仅用于验证，不是正式数据仓库。撤销历史仍在内存中，持久日志接入待办。

文件访问由宿主提供已解析 URL；模块不打开文档里的任意定位字符串。`MusicRenderLease` 绑定工程、修订和归属，宿主在切工程、编辑或取消时失效它。渲染/编码只能把完整临时文件提交到新的输出路径。

正式 App 的音频会话由宿主提供 `MusicAudioAuthority`；模块不修改 AVAudioSession。独立测试 App 自己拥有播放会话，不可把它的演示会话管理照搬到 Floe 的语音/视频路径。

## 明确的阶段边界

当前合成器提供纯音/锯齿波与 8 声部；没有采样钢琴音色。录音验证使用明确注入的 PCM，尚未获取麦克风或证明中断/进程退出恢复。双碟路径是有界缓存的离线真实音频实现，支持交叉混音、拍循环、变速、跳位与反向读取；尚未证明实时专业搓碟、锁调或耳机预听硬件路由。

完整实时多轨引擎、钢琴卷帘/鼓机编辑、完整 MIDI 交换、AUv3、AI 分轨/生成、跨媒体交换和正式 App 界面仍在后续阶段。现有状态可保存未支持的插件内容；渲染时明确拒绝不能执行的活跃状态，不能静默漏掉音轨或效果。LAME 的实际分发许可义务在主线交付前落实，见 [Native/NOTICE.md](Native/NOTICE.md)。
