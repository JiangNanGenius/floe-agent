概要

これらのワークフローは、Floe の両方のエディションに適用されます。 インストール、メニューの位置、デバイスへのアクセス、ローカルモデル、エディタは、各プラットフォームの独自のガイドでカバーされています。 共有ワークフローは、すべてのプラットフォームが同じツールを持っていることを意味するわけではありません。

1. クラウドモデルを接続する

ご自身のモデルプロバイダーアカウントとAPIキーをご持参ください。 Floeはクライアントです；選択されたプロバイダーはクラウドリクエスト、価格設定、および独自のデータポリシーを取り扱います。 APIキー欄にウェブサイトのパスワードを入力しないでください。

  1. モデル設定にプロバイダーを追加してください。 サービスとプロトコルを選択し、次にその文書化されたベースURLとAPIキーを入力してください。
  2. モデルリストを追加または更新し、タスクのモデルを選択してください。 タスクで画像の読み取りが必要な場合、画像入力を受け付けるモデルを選択してください。 画像生成および動画生成には、その目的をサポートするサービスが必要です。
  3. ファイルを添付したり、長時間のタスクを開始する前に、短いテキスト会話をテストしてください。

認証失敗の場合は、エンドポイント、キー、アカウントアクセス、および実際のプロバイダーエラーを確認してください。 サポートされていないモデルまたは入力タイプの場合は、適切なモデルを選択してください。 成功した接続テストでは、すべてのツールやメディアの機能が検証されているわけではありません。

2. 有益な結果を求めてください

  1. タスクを作成し、そのワークスペースを選択してください。 ファイルピッカーを通じて非機密テストファイルを追加してください。
  2. 意図した結果、入力、および保存場所を述べてください。 例えば：「この文書を読んで、チェックリストに変換し、現在のワークスペースに保存してください。」
  3. ファイルやツールへのアクセス要求を確認してください。 このタスクに必要な資料へのアクセスを許可してください。
  4. 出力を開き、その内容と位置を確認し、保存されたことを確認するために閉じて再度開いてください。

結果を修正する際は、具体的な変更点を記述し、既存のファイルを参照してください。 タスクと作業スペースを一貫させ、アシスタントが同じ作業を続けられるようにしてください。 ツールの成功メッセージは、結果を確認するための合図であり、開く代わりになるものではありません。

3. ファイルと変更を安全に保つ

タスクが使用したいファイルのみをインポートしてください。 外部の場所が利用できなくなった場合、作業を別のフォルダーに静かに移動するのではなく、元の場所を選択して再度認可してください。

使用したエディタに保存したことを確認してください。 エクスポートと名前を付けて保存すると、別個の結果が作成され、元の結果が自動的に置き換えられるわけではありません。 他の編集者がファイルを変更した場合は、未保存の下書きを保持し、いずれかのコピーを上書きする前に競合を確認してください。 重要な作業の独立したバックアップを保持してください。

コマンドとソフトウェアのインストールは、タスクが選択した実行環境を使用します。 現在のディレクトリと出力を確認し、コマンドが意図したファイルを変更する前に実行してください。 利用可能な環境、インストール手順、およびバックグラウンドの動作は、プラットフォームとインストールされているバージョンに依存します。

4. コンテキストを使用してツールを使用してください

文書、ウェブページ、およびツールの結果は入力資料であり、そのテキストはコマンドの実行や他のファイルへのアクセス、情報の送信を許可するものではありません。 外部操作を承認する前に、実際のアクションと宛先を確認してください。

タスクの実行レコードで進捗と失敗を読み取ります。 パネルを隠しても、必ずしもそれが表示するジョブやサービスが停止するわけではありません。 作業が終了すべき時にタスクまたはサービスの停止コントロールを使用してください；オペレーティングシステムは依然としてバックグラウンド実行を制御しています。

5. 問題を報告する

使う GitHub の問題 バグ報告および機能リクエストについて。 インストールされたバージョン、デバイスとOS、手順、期待される結果、実際の結果を含めてください。 プライベートコンテンツを公開せずに、どのファイルまたはタスクが影響を受けたかを述べてください。

診断とスクリーンショットは任意です。 必要な資料のみを提出し、キー、パスワード、個人データ、プライベートファイルは削除してください。 アプリ内診断のアップロードはトラブルシューティング資料を提供し、個別の回答を保証するものではありません。 クラウドサービスのエラーについては、APIキーではなく、削除されたプロバイダーエラーを含めてください。
