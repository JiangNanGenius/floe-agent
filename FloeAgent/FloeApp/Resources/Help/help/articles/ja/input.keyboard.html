設定 > 一般 > ハードウェアキーボード > リターンキー

変更してください

設定を開き、一般をタップし、次にハードウェアキーボードをタップしてください。 Return Key を選択し、Newline または Send を選択してください。

ノート

この設定は、このデバイスに接続された外部キーボードに適用されます。 画面上のキーボードは独自の送信ボタンを保持しています。
