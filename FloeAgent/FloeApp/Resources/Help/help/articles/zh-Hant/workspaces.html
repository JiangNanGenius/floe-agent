面向任務的 Floe 個人檔案庫與專用工作臺教程：空間檔案與作品、會議、音樂、圖示、加工與 3D 列印、網路工具箱和化學工程。模型、任務、手記與 Office 的基礎用法請先看使用手冊。

需要什麼版本？

Floe 的各安裝渠道包含的功能不同。下方版本標註表示相應工作流的釋出基線；當前渠道版本及核實日期統一見 CURRENT_STATUS：

標註獲取渠道覆蓋內容
1.7.74App Store，iOS/iPadOS 26+穩定的正式版。僅標註 1.7.74 的小節適用；空間和專用工作臺尚未進入該版本。
1.8.5 基線原始釋出；選擇更新安裝包時檢視渠道狀態空間、會議、音樂、圖示、加工與列印、工具箱和化學工程的原教程基線。
1.8.6 新增已公開的未簽名 IPA；TestFlight 可用性單獨核對已包含 LaTeX、原理圖／PCB、生物學及 CAD 工程分析入口；高階 PCB 與模擬能力仍在完善。
其他專用編輯器按所選版本和接入記錄核對GIS、字型、制譜、Image Playground 各有獨立範圍與資格記錄，開發修改不自動進入安裝包。

已安裝版本在“設定 → 診斷與關於”檢視。各渠道可用狀態見版本與安裝狀態；官網版本中心列出所有已釋出構建。

1. 空間：你的檔案與作品 — 1.8.5

本頁新增截圖取自 iPad 模擬器中的 Floe 1.8.72（393）。

空間是側欄中個人內容的入口：手記文庫，加上可編輯作品與檔案庫。

在概覽按要做的事選工作臺。新建時填寫名稱和保存位置，做完後從繼續使用或檔案開啟原工程。

你手上的工作選哪個功能常用成果
課堂筆記、讀書批注，或積累參考資料手記。按文件和頁面歸檔，適合手寫與標注。可以繼續補寫的筆記
會議錄音、轉寫和決定事項會議筆記。把聲音、轉寫和重點放在同一份會議作品里。錄音、轉寫和紀要
一組還在變化的草稿、圖片和候選方案創意模式的畫布。在看板上自由擺放和比較物件。可繼續調整的看板
流程、順序、關係或架構圖示。用形狀和連線表達關係。可編輯的結構圖

第一次上手：

  1. 從側欄開啟空間。它分為概覽、手記、檔案和工具箱四個板塊。
  2. 概覽提供常用入口、置頂作品、資料夾，以及“繼續使用”（最近開啟的手記與作品）。
  3. “檔案”以列表展示作品，可切換縮圖，並按型別篩選：文件、繪畫/圖片、影片或 CAD。
  4. 想直接開始一種作品，在概覽點常用入口或對應工作臺。想先指定保存位置，在檔案開啟目標資料夾，再從右上角 ＋ 選作品類型。填寫名稱，檢查位置，點創建。空白手記和會議筆記從手記 → ＋創建。
  5. 使用匯入加入已有檔案，或點“瀏覽其他位置…”訪問全部工作區檔案、歸檔聊天檔案和保留的（恢復）文件。被刪除的作品可在最近刪除中恢復。

歸屬與儲存：

  • 作品儲存在裝置上的個人檔案庫中，不屬於任何聊天任務：刪除聊天不會刪除作品，刪除作品也不會影響任務或專案檔案。刪除前請先匯出重要內容。
  • 各編輯器直接儲存進作品。關閉後從“繼續使用”重新開啟，確認最新狀態；在接受的檔案核對完成前，恢復副本保留在“保留的文件”中。
  • 每個作品可以有自己的助手會話（作品助手，會議為會議助手）。會話屬於該作品並保留未傳送草稿；授權助手訪問一個作品不會開啟其他檔案。

2. 會議：錄音、轉寫與紀要 — 1.8.5

會議把個人筆記、實時錄音、轉寫和 AI 紀要整合在一個作品中，從手記進入。

第一場會議：

  1. 開啟空間 → 手記 → ＋ → 會議筆記，輸入名稱並創建。橫屏時左側是我的筆記，右側可切換轉寫、重點、會議助手。
  2. 現場錄音用右下角的開始錄音。處理已有素材時，在頂部點錄音，開啟錄音與素材 → 匯入音影片。開啟邊錄音邊轉寫可實時查看分段，也可稍後處理已保存的素材。
  3. 用轉寫核對逐字稿，在重點整理紀要和待辦。要把重點加入自己的筆記，在核對後再插入。
  4. 開啟自動更新 AI 紀要持續根據轉寫整理，或直接向會議助手提問本場會議內容、請它整理筆記與待辦。未傳送的草稿會保留。
  5. 透過紀要模板選單匯出 Word 或 PDF 文字紀要，並把待辦迴流到任務流程。

連續錄音（較新構建）： 暫停後點繼續，仍在同一場會議的錄音時間線上。結束後回放錄音，點轉寫片段定位到對應時間。可對已有說話人改名，或合併被誤分為多人的同一個人；說話人區分取決於所選識別服務。重新開啟會議後繼續檢視錄音、時間位置和修正後的轉寫。

回放已有素材。 在錄音與素材選取剛匯入的檔案，點播放整段。播放器出現在會議頁底部，可暫停或拖動進度。在轉寫里點有時間戳的片段，可回到對應位置。匯出紀要前分別核對逐字稿、重點和待辦。

邊界： 錄音預設保留在本機；雲端轉寫使用你明確選擇的服務，費用由該服務商計取。轉寫質量隨識別設定變化（見使用手冊 §16）。

3. 音樂工程 — 1.8.5

空間音樂作品把編曲、鍵盤、混音與 DJ 工作流整合在一個工程中。

第一個工程：

  1. 在空間 → 檔案中新建音樂作品並命名。
  2. 工作臺提供編曲，以及鋼琴捲簾、鼓機、電子琴、DJ 打碟等專用介面，軌道配有調音臺與效果器。
  3. 匯入音訊或 MIDI 素材，或讓助手提出修改建議；每項建議在應用前都會展示具體改動。
  4. 儲存自動寫入作品。需要音訊檔案時執行渲染，按回執核對實際生成的檔案，再從作品分享或匯出。

本輪測試版的音樂功能： 在“樂譜”中可切換五線譜與簡譜，編輯和儲存仍使用同一份樂譜。開啟“演奏音色”為各聲部選取合成樂器音色；“演奏並加入編曲”生成音訊，並在當前播放頭位置加入新音軌，完成後返回編曲。普通播放用於試聽。需要檢視簡譜中未呈現的複雜記號時，切回五線譜。

從播放頭錄製（較新構建）： 把播放頭移到起錄位置，選擇音訊或 MIDI 錄製，再開始演奏。已有未靜音軌同步播放，舊片段保留；停止後在同一時間線上試聽新片段，儲存並重新開啟核對位置。編曲錄製、素材試聽、監聽與 DJ 錄製各有自己的控制，離開前在對應入口確認停止。

電子琴會利用可用高度顯示琴鍵。寬屏右側檢查器可透過“顯示檢查器／隱藏檢查器”展開或收起，也可展開下方編輯器以獲得更大的演奏區域。

邊界： AI 輔助編輯使用你配置的模型；播放與渲染在本機執行，以工程的真實能力為準。

4. 圖示與混合畫布 — 1.8.5

圖示適合解釋“誰接到誰”“接下來做什麼”。例如整理審批流程，把每個操作畫成形狀，用連線表達順序。創建後從空間 → 檔案重開，檢查形狀與關係是否齊全。交給助手提出更改時，先預覽差異，再決定是否應用。

創意畫布適合把一個主題下的便利貼、圖片、文件和方案排在一起。選取物件可編輯對應內容，移動物件只改變看板佈局。在比較圖片或圖紙的多個版本時，把成品留在對應工作臺，畫布保留選材和比較過程。詳見自由編輯步驟。

5. 加工與 3D 列印 — 1.8.5

加工與列印從 CAD 文件的加工入口進入。

加工流程：

  1. 開啟二維/三維 CAD 設計並進入加工。先選擇機床。
  2. 設定毛坯、座標與工序；助手可以讀取當前物件，並在任務許可權內建議工序。
  3. 執行預覽，沿刀路逐步檢視去料；已實現的碰撞檢查會隨執行報告。
  4. 儲存結果、匯出 STL 或刀路，並重新開啟儲存的結果核對。製造單元（多主軸/多刀塔）程式獨立儲存，可稍後讀取。

3D 列印流程：

  1. 從 CAD 設計或檔案準備列印工程，Floe 會把當前幾何複製進去。
  2. 在列印平臺上擺放模型，新增或複製零件，並按平臺調整層高、填充等引數。
  3. 選擇機型配置：平臺尺寸、座標原點、噴頭偏移、自定義開始/結束/換頭 G-code，以及光固化平臺的朝向。
  4. 切片完成後自動進入“預覽”，儲存結果與引數保持繫結。匯出印表機所需的 G-code，並在你的切片或上位機軟體中核對。

邊界： 加工預覽只報告已實現的檢查，不構成完整的機床安全認證。本構建未附帶原生 USB 印表機驅動；請使用印表機的常規傳輸方式。實際列印與加工仍以機床真實能力和安全規範為準。

6. 網路工具箱 — 1.8.5

開啟空間 → 工具箱。從頂部快捷卡片、下方分類或右上角搜索工具開啟所需功能。工具箱同時提供網路會話與日常測量工具。

  • 診斷： Ping、路由追蹤、DNS、埠檢查、區域網發現、Wi-Fi 資訊和漫遊檢查。Wi-Fi 名稱與 BSSID 僅在系統授權後讀取；不開始就不會掃描。
  • 連線與會話： HTTP、WebSocket 和 MQTT 客戶端，串列埠助手（TCP、UDP 或藍芽；USB 需要受支援的 iPad 與尚未隨包的驅動），以及終端和 VNC 遠端工作區。
  • 分析： 抓包瀏覽器，支援匯入抓包檔案（PCAP/PCAPNG）；AI 分析顯示進度、可停止、超時如實報告。
  • 小工具： JSON 格式化、編碼轉換、二維碼和校驗碼。

測量與日常工具（較新構建）： 在頂部滑動入口、分類或搜尋中選擇工具；完整列表仍在下方。

  • 水平儀、運動感測器、指南針、氣壓與高度：開始後檢視讀數，按工具提供的操作歸零、鎖定或記錄，結束時停止採集。指南針顯示磁北；氣壓高度是相對變化。
  • 直尺與量角器、相機測量、圖片比例測量：螢幕尺先用實物校準；AR 測量需裝置支援。圖片先標定已知長度，再測同一平面上的長度、角度或面積，按需要匯出標註圖。視窗或顯示條件變化後重新核對校準。
  • 計算與換算、定位與地圖：計算表示式或互換單位並複製結果；定位獲授權後檢視位置和精度，按需儲存、分享地點或存入手記。
  • 聲音分析、放大鏡與照明、掃描與識別：主動開啟麥克風或相機；可檢視相對聲音電平與頻譜、放大或凍結畫面、掃描條碼和文字並匯出。聲音讀數不等於校準後的環境聲壓。
  • 秒錶與倒計時：記錄分段、管理多個命名倒計時，並按提示允許系統響鈴。任務中的分階段計時見使用手冊 §17；系統響鈴與模型繼續執行分別看待。

計算、換算與測量示例

  1. 點計算與換算，在計算器輸入 2×3，點底部計算。結果為 6，也會出現在歷史記錄里。點表達式旁的複製圖示可取用結果。
  2. 切到單位換算，選長度和毫米、釐米。輸入 1 後顯示 0.1 cm。點兩個單位間的交換按鈕可反轉方向，1 cm 會顯示為 10 mm。
  3. 回到工具箱，開啟直尺與量角器。選角度可拖動線上的控制點並讀取夾角。測量螢幕上的實際長度前，選已知尺寸的參照物、對齊兩個藍色標記，再點完成校准。校准前長度顯示為螢幕點。

一次測量只覆蓋一個端點與路徑，不代表整個網路。報告只匯出你選擇的內容。

7. 化學工程 — 1.8.5

在空間 → 新建中建立化學工程。原生結構編輯器把結構儲存進工程，計算記錄隨工程保留，結構圖可寫手記引用。重計算在配置的執行環境中執行——長任務前先確認環境可用。

8. 更多工作臺與適用版本

1.8.6 釋出說明已記錄這些公開安裝包新增內容：

  • LaTeX：工程工作臺、原始碼摺疊和 PDF 全文搜尋，並在切換全屏後保留閱讀與搜尋狀態。
  • 電子／PCB：原理圖與 PCB 編輯、畫布操作、設計規則檢查和同步；從 PCB 更新原理圖時展示差異並確認。
  • 生物學與 CAD 工程分析：空間中的更多原生工作臺入口，本版範圍包含編輯、預覽及儲存重開路徑。

部分高階 PCB 編輯和模擬分析仍在完善，原生 USB 串列埠驅動未包含在該構建中。這些新增記錄不表示全部專用能力或後續原始碼修改均已交付。

GIS、字型設計、制譜及 Image Playground 請分別核對專用編輯器接入計劃、在研接入記錄與所選版本說明。可用性按功能區分，原始碼接入不等於安裝包已交付。

從空間進入三維草圖

  1. 在空間 → 概覽開啟三維設計，命名並確認位置。左側草圖內有直線、矩形、圓等工具。
  2. 開啟草圖 → 矩形，按提示選擇參考平面。用手指時，先確認左側手指圖示觸屏繪圖高亮，再在網格上從一角拖到對角。鬆手後應出現四條閉合邊。拖動只平移視圖時，先檢查繪圖開關、矩形工具和當前平面。
  3. 點頂部 Exit Sketching（退出草圖），選取封閉輪廓的內部。在特徵 → 拉伸中，將距離設為 2 mm，選 New Body（新建實體）並確認。試做 5 × 3 mm 矩形時，沿面外方向應得到厚 2 mm 的實體。如果無法選取內部，回到草圖檢查是否有缺口或重疊。
  4. 關閉後從空間 → 檔案按名稱重開工程，確認實體仍在。需要交付網格時，用頂部分享圖示選擇 STL 並保存到系統“檔案”。收件軟體開啟後核對尺寸和方向。同時保留三維工程供後續修改。更多操作見統一 3D 工作臺。

論文排版概覽 → LaTeX 論文，在工程中編輯源碼，編譯後查看 PDF核對日誌和 PDF 頁數，分別保留工程源碼和交付 PDF
原理圖與 PCB檔案 → ＋ → 電路設計，編輯原理圖後核對元件和網路，再檢查 PCB應用同步前核對差異，布線後檢查設計規則
地圖資料檔案 → … → 匯入地理資料…，或在新建菜單選擇地圖編輯器選擇具體圖層，核對坐標系、可見性、屬性和匯出幾何
學習用的分子結構概覽 → 化學工程，在結構編輯器開啟或繪制分子先核對結構圖和工程保存，獨立檢查計算是否已完成
教學序列資料概覽 → 生物工程，開啟工程後查看所選記錄或注釋檢查記錄名稱和注釋範圍，區分原始檔案與匯出副本

這些工作臺在不同構建中的能力有所差異，入口和支援的格式以你的安裝版本為準。

二維設計：畫矩形並交付 DXF

  1. 從空間 → 概覽 → 二維設計新建圖紙。確認右上角單位為 mm，從左側開啟觸屏繪圖並選擇矩形。在網格上拖出兩角。示例繪出 6 × 4 mm，選取後顯示周長 20 mm。尺寸偏差時，檢查當前單位、捕捉狀態和四個角點。
  2. 用頂部分享圖示選擇 DXF，在系統“檔案”選擇保存位置。用目標 CAD 軟體開啟 DXF，確認輪廓閉合且寬高與工程一致。
  3. 點完成，再從空間 → 檔案按名稱重開圖紙，檢查四條邊。在 Floe 繼續編輯時開啟此圖紙。

地圖：匯入、改屬性並匯出 GeoJSON

  1. 在空間 → 檔案 → … → 匯入地理資料…選 GeoJSON。匯入後點左側具體圖層名稱，確認已選取，再點地圖工具欄的縮放至圖層。小區域首次開啟可能落在全球視圖里。先確認圖層可見、有要素，再核對坐標系。
  2. 開啟屬性表，選擇要素，點選要修改的欄位。輸入後按回車提交並等待保存。用一個帶 name 欄位的面要素做練習時，可以把名稱改成“示例區域”，保持原來的界線。重開專案並重新開啟屬性表，確認欄位值仍在。
  3. 長按左側的具體圖層行，點匯出圖層進入匯出資料／工程。選 GeoJSON，只要當前圖層時關閉包含所有矢量圖層。坐標系留空時，GeoJSON 使用 EPSG:4326。填名稱、點應用，從完成結果開啟匯出檔案，核對要素數量、屬性和幾何。
  4. 如匯入提示 Unexpected EOF，用原 GIS 工程重新匯出完整檔案，或檢查複製是否截斷，然後重試。成功後從空間 → 檔案開啟新工程確認圖層。

儲存、匯出與反饋

  • 關閉並重新開啟作品以確認儲存；在核對完成前保留恢復副本。
  • 刪除前先匯出或分享；被刪除的作品僅可在同一裝置上從“最近刪除”恢復。
