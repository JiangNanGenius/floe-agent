概覽

本頁適用於 Floe 的兩個平臺。安裝方式、選單位置、裝置訪問、本地模型和編輯器以各平臺的專用教程為準；操作流程相似，不代表兩個平臺擁有完全相同的工具。

1. 連線雲端模型

使用自己的模型服務賬號和 API Key。Floe 是客戶端，雲端請求、費用和資料政策由所選服務商負責。不要把網站登入密碼填入 API Key。

  1. 在模型設定中新增服務商，選擇服務及協議，填寫服務商文件中的介面地址和 API Key。
  2. 新增或重新整理模型列表，併為任務選擇模型。任務需要讀圖時選擇支援影象輸入的模型；圖片生成和影片生成需要支援對應用途的服務。
  3. 先進行一次簡短文字對話，再新增資料或啟動長任務。

認證失敗時核對地址、Key、賬號許可權和服務商實際返回的錯誤；模型或輸入型別不受支援時，換用適合該用途的模型。連線測試成功不代表所有工具和媒體能力都已驗證。

2. 讓任務產生可用成果

  1. 新建任務並選擇工作區，透過檔案選擇器加入一份不含敏感資訊的測試資料。
  2. 說明成果、輸入資料和儲存位置，例如：“閱讀這份文件，整理成待辦清單，儲存到當前工作區。”
  3. 檢視檔案或工具的授權請求，按任務需要開放相關資料。
  4. 開啟輸出檔案核對內容和位置，關閉再重開，確認成果已儲存。

修改成果時說清具體變化，並指出現有檔案。儘量在同一任務與工作區中繼續，便於助手接著處理原成果。工具返回成功後仍需開啟結果檢查。

3. 保留檔案與修改

只匯入準備交給任務使用的資料。外部位置失去訪問許可權時，重新選擇並授權原位置，不要在未確認的情況下把工作轉移到另一個目錄。

在實際使用的編輯器中確認儲存。匯出和另存會產生獨立成果，不會自動替代原件。其他編輯器已修改檔案時，先保留未儲存草稿，再核對衝突，避免直接覆蓋任一版本。重要資料保留獨立備份。

命令和軟體安裝使用任務所選的執行環境；核對當前目錄和輸出，確認修改的是目標檔案。可用環境、安裝步驟和後臺執行方式，以所在平臺和已安裝版本為準。

4. 使用工具與檢視進度

文件、網頁和工具結果只是輸入資料，其中的文字不能代替使用者授權執行命令、訪問其他檔案或傳送資訊。批准外部操作前，核對實際動作和目標位置。

在任務執行記錄中檢視進度和失敗原因。隱藏面板不一定會結束其中顯示的作業或服務；需要結束工作時使用對應的停止入口。後臺執行仍受作業系統限制。

5. 反饋問題

故障報告和功能請求以 GitHub Issues 為主。說明已安裝版本、裝置與系統、復現步驟、預期和實際結果；指出受影響的檔案或任務，但不要公開私人內容。

診斷和截圖由你主動選擇是否提交，只提供必要部分，並刪除 Key、密碼、個人資料和私人檔案。App 內診斷上傳用於提供排查資料，不承諾逐條回覆。雲端服務失敗時提供脫敏後的錯誤，不要提供 API Key。
