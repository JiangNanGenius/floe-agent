Descripción general

Esta guía cubre iOS / iPadOS. Compruebe la versión seleccionada para sus capacidades reales. Ver el Guía compartida Para modelos, tareas y archivos.

Elija un canal de instalación

Abre el Centro de liberación Y elija Floe Agent, Mac Bridge o iOS Bridge. El agente Floe está disponible en el App Store para iOS/iPadOS 26+; actualización a través de la tienda. GitHub iOS IPAs requieren su propia firma y pueden tener características más nuevas. Cheque Versiones del canal y fechas de verificación Antes de elegir un instalador. Aplicar en el sitio web Para el acceso a TestFlight; la solicitud no garantiza la elegibilidad inmediata.

Completar una tarea de IA

Agregue un modelo de nube que funcione en la configuración del modelo, luego cree una tarea y seleccione su espacio de trabajo. Seguir Modelos, tareas y archivos Para configuración, instrucciones claras, ahorro y errores comunes. Ver el Manual de la plataforma Para modelos locales y capacidades de dispositivos.

Ejecutar código en su dispositivo

Preparar: Suficiente almacenamiento y memoria. El iOS actual utiliza un tiempo de ejecución compartido ARM64 Linux mientras conserva la propiedad de la tarea y el proyecto. Los paquetes deben coincidir con la arquitectura del invitado.

  1. Descargue y verifique los recursos en la configuración del entorno de ejecución, luego abra el terminal del espacio de trabajo actual.
  2. Carrera pwd Y uname -m Para comprobar el directorio y la arquitectura real. Instale Python, Node.js u otros paquetes necesarios para ese entorno.
  3. Ejecute un programa pequeño y abra su salida. Para un servicio HTTP, elija Ejecutar como servicio web, Espera una respuesta real, luego previsualíla.
  4. Detenga el trabajo o servicio propio cuando haya terminado. Ocltar el terminal o cerrar la vista previa no detiene el trabajo en segundo plano.

Si falla: Inspeccione primero la instalación, el inicio y la salida del trabajo. Conservar los archivos del proyecto antes de la reparación; no restablezca ni elimine los datos como primer paso. Ver Terminales y entornos.

Crea y guarda un modelo 3D

Preparar: Una versión iOS/iPadOS con el banco de trabajo 3D nativo. Las mallas importadas no obtienen un historial paramétrico nativo, y las operaciones admitidas varían según el formato.

  1. Cree un modelo 3D nativo a través del flujo de trabajo creativo, comenzando con la geometría simple.
  2. Refina las dimensiones, agujeros o filetes en el mismo modelo. Al usar el asistente, identifique el modelo actual y el cambio previsto.
  3. Comprueba la geometría, los materiales y las vistas; guarda el .floecad Archivo y volver a abrirlo.
  4. Exporte una imagen o un formato 3D compatible para el uso previsto, luego compruébalo en la herramienta de recepción.

Si falla: Preservar las importaciones de solo lectura en lugar de tratar las importaciones exitosas como soporte editable. Deshacer un cambio de geometría fallido a un estado recuperable. Ver el Manual 3D nativo.

Prueba un trabajo en el espacio (construcciones más nuevas)

Preparar: Un instalador que incluye Space; ver el Guía del espacio de trabajo Para la construcción requerida y Estado del canal Para disponibilidad. Las IPA de GitHub necesitan su propia firma.

  1. Abrir Espacio Desde la barra lateral y cambie a Archivos. Grifo Nuevo Y crear un dibujo o un documento; nombrarlo.
  2. Edite el trabajo, luego ciérrelo y vuelva a abrirlo desde Continuar trabajando para confirmar que se ha guardado.
  3. Abra el asistente del trabajo y pídale que resuma o continúe el trabajo; revise cualquier propuesta antes de aceptarla.
  4. Elimine el trabajo de prueba y restaurelo desde Eliminado recientemente para aprender la recuperación.

Si falla: Confirme que la compilación admite el espacio (Configuración → Diagnóstico y Acerca de). Ver Espacio y bancos de trabajo especializados Para reuniones, música, impresión y la caja de herramientas.

Mac Bridge: instala un Lanzamiento seleccionado, Abre la aplicación de la barra de menús y conéctate desde Floe en el mismo Mac. Compare el código y apruebe ambas indicaciones. Revise el directorio y lea un archivo de prueba antes de comenzar a trabajar. Los comandos no se repiten después de la desconexión. Si falta el icono de la barra de menús, reinicie la aplicación; si el emparejamiento falla, compruebe ambas versiones y confirmaciones.

Puente iOS: comienza con el Instrucciones de instalación versionadas. La versión 1.0 requiere la firma con capacidades de extensión de red; no se garantizan configuraciones arbitrarias de re-firma. Completa la preparación en la aplicación y aprueba el emparejamiento del cliente en el dispositivo. El acceso es local por defecto; habilite el acceso LAN solo cuando sea necesario. Lea la pantalla después de una acción; no repita automáticamente un toque cuando su resultado no esté confirmado.

Ahorre, recupere y obtenga ayuda

Confirme el guardado en cada editor de Office, medios o 3D. Guardar como y exportar no reemplazan automáticamente el original. Conserve las copias de recuperación cuando queden conflictos. Mantenga copias de seguridad independientes de los archivos importantes.

Para obtener asistencia, describa la versión, el dispositivo, los pasos, el resultado esperado y el resultado real en el Canal de apoyo. Envíe solo los diagnósticos o capturas de pantalla necesarios de forma voluntaria; nunca incluya contraseñas, claves o archivos privados. Continúa con el Manual completo Y el Guía del espacio de trabajo.
