¿Dónde está?

Configuración > Entorno de ejecución > Tiempo de ejecución compartido > Memoria

Configuración > Entorno de ejecución > Tiempo de ejecución compartido > Memoria.

Cámbialo

Abra Configuración, toque Entorno de ejecución, luego Tiempo de ejecución compartido y seleccione Memoria.

Notas

Las opciones de memoria aparecen después de que el tiempo de ejecución compartido esté listo. Bajar el límite espera a que los proyectos actuales se cierren.
