# Ajuda Floe (floe.help.quickstart 1.4.0)

Este é o pacote de documentos offline para o centro de ajuda integrado Floe. Leia-o no aplicativo em Configurações > Ajuda com conteúdo, pesquisa e imagens.

## Da instalação ao seu primeiro resultado

Este guia cobre iOS / iPadOS. Verifique a versão selecionada para seus recursos reais. Veja o guia compartilhado para modelos, tarefas e arquivos.

- Visão geral
- Escolha um canal de instalação
- Complete uma tarefa de IA
- Execute o código no seu dispositivo
- Crie e salve um modelo 3D
- Experimente um trabalho no espaço (novas construções)
- Escolha a ponte certa
- Economize, recupere e obtenha ajuda

## Modelos, tarefas e arquivos

Esses fluxos de trabalho se aplicam a ambas as edições do Floe. Instalação, locais de menu, acesso ao dispositivo, modelos locais e editores são cobertos pelo próprio guia de cada plataforma. Um fluxo de trabalho compartilhado não significa que todas as plataformas têm o mesmo

- 2. Peça um resultado útil
- 3. Mantenha arquivos e alterações seguros
- 4. Use ferramentas com contexto
- 5. Relatar um problema
