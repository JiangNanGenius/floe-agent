# Floe ヘルプ (floe.help.quickstart 1.4.0)

これは、組み込みのFloeヘルプセンター用のオフラインドキュメントパッケージです。 アプリの「設定」>「コンテンツ、検索、画像のヘルプ」からお読みください。

## インストールから最初の結果まで

このガイドでは iOS / iPadOS を取り上げています。 選択したリリースの実際の機能を確認してください。 モデル、タスク、ファイルに関する共有ガイドをご覧ください。

- 概要
- インストールチャンネルを選択してください
- AIタスクを完了してください
- デバイスでコードを実行してください
- 3Dモデルを作成して保存してください
- Spaceで作業してみてください（新しいビルド）
- 適切なブリッジを選択してください
- 保存し、回復し、サポートを受ける

## モデル、タスク、ファイル

これらのワークフローは、Floe の両方のエディションに適用されます。 インストール、メニューの位置、デバイスへのアクセス、ローカルモデル、エディタは、各プラットフォームの独自のガイドでカバーされています。 共有ワークフローは、すべてのプラットフォームが同じであることを意味するわけではありません。

- 概要
- 1. クラウドモデルを接続する
- 2. 有益な結果を求めてください
- 3. ファイルと変更を安全に保つ
- 4. コンテキストを使用してツールを使用してください
- 5. 問題を報告する
