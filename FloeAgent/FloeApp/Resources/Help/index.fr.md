# Aide de Floe (floe.help.quickstart 1.3.0)

Il s'agit du paquet de documents hors ligne pour le centre d'aide Floe intégré. Lisez-le dans l'application sous Paramètres > Aide avec le contenu, la recherche et les images.

## De l'installation à votre premier résultat

Ce guide couvre iOS / iPadOS. Vérifiez la version sélectionnée pour ses capacités réelles. Consultez le guide partagé pour les modèles, les tâches et les fichiers.

- Vue d’ensemble
- Choisissez un canal d'installation
- Compléter une tâche d'IA
- Exécutez le code sur votre appareil
- Créer et enregistrer un modèle 3D
- Essayez un travail dans l'espace (constructions plus récentes)
- Choisissez le bon pont
- Économisez, récupérez et obtenez de l'aide
