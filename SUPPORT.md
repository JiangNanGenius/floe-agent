# Support

Floe Agent does not yet have a supported public release. Community help is best-effort and development builds should not be used with production credentials or machines.

## Where to ask

- Use a [GitHub issue](https://github.com/JiangNanGenius/floe-agent/issues/new/choose) for a reproducible bug, build problem, documentation gap, or scoped feature proposal.
- Check the [README](README.md), [development plan](docs/DEVELOPMENT_PLAN.md), and existing issues before opening a new report.
- Include the branch or commit, Xcode and macOS versions, target device or simulator, reproduction steps, expected behavior, observed behavior, and sanitized logs.

Never include API keys, passwords, private keys, hostnames, personal files, or other secrets. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
