# Floe 幫助 (floe.help.quickstart 1.4.0)

這是 Floe App 內建幫助中心的離線文件包。請在 App 的“設定 > 幫助”中閱讀，支援目錄、搜尋與圖文。

## 從安裝到第一個成果

本頁適用於 iOS / iPadOS。功能以所選版本的釋出說明為準；模型、任務與檔案的通用操作見共通指南。

- 概覽
- 選擇安裝方式
- 完成一個 AI 任務
- 在裝置端執行程式碼
- 建立並儲存一個 3D 模型
- 在空間試用一個作品（較新構建）
- 區分兩種 Bridge
- 儲存、恢復與反饋

## 模型、任務與檔案

本頁適用於 Floe 的兩個平臺。安裝方式、選單位置、裝置訪問、本地模型和編輯器以各平臺的專用教程為準；操作流程相似，不代表兩個平臺擁有完全相同的工具。

- 概覽
- 1. 連線雲端模型
- 2. 讓任務產生可用成果
- 3. 保留檔案與修改
- 4. 使用工具與檢視進度
- 5. 反饋問題

本指南主要介紹 iOS/iPadOS。從安裝到第一個成果提供任務式教程。App Store、GitHub／Feather 與 TestFlight 的版本及核實日期統一見渠道狀態。GitHub IPA 需要自行簽名，TestFlight 可用性以實際測試組為準。各工作臺的適用版本見空間與專用工作臺教程。

- 7. 手記：匯入、搜尋與書寫

- 9. 本地終端與 Linux 效能配置
- 10. Python、Node、依賴與執行程式碼
- 11. Git 與 GitHub Actions
- 12. 遠端裝置、桌面與網路診斷
- 13. 瀏覽器、網頁預覽與登入
- 14. 工程圖紙與圖紙助手
- 15. 畫布、影象、音影片

- 17. Skills、MCP、郵件與自動任務
