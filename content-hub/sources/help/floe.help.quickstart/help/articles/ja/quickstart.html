概要

このガイドでは iOS / iPadOS を取り上げています。 選択したリリースの実際の機能を確認してください。 ご覧ください 共有ガイド モデル、タスク、ファイル用です。

インストールチャンネルを選択してください

開く リリースセンター そして、Floe Agent、Mac Bridge、またはiOS Bridgeを選択してください。 Floeエージェントは、iOS/iPadOS（26歳以上）向けにApp Storeでご利用いただけます。ストアから更新してください。 GitHub iOS IPAはご自身の署名が必要で、新しい機能が搭載されている可能性があります。 検査する チャンネルバージョンと検証日 インストーラーを選択する前に ウェブサイトで申し込む TestFlightへのアクセスについて；申請しても即時の適格性が保証されるわけではありません。

AIタスクを完了してください

モデル設定で作業中のクラウドモデルを追加し、タスクを作成してそのワークスペースを選択してください。 続く モデル、タスク、ファイル 設定、明確な手順、保存、および一般的なエラーについて。 ご覧ください プラットフォームマニュアル ローカルモデルおよびデバイスの機能について。

デバイスでコードを実行してください

準備してください： 十分なストレージとメモリ。 現在の iOS は、タスクおよびプロジェクトの所有権を保持しながら、共有 ARM64 Linux ランタイムを使用しています。 パッケージはゲストアーキテクチャと一致しなければなりません。

  1. 実行環境設定でリソースをダウンロードし、検証してから、現在のワークスペース端末を開いてください。
  2. ラン pwd そして uname -m ディレクトリと実際のアーキテクチャを確認する。 その環境にPython、Node.js、またはその他の必要なパッケージをインストールしてください。
  3. 小さなプログラムを実行し、その出力を開いてください。 HTTP サービスの場合は、選択してください Webサービスとして実行、実際の応答を待ってから、プレビューしてください。
  4. 完了したら、所有ジョブまたはサービスを停止してください。 端末を隠したりプレビューを閉じたりしても、バックグラウンド作業は停止しません。

失敗した場合は： まず、インストール、起動、ジョブの出力を検査してください。 修復する前にプロジェクトファイルを保存し、最初のステップとしてデータをリセットしたり削除したりしないでください。 見てみる 端末と環境.

3Dモデルを作成して保存してください

準備してください： ネイティブ3Dワークベンチを使用したiOS/iPadOSリリース。 インポートされたメッシュはネイティブのパラメトリック履歴を取得せず、サポートされる操作はフォーマットによって異なります。

  1. クリエイティブなワークフローを通じて、シンプルなジオメトリから始めて、ネイティブの3Dモデルを作成してください。
  2. 同一モデル内で寸法、穴、またはフィレットを絞り込む。 アシスタントを使用する際は、現在のモデルと意図された変更を特定してください。
  3. ジオメトリ、素材、ビューを確認し、保存してください。 .floecad ファイルをファイルし、再度開いてください。
  4. 意図した使用目的の画像またはサポートされている3D形式をエクスポートし、受信ツールで確認してください。

失敗した場合は： 成功したインポートを編集可能なサポートとして扱うのではなく、読み取り専用のインポートを保持します。 失敗したジオメトリの変更を復元可能な状態に元に戻す。 ご覧ください ネイティブ3Dマニュアル.

Spaceで作業してみてください（新しいビルド）

準備してください： Space を含むインストーラです；参照してください ワークスペースガイド 必要なビルドと チャンネルのステータス 可用性について GitHub IPAはご自身の署名が必要です。

  1. 開く スペース サイドバーから「Files」に切り替えてください。 軽くたたく 新しい そして、図面または文書を作成し、名前を付けてください。
  2. 作業を編集し、閉じてから「Continue working」から再度開いて、保存されたことを確認してください。
  3. 作業のアシスタントを開き、作業を要約または続行するよう依頼してください；提案を受諾する前にすべて確認してください。
  4. テスト作業を削除し、最近削除した項目から復元して、リカバリを学んでください。

失敗した場合は： ビルドがスペースをサポートしていることを確認してください（設定 → 診断と概要）。 見てみる スペースと専門作業台 会議、音楽、印刷、ツールボックスのために。

適切なブリッジを選択してください

製品目的接続する前に
Floe ブリッジ · Mac同じMacでFloeからターミナル、ファイル、MCPを使用する両方のアプリは1台のMacで実行され、同じペアリングコードを確認します。これはiPadからMacへのリモートブリッジではありません。
Floe iOS ブリッジiPhone および iPad 用のスタンドアロンローカルオートメーションブリッジ必要な署名機能、デバイスの準備およびペアリングが必要です；バージョン1.0はメインのFloeアプリと統合されていません

Mac Bridge: インストール 選択されたリリース、メニューバーアプリを開き、同じMac上のFloeから接続してください。 コードを比較し、両方のプロンプトを承認してください。 作業を開始する前に、ディレクトリを確認し、テストファイルを読んでください。 切断後、コマンドは再生されません。 メニューバーのアイコンが見当たらない場合は、アプリを再起動してください。ペアリングに失敗した場合は、両方のバージョンと確認を確認してください。

iOS ブリッジ：開始は バージョン管理されたインストール手順. バージョン1.0では、Network Extension機能による署名が必要です。任意の再署名設定は保証されません。 アプリで準備を完了し、デバイス上でクライアントのペアリングを承認してください。 アクセスはデフォルトでローカルです。必要な場合にのみ LAN アクセスを有効にしてください。 操作後に画面を読み取ってください；結果が未確認の場合、自動的にタップを繰り返さないでください。

保存し、回復し、サポートを受ける

各Office、メディア、または3Dエディタに保存されていることを確認してください。 名前を付けて保存するとエクスポートは、元のデータを自動的に置き換えるわけではありません。 競合が残っている場合は、リカバリコピーを保存してください。 重要なファイルの独立したバックアップを保持してください。

サポートのために、バージョン、デバイス、手順、期待される結果、実際の結果を記述してください。 サポートチャンネル. 必要な診断情報またはスクリーンショットのみを自発的に提出し、パスワードやキー、プライベートファイルは決して含めない。 続行 フルマニュアル そして ワークスペースガイド.
