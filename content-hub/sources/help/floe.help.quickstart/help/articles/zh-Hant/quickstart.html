概覽

本頁適用於 iOS / iPadOS。功能以所選版本的釋出說明為準；模型、任務與檔案的通用操作見共通指南。

選擇安裝方式

先開啟版本中心，按產品選擇 Floe Agent、Mac Bridge 或 iOS Bridge。Floe Agent 正式版已上架 App Store（iOS/iPadOS 26+），可直接安裝與更新。GitHub iOS IPA 需要自行簽名，可能包含較新功能；選擇安裝包前核對渠道版本及核實日期。想使用 TestFlight，可在官網申請，申請不等於立即獲得測試資格。

完成一個 AI 任務

先在模型設定新增可用的雲端模型，再新建任務並選擇工作區。如何配置模型、描述成果、核對儲存和處理常見錯誤，見模型、任務與檔案。本地模型安裝與裝置能力見本平臺手冊。

在裝置端執行程式碼

準備： 足夠的可用儲存和裝置記憶體。iOS 當前使用共享 ARM64 Linux 執行環境，任務與專案目錄保持各自歸屬；執行包需適配客體架構。

  1. 到執行環境設定下載並校驗所需資源，再開啟當前工作區的本地終端。
  2. 執行 pwd 和 uname -m，核對目錄與實際架構，然後按任務安裝 Python、Node.js 或所需軟體包。
  3. 執行一個小程式，開啟生成的檔案；網頁服務使用“作為網頁服務執行”，待實際響應後再預覽。
  4. 結束時停止對應作業或服務。隱藏終端、關閉預覽不等於停止後臺任務。

遇到問題： 先檢視安裝、啟動和執行輸出。資源修復前保留專案檔案，不隨意重置或刪除資料。詳見終端與執行環境。

建立並儲存一個 3D 模型

準備： 已提供原生 3D 工作臺的 iOS/iPadOS 版本。匯入的網格不自動擁有原生引數化歷史；不同格式支援的操作不同。

  1. 在創作流程中建立原生 3D 模型，先用簡單幾何建立可編輯成果。
  2. 在同一模型中繼續調整尺寸、孔或圓角；使用 AI 時明確當前模型及所需修改。
  3. 核對幾何、材質和檢視，儲存 .floecad，關閉後重開確認。
  4. 按用途匯出圖片或受支援的 3D 格式，使用接收方工具再核對。

遇到問題： 格式只讀時保留原檔案，不把匯入成功當作可編輯證明；幾何失敗先撤銷到可恢復狀態。詳見原生 3D 手冊。

在空間試用一個作品（較新構建）

準備： 包含空間功能的安裝包，適用版本見工作臺教程，渠道可用性見版本狀態。GitHub IPA 下載後需自行簽名。

  1. 從側欄開啟空間，切換到“檔案”。點新建建立一個繪畫或文件作品並命名。
  2. 編輯作品後關閉，再從“繼續使用”重新開啟，確認儲存成功。
  3. 開啟該作品的助手，請它總結或繼續處理；採納前核對每項建議。
  4. 刪除測試作品，再從“最近刪除”恢復，熟悉恢復流程。

遇到問題： 先確認構建支援空間（設定 → 診斷與關於）。會議、音樂、列印和工具箱見空間與專用工作臺。

區分兩種 Bridge

產品用途連線前檢查
Floe Bridge · Mac為同一臺 Mac 上的 Floe 提供本機終端、檔案和 MCP兩個應用在同一臺 Mac，雙方確認同一配對碼；不是 iPad 到 Mac 的遠端橋
Floe iOS Bridge獨立的 iPhone/iPad 本機自動化橋自行簽名所需能力、裝置設定與授權；1.0 不接入主 Floe App

Mac Bridge：從對應版本安裝，啟動選單欄應用，再在同一 Mac 的 Floe 中發起連線；雙方核對驗證碼並確認。先檢查目錄、讀取一個測試檔案，再開始任務。斷開後不自動重放命令。沒有圖示時重新啟動應用；拒絕連線時檢查兩端版本與配對確認。

iOS Bridge：先閱讀固定版本安裝說明。1.0 的簽名材料需要 Network Extension 能力，不承諾任意重籤方式相容。按應用嚮導完成裝置準備，在裝置上批准客戶端配對；預設只訪問本機，需要時才開啟區域網。操作後重新讀屏核對，遇到“結果未確認”不要自動重複點選。

儲存、恢復與反饋

Office、媒體和 3D 成果應分別在對應編輯器確認儲存；另存和匯出不會自動替代原件。存在衝突時先保留恢復副本。重要資料始終保留獨立備份。

仍有問題時，在支援入口描述版本、裝置、復現步驟、預期與實際結果；診斷和截圖只主動提交必要部分，不附密碼、Key 或私人檔案。繼續閱讀完整手冊與空間與專用工作臺。
