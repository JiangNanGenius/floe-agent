Übersicht

Dieser Leitfaden behandelt iOS / iPadOS. Überprüfen Sie die ausgewählte Version auf ihre tatsächlichen Fähigkeiten. Siehe die Gemeinsamer Leitfaden Für Modelle, Aufgaben und Dateien.

Wählen Sie einen Installationskanal

Öffnen Sie die Freigabezentrum Und wählen Sie Floe Agent, Mac Bridge oder iOS Bridge. Floe Agent ist auf dem App Store für iOS/iPadOS 26+ verfügbar; Update über den Store. GitHub iOS IPAs erfordern Ihre eigene Unterschrift und können neuere Funktionen enthalten. Scheck Kanalversionen und Verifizierungsdaten Vor der Auswahl eines Installateurs. Bewerben Sie sich auf der Website Für TestFlight-Zugang; die Bewerbung garantiert nicht die sofortige Berechtigung.

Erledige eine KI-Aufgabe

Fügen Sie in den Modelleinstellungen ein funktionierendes Cloud-Modell hinzu, erstellen Sie dann eine Aufgabe und wählen Sie deren Arbeitsbereich aus. Folgen Modelle, Aufgaben und Dateien Für Konfiguration, klare Anweisungen, Speichern und häufige Fehler. Siehe die Plattformhandbuch Für lokale Modelle und Gerätefunktionen.

Code auf Ihrem Gerät ausführen

Vorbereiten: Genügend Speicherplatz und Speicher. Die aktuelle iOS verwendet eine gemeinsame ARM64 Linux-Laufzeit, während Aufgaben- und Projektbesitz erhalten bleibt. Pakete müssen mit der Gastarchitektur übereinstimmen.

  1. Laden Sie Ressourcen in den Einstellungen für die Ausführungsumgebung herunter und überprüfen Sie sie, und öffnen Sie dann das aktuelle Workspace-Terminal.
  2. Lauf pwd Und uname -m Um das Verzeichnis und die tatsächliche Architektur zu überprüfen. Installieren Sie Python, Node.js oder andere erforderliche Pakete für diese Umgebung.
  3. Führen Sie ein kleines Programm aus und öffnen Sie dessen Ausgabe. Wählen Sie für einen HTTP-Dienst Ab-Dienst als Webdienst ausführen, Warten Sie auf eine echte Antwort und sehen Sie sie dann in der Vorschau an.
  4. Beenden Sie den eigenen Auftrag oder die Dienstleistung, wenn Sie fertig sind. Das Angehen des Terminals oder das Schließen der Vorschau stoppt die Hintergrundarbeit nicht.

Wenn es fehlschlägt: Überprüfen Sie zuerst die Installation, den Start und die Auftragsausgabe. Bewahren Sie Projektdateien vor der Reparatur auf; setzen Sie Daten nicht zurück oder löschen Sie sie als ersten Schritt. Sehen Terminals und Umgebungen.

Erstellen und Speichern eines 3D-Modells

Vorbereiten: Eine iOS/iPadOS-Version mit der nativen 3D-Werkbank. Importierte Meshes erhalten keinen nativen parametrischen Verlauf, und unterstützte Vorgänge variieren je nach Format.

  1. Erstellen Sie ein natives 3D-Modell durch den kreativen Workflow, beginnend mit einfacher Geometrie.
  2. Verfeinern Sie die Abmessungen, Löcher oder Filets im selben Modell. Wenn Sie den Assistenten verwenden, geben Sie das aktuelle Modell und die beabsichtigte Änderung an.
  3. Überprüfen Sie Geometrie, Materialien und Ansichten; speichern Sie die .floecad Datei und öffnen Sie sie erneut.
  4. Exportieren Sie ein Bild oder ein unterstütztes 3D-Format für die beabsichtigte Verwendung und überprüfen Sie es dann im Empfangstool.

Wenn es fehlschlägt: Bewahren Sie schreibgeschützte Importe bei, anstatt den erfolgreichen Import als bearbeitbare Unterstützung zu behandeln. Eine fehlgeschlagene Geometrieänderung in einen wiederherstellbaren Zustand rückgängig machen. Siehe die Natives 3D-Handbuch.

Versuchen Sie eine Arbeit im Weltraum (neuere Builds)

Vorbereiten: Ein Installationsprogramm, das Speicherplatz enthält; siehe die Leitfaden für den Arbeitsbereich Für den erforderlichen Build und Kanalstatus Für Verfügbarkeit. GitHub IPAs benötigen Ihre eigene Signatur.

  1. Öffnen Bereich Von der Seitenleiste und wechseln Sie zu Dateien. Wasserhahn Neu Und erstellen Sie eine Zeichnung oder ein Dokument; nennen Sie es.
  2. Bearbeiten Sie die Arbeit, schließen Sie sie, und öffnen Sie sie erneut, um zu bestätigen, dass sie gespeichert ist.
  3. Öffnen Sie den Assistenten der Arbeit und bitten Sie ihn, die Arbeit zusammenzufassen oder fortzusetzen; überprüfen Sie jeden Vorschlag, bevor Sie ihn annehmen.
  4. Löschen Sie die Testarbeit und stellen Sie sie aus "Kutzt gelöscht" wieder her, um die Wiederherstellung zu erfahren.

Wenn es fehlschlägt: Bestätigen Sie, dass der Build Space unterstützt (Einstellungen → Diagnose & Info). Sehen Raum- und Fachwerkbänke Für Meetings, Musik, Drucken und den Werkzeugkasten.

Wählen Sie die richtige Brücke

ErzeugnisZweckVor der Verbindung
Floe Brücke · MacTerminal, Dateien und MCP für Floe auf demselben MacBeide Apps laufen auf einem Mac und bestätigen denselben Kopplungscode; dies ist keine iPad-zu-Mac-Remote-Bridge
Floe iOS BrückeEine eigenständige lokale Automatisierungsbrücke für iPhone und iPadErforderliche Signierfähigkeiten, Geräteeinrichtung und Kopplung. Version 1.0 ist noch nicht in die Floe-Hauptapp integriert.

Mac Bridge: Installieren Sie eine Ausgewählte Freigabe, Öffnen Sie die Menüleisten-App und verbinden Sie sich von Floe auf demselben Mac. Vergleichen Sie den Code und genehmigen Sie beide Aufforderungen. Überprüfen Sie das Verzeichnis und lesen Sie eine Testdatei, bevor Sie mit der Arbeit beginnen. Befehle werden nach der Trennung nicht wiederholt. Wenn das Menüleistensymbol fehlt, starten Sie die App neu; wenn die Kopplung fehlschlägt, überprüfen Sie sowohl Versionen als auch Bestätigungen.

iOS Bridge: Beginnen Sie mit dem Versionierte Installationsanweisungen. Version 1.0 erfordert die Unterzeichnung mit Netzwerkerweiterungsfunktionen; willkürliche Neusignierungseinstellungen sind nicht garantiert. Schließen Sie die Vorbereitung in der App ab und genehmigen Sie die Client-Kopplung auf dem Gerät. Der Zugriff ist standardmäßig lokal; LAN-Zugriff nur bei Bedarf aktivieren. Lesen Sie den Bildschirm nach einer Aktion; wiederholen Sie ein Tippen nicht automatisch, wenn das Ergebnis nicht bestätigt ist.

Speichern, wiederherstellen und Hilfe erhalten

Bestätigen Sie das Speichern in jedem Office-, Medien- oder 3D-Editor. Save-as und Export ersetzen nicht automatisch das Original. Bewahren Sie Wiederherstellungskopien auf, wenn Konflikte bestehen bleiben. Halten Sie unabhängige Backups wichtiger Dateien.

Beschreiben Sie für Support die Version, das Gerät, die Schritte, das erwartete Ergebnis und das tatsächliche Ergebnis in der Unterstützungskanal. Reichen Sie nur die notwendigen Diagnosen oder Screenshots freiwillig ein; fügen Sie niemals Passwörter, Schlüssel oder private Dateien hinzu. Fahren Sie mit dem Vollständiges Handbuch Und die Leitfaden für den Arbeitsbereich.
