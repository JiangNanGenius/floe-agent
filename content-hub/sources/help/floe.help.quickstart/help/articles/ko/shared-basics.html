개요

이러한 워크플로는 Floe의 두 에디션 모두에 적용됩니다. 설치, 메뉴 위치, 장치 접근, 로컬 모델 및 편집기는 각 플랫폼 고유의 가이드에 포함되어 있습니다. 공유 워크플로우가 모든 플랫폼에 동일한 도구가 있다는 뜻은 아닙니다.

1. 클라우드 모델을 연결하십시오

자신의 모델 제공업체 계정과 API 키를 가져오세요. Floe는 클라이언트이며, 선택된 제공업체는 클라우드 요청, 가격 및 자체 데이터 정책을 처리합니다. API 키 필드에 웹사이트 비밀번호를 입력하지 마십시오.

  1. 모델 설정에 제공자를 추가하십시오. 서비스와 프로토콜을 선택한 다음, 문서화된 기본 URL과 API 키를 입력하십시오.
  2. 모델 목록을 추가하거나 새로 고침하고 작업에 대한 모델을 선택하십시오. 작업이 그림을 읽어야 할 경우, 이미지 입력을 허용하는 모델을 선택하십시오. 이미지 생성 및 비디오 생성에는 해당 목적을 지원하는 서비스가 필요합니다.
  3. 파일을 첨부하거나 긴 작업을 시작하기 전에 짧은 텍스트 대화를 테스트하십시오.

인증 실패에 대해서는 엔드포인트, 키, 계정 접근 및 실제 제공자 오류를 확인하십시오. 지원되지 않는 모델 또는 입력 유형의 경우, 적절한 모델을 선택하십시오. 성공적인 연결 테스트가 모든 도구 또는 미디어 기능을 검증하는 것은 아닙니다.

2. 유용한 결과를 요청하십시오

  1. 작업을 생성하고 작업 공간을 선택하십시오. 파일 선택기를 통해 비민감 테스트 파일을 추가하십시오.
  2. 의도한 결과와 입력, 그리고 저장할 위치를 명시하십시오. 예를 들어: “이 문서를 읽고, 체크리스트로 변환한 뒤 현재 작업 공간에 저장하십시오.”
  3. 파일 또는 도구에 대한 접근 요청을 검토하십시오. 이 작업에 필요한 자료에 대한 접근 권한을 부여하십시오.
  4. 출력물을 열고 내용과 위치를 확인한 뒤, 닫았다가 다시 열어 저장되었는지 확인하십시오.

결과를 수정할 때는 구체적인 변경 사항을 설명하고 기존 파일을 참조하십시오. 작업과 작업 공간을 일관되게 유지하여 보조자가 동일한 작업을 계속할 수 있도록 하십시오. 도구의 성공 메시지는 결과를 확인하기 위한 신호일 뿐만 아니라, 이를 열 수 있는 대체가 아닙니다.

3. 파일 및 변경 사항을 안전하게 보관하십시오.

작업에 사용하려는 파일만 가져오십시오. 외부 위치를 사용할 수 없게 되면, 작업을 다른 폴더로 조용히 옮기는 대신 원래 위치를 다시 선택하고 인증하십시오.

사용하신 편집기에서 저장을 확인하십시오. 내보내기와 다른 이름으로 저장은 별도의 결과를 생성하며 원본을 자동으로 교체하지 않습니다. 다른 편집자가 파일을 변경한 경우, 저장되지 않은 초안을 보존하고 충돌을 검토한 후 어느 복사본을 덮어쓰십시오. 중요한 작업에 대한 독립적인 백업을 유지하십시오.

명령 및 소프트웨어 설치는 작업이 선택한 실행 환경을 사용합니다. 명령이 의도한 파일을 변경하기 전에 현재 디렉터리와 출력을 확인하십시오. 사용 가능한 환경, 설치 단계 및 백그라운드 동작은 플랫폼 및 설치된 버전에 따라 달라집니다.

4. 문맥을 활용한 도구를 사용하십시오.

문서, 웹 페이지 및 도구 결과는 입력 자료이며, 해당 텍스트는 명령을 실행하거나 다른 파일에 접근하거나 정보를 전송할 권한을 부여하지 않습니다. 외부 작업을 승인하기 전에 실제 작업과 목적지를 검토하십시오.

작업 실행 기록에서 진행 상황과 실패를 읽습니다. 패널을 숨겨도 표시되는 작업이나 서비스가 반드시 중단되는 것은 아닙니다. 작업이 종료되어야 할 때 작업 또는 서비스의 정지 제어를 사용하십시오; 운영 체제는 여전히 백그라운드 실행을 제어합니다.

5. 문제 신고

사용하다 GitHub 문제 버그 보고 및 기능 요청에 대해. 설치된 버전, 장치 및 OS, 단계, 예상 결과 및 실제 결과를 포함하십시오. 개인 콘텐츠를 게시하지 않고 영향을 받은 파일이나 작업을 명시하십시오.

진단 및 스크린샷은 선택 사항입니다. 필요한 자료만 제출하고 키, 비밀번호, 개인 데이터 및 개인 파일은 삭제하십시오. 앱 내 진단 업로드는 문제 해결 자료를 제공하며 개별적인 응답을 보장하지 않습니다. 클라우드 서비스 오류의 경우, API 키 대신 편집된 공급자 오류를 포함하십시오.
