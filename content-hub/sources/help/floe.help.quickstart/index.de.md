# Floe Hilfe (floe.help.quickstart 1.4.0)

Dies ist das Offline-Dokumentenpaket für das integrierte Floe-Hilfezentrum. Lesen Sie es in der App unter Einstellungen > Hilfe zu Inhalten, Suche und Bildern.

## Von der Installation bis zum ersten Ergebnis

Dieser Leitfaden behandelt iOS / iPadOS. Überprüfen Sie die ausgewählte Version auf ihre tatsächlichen Fähigkeiten. Im freigegebenen Leitfaden finden Sie Modelle, Aufgaben und Dateien.

- Übersicht
- Wählen Sie einen Installationskanal
- Erledige eine KI-Aufgabe
- Code auf Ihrem Gerät ausführen
- Erstellen und Speichern eines 3D-Modells
- Versuchen Sie eine Arbeit im Weltraum (neuere Builds)
- Wählen Sie die richtige Brücke
- Speichern, wiederherstellen und Hilfe erhalten

## Modelle, Aufgaben und Dateien

Diese Arbeitsabläufe gelten für beide Ausgaben von Floe. Installation, Menüpositionen, Gerätezugriff, lokale Modelle und Editoren werden von der eigenen Anleitung jeder Plattform abgedeckt. Ein gemeinsamer Workflow bedeutet nicht, dass jede Plattform das Gleiche hat

- Übersicht
- 1. Ein Cloud-Modell verbinden
- 2. Fragen Sie nach einem nützlichen Ergebnis
- 3. Dateien und Änderungen sicher aufbewahren
- 4. Verwenden Sie Werkzeuge mit Kontext
- 5. Ein Problem melden
