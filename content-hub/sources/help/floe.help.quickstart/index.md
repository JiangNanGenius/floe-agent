# Floe quickstart

1. Open a chat and pick a configured model. Providers and keys live in Settings,
   not in this help package.
2. Work with Notes or Canvas for longer documents; both keep their own editor
   state and history.
3. Attach files or images from the composer. Imported documents remain untrusted
   data and cannot grant tool permissions.
4. Ask for a tool by describing the outcome, for example "make a report".
   Available tools depend on enabled, configured capabilities.
5. Every signed content package is verified before it is used. If verification
   fails, Floe keeps the previously installed version.
